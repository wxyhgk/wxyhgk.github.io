    GaussView 6：绘图与光谱（Plots & Spectra）（p.88–135）¶

    3D Scan 图、Plot 各面板、自定义、右键菜单、参考数据、位移模式、同位素、线型、Spectra 菜单与数据保存

    原文件：../gview6官方说明书.md（全量单文件存档）｜图片目录：../imgs/

    Scan 结果¶

    通过结果（Results）=>Scan 菜单路径，可以查看产生多个结构的计算所得能量及其他结果的绘图。

    Scan 结果示例 点击图中的一点，对应的结构即会出现在视图窗口中。

    关于使用绘图（Working with Plots）的更多信息见此处。

    3D Scan 图¶

    对两个变量进行 Scan 的 Gaussian 计算，GaussView 会将其绘制为三维表面。与 2D 图一样，可以点击该图中的各个点。

    对 2 个变量进行 PES Scan 的结果绘图 只有恰好对两个变量进行 Scan 的计算才会产生这样的图形。该图可使用标准鼠标操作进行旋转和缩放，并可通过点击选择节点。

    3D Scan 的右键菜单与其他绘图不同（如上图所示）。它包含以下项目：

    • 保存图像文件（Save Image File）：将图像保存为图形文件。

    • 保存数据（Save Data）：将图形数据保存为文本文件。

    • 显示表面（Show Surface）：选择表面显示类型。默认为填充网格（filled mesh）。

    • 显示柱条（Show Bars）：以多种样式将数值绘制为 z 方向的线条（柱条）。柱条最常与线框（Wireframe）或无（None）表面显示组合使用。

    • 显示节点（Show Nodes）：将所有结构的位置显示为白点（全部（All），为默认值）、仅显示活动（Active）节点（显示为绿点），或在交叉处不做特殊标记（无（None））。

    • 其余五个 show 项目用于显示或隐藏相应项目。这些选项为开关切换。

    • 4 个 Edit 项目允许修改各种标签文本。

    • 反转坐标轴（Invert Axis）：反转所选坐标轴的方向。

    • 坐标轴缩放（Axis Scale）：缩放所选坐标轴上的数值并相应调整标签。默认为 1.0。

    • 坐标轴原点（Axis Origin）：更改所选坐标轴的原点，并将标签改为相对于该新值的形式。默认为 0。

    • 背景颜色（Background Color）：设置窗口背景颜色。

    • 数值颜色（Value Color）：指定所绘表面的配色方案。

    • 柱条颜色（Bar Color）：指定所绘柱条（如果可见）是按数值颜色（按数值颜色（value color）中所指定）着色，还是全部绘制为统一的单一颜色。后一种情况下，使用选择通用颜色（choose common）菜单项设置所需颜色。

    • 在视图中高亮坐标轴 n 的原子（Highlight Coordinate n Atoms i View）：在视图窗口中高亮并标记用于定义坐标 n（1 或 2）的原子。这些项目为开关切换。

    Trajectory 图¶

    该功能允许查看 Gaussian 轨迹计算（ADMP 或 BOMD）所得能量及其他结果的绘图。

    ADMP 轨迹计算的核动能图 所绘制的项目如下：

    • 核动能（Nuclear Kinetic Energy）

    • 电子动能（Electronic Kinetic Energy）

    • 势能（Potential Energy）

    • 总能量（Total Energy）

    • 总角（Total Angular）

    • 动量（Momentum）

    • Alpha 电子数守恒（Conservation of Alpha Electrons）

    • 平均 Alpha 幂等性（Average Alpha Idempotency）

    • RMS Alpha 幂等性（RMS Alpha Idempotency）

    • Beta 电子数守恒（Conservation of Beta Electrons）

    • 平均 Beta 幂等性（Average Beta Idempotency）

    • RMS Beta 幂等性（RMS Beta Idempotency）

    后三项仅适用于开壳层计算。

    关于该功能的更多信息见使用绘图（Working with Plots）。

    使用 Plot 属性自定义绘图与光谱¶

    从 Plot 菜单或绘图/光谱的右键菜单中选择属性（Properties）项时，会出现 Plot 属性（Plot Properties）窗口。该对话框可用于自定义绘图或光谱的许多方面。它有四个面板，如下图所示：

    自定义 Plot（左）或 Spectrum（右）

    Plot 面板¶

    该面板中各控件的作用如下：

    • 单位（Units）：指定相应坐标轴的单位。还可通过从弹出菜单中选择缩放依据（Scale by）并在文本框中输入数值来缩放坐标（见上图 Y 轴）。

    • 原点（Origin）：指定相应坐标轴的原点值。

    • 当前（Current）按钮：使当前选中点的坐标用作相应坐标轴的原点。

    • 反转坐标轴（Invert Axis）：垂直（Y 轴）或水平（X 轴）反转图形。

    光谱版本的窗口中可能还会出现其他字段，例如缩放频率？（Scale Frequencies?）和 IR 峰半宽高（IR Peak Half-Width Height）选项。

    标题（Title）面板¶

    自定义标题 该面板中各控件的作用如下：

    • 标题（Title）：更改绘图图形的标题。

    • 标题颜色（Title Color）：调整标题的颜色。

    • 字体（Font）：更改标题的字体。

    • X 轴标题、Y 轴标题（X-Axis Title, Y-Axis Title）：分别编辑 X 轴或 Y 轴的标题。可以包含特殊字符，以 HTML 实体形式表示（例如上图 IR 光谱的 Y 轴标题），也可使用 和 标签分别表示下标和上标。

    • 坐标轴标题颜色（Axis Title Color）：调整两个坐标轴标题的颜色。

    光谱版本的窗口中可能还会出现其他字段：例如上图的 Y2 轴标题（Y2-Axis Title）选项。

    外观（Appearance）面板¶

    自定义 Plot（左）/Spectrum（右）外观 该面板中各控件的作用如下：

    • 曲线（Curve）：允许调整曲线的颜色并编辑线宽。还可通过取消勾选复选框来删除曲线。

    • 点（Points）：允许调整点的颜色并编辑点的大小。还可通过取消勾选复选框来删除点。

    • 标记（Marker）：该选项允许调整标记的颜色并编辑标记的大小。还可通过取消勾选复选框来删除标记。

    • 网格（Grid）：调整图上网格线的颜色。还可通过取消勾选复选框来删除网格。

    • 背景颜色（Background Color）：更改图形的背景颜色。

    • 画布颜色（Canvas Color）：调整图形的画布颜色。

    • 透明背景（Transparent Background）：该选项允许设置透明或不透明背景，但仅在打印时有效。

    数字（Numbers）面板¶

    自定义数字的外观 该面板中各控件的作用如下：

    • 数字颜色（Number Color）：调整数字的颜色。

    • 字体（Font）：更改数字的字体。

    • X 轴：最大精度（X-Axis: Max Precision）：更改 X 轴间隔。

    • Y 轴：最大精度（Y-Axis: Max Precision）：更改 Y 轴间隔。

    • 指数格式（Exponential Format）：以指数记数法显示 X 轴和 Y 轴的数字。

    光谱版本的窗口中可能还会出现其他字段，例如上图的 Y2 轴：最大精度（Y2-Axis: Max Precision）选项。

    使用绘图¶

    操作和自定义绘图¶

    可以点击图中的各个点，对应的结构即会出现在视图窗口中。

    所有绘图都可以通过多种方式进行查看操作：

    • 滚动和调整大小：通常，同一对话框中有多个绘图/光谱可用，不会同时全部可见。此时，可以调整对话框窗口大小以同时查看更多内容，或使用滚动条滚动到所需的绘图。如果同时可见多个绘图，则调整窗口大小会沿 X 轴放大/缩小，而绘图高度保持不变。换句话说，只有 viewing 区域的高度发生变化。当只可见一个绘图时——即对话框只包含一个绘图，或其他绘图已被隐藏（见下文）——调整对话框大小会沿两个坐标轴同时放大/缩小绘图。要聚焦于其中一两个绘图，可使用 Plot 菜单隐藏其他绘图。

    • 缩放和取消缩放：所有绘图都支持缩放。该功能对于分辨精细细节非常方便。要放大，点击并按住鼠标左键选择缩放区域的一个角。按住鼠标按钮的同时，将鼠标移动到所需缩放区域的对角。缩放区域将以黑色虚线标记，如下图所示。释放鼠标按钮，所选区域即被放大以充满整个区域。该视图如下方右侧图所示。可以根据需要不断放大。要取消缩放（即恢复原始视图），使用绘图右键菜单中的缩小（Zoom Out）项。

    • 平移（Panning）：在绘图内，按住 Shift 键同时拖动，可沿 X 轴或 Y 轴移动视图。与缩放结合使用时很有用，可沿绘图路径跟踪查看。

    放大绘图

    • 隐藏单个绘图/光谱：Plot 菜单的上部如下图所示，列出所有当前可用项目。可通过去掉/恢复项目名前面的勾选来分别隐藏或显示列表中的单个项目（respectively）。显示所有 Plot（Show All Plots）项将始终显示（勾选）所有项目。右键菜单（见下文）中的隐藏其他 Plot（Hide Other Plots）将隐藏除当前显示项之外的所有项。该菜单中的隐藏本 Plot（Hide This Plot）项将隐藏当前显示的项。

    Plot 菜单 该菜单见于所有绘图和光谱窗口。本例来自 IRC 计算的绘图窗口。当前所有可用绘图均可见。

    该菜单还提供打印（Printing）和保存（Saving）绘图、保存绘图图片以及修改绘图属性的选项。

    修正绘图不连续性¶

    读取多几何结构绘图的数据时，X 轴上的值应形成单一连续递增集合。有时，用户可能在同一分子组中包含来自两个或更多不同文件中的分子。这有时为便于比较或为扩展之前运行的输出而使用。此时，X 轴的值不再形成单一连续递增集合，导致所得绘图呈锯齿状外观。检测到这种情况时，会显示信息提示。

    可使用 Plot=>修正不连续性（Fix Discontinuity）菜单项修正此类绘图。使用该功能后，绘图标题中会添加“（Modified）”字样，以提醒用户绘图中的数据已被修改，应谨慎查看。

    绘图右键菜单¶

    在绘图或光谱内右击时出现左侧菜单。

    在绘图或光谱内右击，包括包含标题和坐标轴标签的灰色区域，将弹出针对该特定绘图/光谱的右键菜单。菜单中的选项一般仅适用于当前项目。右键菜单如上图所示。各项目的含义如下：

    • 显示所有 Plot（Show All Plots）和隐藏其他 Plot（Hide Other Plots）分别显示所有项目和隐藏除当前项之外的所有项。

    • 缩小（Zoom Out）恢复原始绘图外观，撤销所有缩放。撤销上次缩放（Undo Last Zoom）仅撤销最近一次缩放操作。

    • 打印（Print）打印当前绘图或光谱。

    • 保存数据（Save Data）允许将绘图或光谱数据保存为文本文件（见下文）。

    • 保存图片（Save Picture）允许将绘图或光谱保存为图形文件。

    • 属性（Properties）允许自定义绘图的许多方面。详细讨论见此处。

    添加新的参考结果¶

    GaussView 主目录下的 data 子目录包含 nmr.data，其中保存 NMR 显示的参考数据。这是普通文本文件，可用任何文本编辑软件修改。但必须注意保持现有格式。在添加或修改之前，谨慎做法是先备份该文件。

    使用手动位移显示模式¶

    手动位移（Manual Displacement）框允许设置偏离平衡几何结构的位移。勾选后，振动的动画将被关闭。勾选后，滑动条、数字框和保存结构（Save Structure）按钮变为活动状态。在此模式下，更改滑动条或相应的数字框会导致分子沿当前活动的简正模式静态位移。滑动条的中间值或文本框中的零对应无位移。向右移动滑动条或在文本框中输入正值，将使原子沿当前活动的简正模式位移。向左移动或输入负值，将使原子沿与当前活动的简正模式相反的方向位移。文本框中允许的数值范围为 -1 到 +1。点击保存结构（Save Structure）将出现新的分子窗口，其几何结构恰好对应位移后的结构。

    该工具的主要用途是帮助消除虚假的负本征值。当寻找过渡态时，最终得到含有两个（或更多）负本征值的结构并不罕见。这些虚假的负本征值一般很小，但必须消除才能分离出真正的过渡态。对于这些情况，选择与虚假负本征值对应的简正模式，然后选择手动位移（Manual Displacement）。向右调整滑动条（或在文本框中输入正数），然后选择保存结构（Save Structure）以创建具有位移几何结构的新分子，随后可对其重新优化。如果正向位移未能消除虚假负本征值，按相同步骤尝试负方向位移。还可以尝试改变位移的大小。

    手动位移的第二个用途是生成分子处于振动过程中的图片。因此，可用于将振动的动画有效地冻结在特定点。

    混合编辑器（Mixture Editor）对话框用于在绘制多个数据集时修改图形。该对话框包含两个部分：

    • 类似电子表格的列表包含每个可用数据集的控件。点击任意列标题可对列表排序。可使用 control 命令键和 shift 键选择多个数据集。所做的任何更改将应用于所有选定项。

    • 活动（Active）：数据集是否包含在图中。非活动数据不参与玻尔兹曼布居（Boltzmann Populations）计算。对于组合图，活动（Active）框控制 GaussView 确定图形缩放时是否考虑该数据。组合（Combination）数据是否存在由其绘图样式（Plot Style）（无（None）表示隐藏）控制。

    • ID：显示赋予文件的标识号。编号从 0 开始。该列可用于恢复原始顺序。

    • 分子（Molecule）：显示输出文件的名称。

    • 绘图样式（Plot Style）和画笔（Pen）字段：见下文。

    • Y 偏移（%）（Y Offset (%)）：该选项允许按指定量平移数据的 Y 轴，以百分比表示。

    操作和自定义光谱¶

    所有光谱都可以通过多种方式进行查看操作：

    • 滚动和调整大小：通常同一对话框中有多个绘图/光谱可用，不会同时全部可见。此时，可以调整对话框窗口大小以同时查看更多内容，或使用滚动条滚动到所需的光谱。如果同时可见多个光谱，则调整窗口大小会沿 X 轴放大/缩小，而绘图高度保持不变。换句话说，只有 viewing 区域的高度发生变化。当只可见一个光谱时——即对话框只包含一个光谱，或其他绘图已被隐藏（见下文）——调整对话框大小会沿两个坐标轴同时放大/缩小光谱。要聚焦于其中一两个光谱，可使用 Plot 菜单隐藏其他光谱。

    • 隐藏单个光谱：Plot 菜单的上部如下图所示，列出所有当前可用项目。可通过去掉/恢复项目名前面的勾选来分别隐藏或显示列表中的单个项目（respectively）。显示所有 Plot（Show All Plots）项将始终显示（勾选）所有项目。右键菜单（见下文）中的隐藏其他 Plot（Hide Other Plots）将隐藏除当前显示项之外的所有项。

    • 平移（Panning）：在光谱内，按住 Shift 键同时拖动，可沿 X 轴或 Y 轴移动视图。与缩放结合使用时很有用，可沿光谱路径跟踪查看。

    光谱显示的 Plot 菜单 该菜单见于所有绘图和光谱窗口。本例来自 IRC 计算的绘图窗口。当前所有可用光谱均可见。

    • 缩放和取消缩放：所有光谱都支持缩放。该功能对于分辨精细细节非常方便。要放大，点击并按住鼠标左键选择缩放区域的一个角。按住鼠标按钮的同时，将鼠标移动到所需缩放区域的对角。缩放区域将以绿色矩形标记（见图 109）。释放鼠标按钮，所选区域即被放大以充满整个区域。可以根据需要不断放大。要取消缩放（即恢复原始视图），使用绘图右键菜单中的缩小（Zoom Out）项。

    光谱右键菜单¶

    在光谱内右击时出现右侧菜单。

    右键菜单中的选项一般仅适用于当前光谱。它们的含义如下：

    • 显示所有 Plot（Show All Plots）和隐藏其他 Plot（Hide Other Plots）分别显示所有项目和隐藏除当前项之外的所有项。

    • 缩小（Zoom Out）恢复原始光谱外观，撤销所有缩放。撤销上次缩放（Undo Last Zoom）仅撤销最近一次缩放操作。

    • 打印（Print）打印当前绘图或光谱。

    • 保存数据（Save Data）允许将绘图或光谱数据保存为文本文件（见下文）。

    • 保存图片（Save Picture）允许将绘图或光谱保存为图形文件。

    • 属性（Properties）允许自定义光谱的许多方面。详细讨论见此处。

    保存光谱数据¶

    光谱的右键菜单包含保存数据（Save Data）项。该项可用于将绘图/光谱对应的数值数据保存到外部文件。以下是从 IR 光谱保存的数据示例：
