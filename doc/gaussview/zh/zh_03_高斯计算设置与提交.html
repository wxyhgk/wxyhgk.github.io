    计算设置（Calculation Setup）各面板、检查点（Checkpoint）读取、各类任务特殊设置、扫描（Scan）、提交与任务控制、执行方式

    原文件：../gview6官方说明书.md（全量单文件存档）｜图片目录：../imgs/

    操作指南：设置 Gaussian 任务¶

    本页介绍使用 GaussView 设置 Gaussian 计算的方法，仅涉及操作步骤。关于所有 Gaussian 关键词和选项的详细信息，请参阅《Gaussian 用户参考手册（Gaussian User's Reference）》。

    高斯计算设置（Gaussian Calculation Setup）窗口¶

    完成所需分子构建后，可使用 计算（Calculate）=>高斯计算设置（Gaussian Calculation Setup）菜单路径打开 高斯计算设置（Gaussian Calculation Setup）对话框，如下图所示：

    高斯计算设置（Gaussian Calculation Setup）对话框 该对话框可用于设置几乎所有类型的 Gaussian 计算，并可从 GaussView 直接提交任务。GaussView 正在生成的路径行（route section）显示在对话框顶部，并会随着您在各面板中进行选择而不断更新。

    该对话框包含以下面板：

    • 任务类型（Job Type）：在顶部弹出菜单中显示指定的任务类型，默认为单点能计算。该面板中的其余字段表示所选任务类型的常用选项。

    • 方法（Method）：该面板指定计算中所用的量子力学方法。出厂默认方法为使用 3-21G 基组的基态闭壳层 Hartree-Fock 计算，但可用 高斯设置偏好（Gaussian Setup Preferences）修改。

    • 标题（Title）：该面板包含用于 Gaussian 标题部分（用于填写任务简述）的字段，请在文本框中输入说明文字。

    • Link 0：该面板用于输入任务的 Link 0 命令。

    • 常规（General）：该面板用于选择常用的常规计算选项。

    • 初猜（Guess）：该面板包含与初始猜测相关的设置，有关这些选项的完整说明，请参阅《Gaussian 用户参考手册》中 Guess 关键词的讨论。

    • 布居（Pop）：该面板用于在 Gaussian 任务结束时选择 NBO 分析。

    • PBC：该面板用于指定 Gaussian PBC 关键词的选项。

    • 预览（Preview）：预览生成的输入文件。

    • 溶剂化（Solvation）：该面板用于指定在溶液中而非气相中进行计算。

    • 附加输入（Additional Input）面板：高斯计算设置（Gaussian Calculation Setup）对话框中的最后一个面板标为 附加输入（Add. Inp.），可用于输入计划运行的计算所需的任何附加输入节。

    面板区域下方的 附加关键词（Additional Keywords）字段用于输入所需的任何 Gaussian 关键词和/或选项。请注意，即使该选项已因面板选择而出现在路径行中，也必须在该字段中为每个选项写出完整的关键词。

    面板区域下方是 计算方案（Calculation Scheme）区域，各控件用途如下：

    • 方案（Scheme）弹出菜单：选择并应用计算方案。

    • （方案（Schemes）按钮）：打开 高斯计算方案（Gaussian Calculation Schemes）编辑器，也可通过 方案（Scheme）菜单中的 更多方案（More Schemes）进入。

    • 指派给分子组（Assign to Molecule Group）：将当前设置应用于当前分子组的所有成员。保存多个文件的方法在此说明，提交多个任务的方法在此说明。

    对话框底部的按钮作用如下：

    • 提交（Submit）：使用当前输入文件启动 Gaussian 计算，若尚未保存输入文件，系统将提示保存。

    • 快速启动（Quick Launch）：直接启动 Gaussian 任务，不再赘述（更多信息见此处）。

    • 取消（Cancel）：关闭对话框，并将所有选择恢复为默认值。

    • 编辑（Edit）：允许用外部文本编辑器直接访问输入文件；在用 GaussView 保存输入文件之前，输入文件不可编辑。

    • 保留（Retain）：关闭对话框，保留当前选择，但不创建/更新输入文件，也不提交 Gaussian 任务。

    • 默认值（Defaults）：将所有项目恢复为默认值。

    任务类型（Job Type）面板¶

    任务类型（Job Type）面板如下所示。

    任务类型（Job Type）面板 本图示例了通过 附加关键词（Additional Keywords）字段添加选项。

    顶部下拉菜单选择任务类型，默认为单点能计算。面板中的其余字段表示所选任务类型的常用选项。

    可用的任务类型有：

    • 能量（Energy）：执行单点能计算。

    • 优化（Optimization）：执行几何优化，直至找到势能面上的驻点。更多信息……

    • 频率（Frequency）：计算振动（vibration）频率和强度。更多信息……

    • 优化+频率（Opt+Freq）：先执行几何优化，再进行频率分析。

    • IRC：通过积分内禀反应坐标跟踪反应路径。更多信息……

    • 扫描（Scan）：执行势能面扫描。更多信息……

    • 稳定性（Stability）：测试 Hartree-Fock 或 DFT 波函数的稳定性。更多信息……

    • NMR：预测 NMR 屏蔽张量和磁化率。更多信息……

    • 空白（blank）：若要选择弹出菜单中未列出的任务类型，请选择列表底部的空白菜单项，然后在对话框下部的 附加关键词（Additional Keywords）字段中输入相应的 Gaussian 关键词。

    您也可以使用 附加关键词（Additional Keywords）字段添加所需的任何 Gaussian 关键词和/或选项。GaussView 会将同一关键词的所有选项合并到生成的路径行中。请注意，即使该关键词已出现在路径行中，在此字段中出现任何选项时也必须写出完整的关键词。例如，在上图所示对话框中，我们为 IRC 关键词添加了 Phase 选项，而其他选项则由各弹出菜单和复选框选择生成。

    附加关键词（Additional Keywords）字段仅用于向路径行添加关键词，若要创建复杂的输入文件，请使用 编辑（Edit）按钮。

    方法（Method）面板¶

    方法（Method）面板指定计算中所用的量子力学方法。默认方法为使用 3-21G 基组的基态闭壳层 Hartree-Fock 计算。该面板如下图所示。

    方法（Method）面板 方法（Method）行中的字段指定以下项目：

    • 计算针对基态（默认）还是激发态，若为后者，则应选择所需的激发态方法。

    • 理论方法。对于某些选择，还会出现第四个字段，用于选择给定类型的具体方法。例如，在上图中，方法字段设为 DFT，第四个字段选择 B3LYP 泛函。

    • 波函数类型（闭壳层与开壳层），默认为未指定类型。限制性（Restricted）、非限制性（Unrestricted）和限制性开壳层（Restricted-Open）选项分别在方法关键词前添加 R、U 和 RO 前缀。

    左侧第二个菜单（即理论方法菜单）中的 自定义（Custom）项可用于指定菜单中没有的方法，请在出现的文本区中填写所需的方法关键词。

    基组（Basis Set）菜单用于选择计算中所用的基组，可使用该行中相应的菜单为基组添加极化函数和弥散函数。若要选择无法通过本区控件构造的基组，请选择基组菜单底部的 自定义（Custom）项，可在名称字段中输入任何基组关键词。

    输入自定义基组关键词 电荷（Charge）和自旋（Spin）字段指定分子的电荷和自旋多重度，GaussView 会根据分子结构为这些字段选择数值，可根据需要修改。

    经验色散（Empirical dispersion）弹出菜单用于指定是否在 DFT 计算中包含经验色散。

    若定义（If defined）选项将使用所选泛函可用的色散处理，也可通过菜单选项选择特定的色散方案，最后，无（None）选项将不使用经验色散。

    高斯计算设置（Gaussian Calc. Setup）选项对应的 G16 关键词列表见此处。

    标题（Title）面板¶

    标题（Title）面板包含用于 Gaussian 标题部分（用于填写任务简述）的字段，请在文本框中输入说明文字。

    Link 0 面板¶

    Link 0 面板用于输入任务的 Link 0 命令，包含三个子面板。

    Link 0 面板 该面板指定检查点（checkpoint）文件名、旧检查点文件和读写文件、任务使用的内存量、共享内存处理器数和/或 Linda 工作节点位置。

    选项（Options）子面板¶

    可在 选项（Options）子面板中通过控件指定各种设置，各弹出菜单项含义如下（默认选项标有 *）：

    项目 Link 0 命令 选项 内存限制（Memory Limit） %Mem

    • 不使用（Don't use）：不在输入文件中包含 %Mem。
    • 数值（value）：使用所选数值（单位为 megawords）。
    • 指定（Specify）：使用指定数值和单位（见上例）。

    共享处理器（Shared Processors） %NProcShared

    • 不使用（Don't use）：不在输入文件中包含 %NProcShared。
    • 数值（value）：使用所选处理器数。
    • 指定（Specify）：使用文本字段中指定的数值。

    检查点文件（Chkpoint File） %Chk

    • 默认名（Default name）：包含 %Chk，文件名由输入文件名派生。
    • 指定（Specify）：使用输入字段中指定的名称，可用 ... 按钮浏览选择文件。
    • 不保存（Don't save）：不在输入文件中包含 %Chk，见下注。

    旧检查点文件（OldChk File） %OldChk

    • 否（No）：不在输入文件中包含 %OldChk。
    • 默认名（Default name）：包含 %OldChk，名称由输入文件名派生。
    • 指定（Specify）：使用输入字段中指定的名称，可用 ... 按钮浏览选择文件。

    读写文件（Read-write File） %RW

    • 不保存（Don't save）：不在输入文件中包含 %RWF。
    • 默认名（Default name）：包含 %RWF，名称由输入文件名派生。
    • 指定（Specify）：使用输入字段中指定的名称，可用 ... 按钮浏览选择文件。

    Linda 工作节点（Linda Workers） %LindaWorkers

    • 不使用（Don't use）：不在输入文件中包含 %LindaWorkers。
    • 指定（Specify）：使用文本字段中指定的数值。

    终止任务（Kill Job） %KJob

    否（No）：正常运行任务。Lnnn：在指定 Link 完成后停止。指定（Specify）：在文本字段中输入所需的 Link。

    注：若删除检查点文件的位置和名称设置，将无法自动可视化该任务的输出。

    完整路径（Full Path）复选框控制在 %Chk 或 %OldChk Link 0 命令中填入绝对路径（选中）还是相对路径（未选中）。但即使选中该框，完整路径也不会显示在 编辑（Edit）子面板中。... 按钮可通过浏览选择具体文件。

    常规（General）面板¶

    常规（General）面板用于选择常用的常规计算选项，如下图所示：

    高斯计算设置常规选项（Gaussian Calculation Setup General Options）面板 该面板包含一组常用选项，下表列出各复选框对应的 Gaussian 关键词：

    选项 默认值 关键词
    使用二次收敛 SCF 关（Off） SCF=QC
    使用修正冗余坐标 开（On） Geom=ModRedundant
    忽略对称性 关（Off） NoSymm
    使用 Counterpoise 关（Off） Counterpoise
    写出笛卡尔坐标 开（On） 写出笛卡尔坐标（关=Z-矩阵坐标）
    附加输出 关（Off） #P
    写出连接性 开（On） Geom=Connectivity
    写出 PDB 数据 开（On） ResNum、ResName、PDBName（在分子说明中）
    写出 Gaussian 片段数据 开（On） Fragment（在分子说明中）
    使用 MaxDisk 关（Off） MaxDisk=数值
    计算极化率 关（Off） Polar
    计算旋光 关（Off） Polar=OptRot
    读取入射光频率 否（No） CPHF=RdFreq

    仅当已用冗余坐标编辑器创建冗余坐标时，使用修正冗余坐标（Use Modified Redundant Coordinates）项才启用，否则即使为默认值也会被忽略。写出 Gaussian 片段数据（Write Gaussian Fragment Data）和 写出 PDB 数据（Write PDB Data）默认启用，但除非定义了相应项目，否则不起作用。

    写出连接性（Write Connectivity）选项还会在 Gaussian 输入文件中包含相应的附加输入节。

    若取消选中 写出笛卡尔坐标（Write Cartesians），则输入文件中将写入 Z-矩阵而非笛卡尔坐标。

    注：对于异常/疑难情形，请参阅《Gaussian 用户参考手册》中 SCF 关键词的讨论以获取建议（SCF=QC 并非总是最佳的下一步选择）。

    初猜（Guess）面板¶

    初猜（Guess）面板包含与初始猜测相关的设置，如下图所示，有关这些选项的完整说明，请参阅《Gaussian 用户参考手册》中 Guess 关键词的讨论。

    初猜方法（Guess Method）弹出菜单指定初始猜测的类型，有以下选项：

    • 默认（Default）：使用默认的 Harris 初始猜测。

    • 核哈密顿（Core Hamiltonian）：使用 Gaussian 98 默认初始猜测（Guess=INDO）。一般不建议使用，除非 Gaussian, Inc. 技术支持人员建议。

    • 扩展 Huckel 法（Extended Huckel）：使用 Huckel 猜测（Guess=Huckel）。

    • 读取检查点文件（Read checkpoint file）：从检查点文件中读取初始猜测（Guess=Read）。

    • 若可能则读取检查点，否则生成（Read checkpoint if possible; otherwise generate）：检查检查点文件中的初始猜测，若不存在则生成（Guess=TCheck）。

    • 读取输入检查点文件（Read input checkpoint file）：从输入流中指定名称的检查点文件中读取猜测（Guess=Input）。

    Gaussian 初始猜测选项 该面板中复选框含义如下：

    | 选项 | 默认值 | 关键词 |

    布居（Population）面板¶

    布居（Population）面板 布居（Population）面板用于指定布居分析的参数（对应 Population 关键词的选项）。

    输出级别（Level of Output）：控制输出的详细程度，下拉菜单包括 默认（Default）（仅打印总原子电荷和轨道能）、完全（Full）（与常规布居分析相同，但打印所有轨道）、常规（Regular）（打印最高的五个占据轨道和最低的五个空轨道，以及密度矩阵和完整的（逐轨道、逐原子）Mulliken 布居分析）、最小（Minimal）（打印总原子电荷和轨道能）和无（None）（不打印轨道，不做布居分析）。

    在每个几何结构处（At every geometry）：选中时，将在几何优化的每一步都做布居分析，而默认仅在第一步和最后一步进行。

    Merz-Kollman（ESP）电荷、Hirshfeld（CM5）电荷和自然跃迁轨道（NTOs）复选框用于请求这些静电势衍生电荷。

    双正交化轨道（Biorthogonalize orbitals）按钮用于指定计算运行时对轨道做双正交化。

    执行 NBO 计算（Perform NBO calc）

    • 无 NBO（No NBO）：不执行 NBO 计算，为默认选项。

    • 完整 NBO（Full NBO）：请求完整的自然键轨道分析。

    • 仅 NPA（NPA only）：仅请求 NBO 的自然布居分析阶段。

    • 完整 NBO（使用 NBO 6）、仅 NPA（使用 NBO 6）（Full NBO (use NBO 6), NPA only (use NBO 6)）：与上述选项相同，但通过外部接口使用独立的 NBO6 程序。

    • 完整 NBO（使用 NBO 7）、仅 NPA（使用 NBO 7）（Full NBO (use NBO 7), NPA only (use NBO 7)）：与上述选项相同，但通过外部接口使用独立的 NBO7 程序。

    保存轨道到检查点文件（Save orbitals to chk file）：该节用于选择保存到检查点文件的轨道，保存 Mulliken（Save Mulliken）、保存 ESP（Save ESP）、保存 NPA（Save NPA）和保存 Hirshfeld (CM5)（Save Hirshfeld (CM5)）选项可用于保存相应的电荷。

    • 不保存（保留正则轨道）（Don't save (keep canonical orbitals)）：不向检查点文件保存任何轨道，为默认选项。

    • 保存 NLMOs（Save NLMOs）：保存自然定域分子轨道。

    • 保存 NBOs（Save NBOs）：保存自然键轨道。

    • 保存 NLMOs 与 NBOs 的混合（Save Mixture of NLMOs and NBOs）：占据轨道保存 NBOs，空轨道保存 NLMOs。

    • 保存 NTOs（Save NTOs）：将生成的轨道保存在检查点文件中，若密度从该处读入，则替换正则轨道。

    • 保存双正交化轨道（Save Biorthogonalized orbitals）：将双正交化轨道保存在检查点文件中，覆盖正则 MOs。

    保存电荷以供后续 MM 使用（Save charges for later MM）：该菜单提供保存电荷以供后续分子力学计算的选项。

    • 默认（Default）：post-SCF 方法用 Hartree-Fock 密度，DFT 任务用 DFT 密度，CAS 任务用 CASSCF 密度。

    • 当前（Current）：使用当前方法的密度矩阵。

    • 所有跃迁（All Transitions）：使用所有可用的 CIS 跃迁密度。

    • CI：使用对应 CI 能量的广义密度。

    • QCI/CC：使用对应耦合簇/QCI 能量的广义密度。

    各类 Gaussian 任务类型的特殊注意事项¶

    本节总结设置各类需要特殊步骤的 Gaussian 任务类型的信息。

    过渡态优化：Opt=QST2 和 Opt=QST3¶

    基于 Gaussian STQN 的过渡态优化需要两个或三个结构作为输入。要设置这类任务，必须创建包含所需数量结构的分子组。完成后，任务（Job）面板中优化任务类型的 优化到（Optimize to a）字段将启用 TS (QST2) 和 TS (QST3) 选项。

    若计划运行 Opt=QST3 任务，除非在 任务类型（Job Type）面板上指定了不同结构，否则过渡态初猜默认为分子 3。

    验证并指定原子对应关系：在多数情况下，GaussView 会自动识别这些过渡态优化中多个结构的对应原子，但可用工具栏上的 连接编辑器（Connection Editor）按钮或 工具（Tools）=>连接编辑器（Connection Editor）菜单项打开连接编辑器进行验证，连接编辑器详情见此处。

    警告：用于这两种任务类型的各分子中的原子必须完全相同，若 GaussView 检测到任何顺序差异，优化到（Optimize to a）下拉菜单中的该选项将被禁用。

    聚合物、表面（surface）和晶体的计算¶

    可用晶体编辑器（通过 晶体编辑器（Crystal Editor）按钮或 工具（Tools）=>PBC 菜单路径进入）为 Gaussian 周期性边界条件功能设置任务。定义单胞后，GaussView 会将平移矢量包含在分子说明中，从而自动为该结构设置 PBC 任务，高斯计算设置（Gaussian Calculation Setup）对话框中 PBC 面板启用且 使用 PBC（Use PBC）项被选中即表明如此。注意，正常情况下无需访问该面板，可直接按常规方式设置 Gaussian 输入。

    多层 ONIOM 计算¶

    GaussView 包含多项用于设置 ONIOM 计算的功能。

    • 向各层指派原子：层编辑器允许以图形方式将原子指派到各 ONIOM 层，可通过工具栏的 选择层（Select Layer）按钮或 工具（Tools）=>选择层（Select Layer）菜单项进入。

    • 指派分子力学原子类型：GaussView 会自动为分子中所有原子指派 UFF、Dreiding 和 Amber（含 Amber 电荷）的分子力学原子类型，可用原子列表编辑器（通过工具栏上的 原子列表编辑器（Atom List Editor）按钮或 工具（Tools）=>原子列表（Atom List）菜单路径进入）查看和修改。

    • 定义连接原子：GaussView 会自动为 ONIOM 计算中的相应原子指派最小的连接原子信息，但所有连接原子始终以相同方式处理，可能需要根据需要修改。GaussView 生成的连接原子始终为氢（使用 H_ UFF 和 Dreiding 原子类型及 HR Amber 原子类型，其中 R 为所连接原子的元素），唯一包含的其他连接原子参数是所连接的原子（即当前原子所键连的高层原子），其余参数均留空。原子列表编辑器通常是检查和修改 ONIOM 计算连接原子的便捷方式，可用 ONIOM 层（ONIOM Layers）按钮轻松查看和修改连接原子。

    • 指定每层的模型化学：在准备好结构并指定所有必要参数后，可通过 高斯计算设置（Gaussian Calculation Setup）对话框的 方法（Method）面板设置 ONIOM 计算，多层 ONIOM 模型（Multilayer ONIOM Model）复选框表示这将是一个 ONIOM 计算。

    使用 Guess=Permute 指定 CASSCF 活性空间¶

    GaussView 可方便地指定 CASSCF 活性空间，MOs 对话框允许生成、查看、选择和重排起始轨道，可通过 工具（Tools）=>MOs 菜单路径及工具栏上的 MO 编辑器（MO Editor）按钮进入，更多详情见此处。

    修改冗余内坐标（Geom=ModRedundant）¶

    可用冗余坐标编辑器（通过工具栏上的 冗余坐标编辑器（Redundant Coordinate Editor）按钮或 编辑（Edit）=>冗余坐标（Redundant Coordinates）菜单路径进入）为几何优化及其他任务指定冗余内坐标的添加和其他修改。

    几何优化中冻结原子¶

    原子组编辑器可用于通过其 冻结原子（Freeze Atoms）组类指定在几何优化中保持固定的原子，该组类默认定义了四个组，分别对应未冻结原子、冻结原子及前两个 ONIOM 冻结刚性块（冻结设置为 -2 和 -3，有关冻结原子和 ONIOM 刚性块指定的完整说明，请参阅《Gaussian 用户参考手册》中 Geom 关键词的讨论）。若要在几何优化中固定特定原子，请将其加入 冻结（是）（Freeze (Yes)）组。

    为频率计算选择简正模式（Freq=SelectNormalModes）¶

    可用原子组编辑器选择进行简正模式分析的原子（详情见《Gaussian 用户参考手册》）。将所需原子放入 选择简正模式（是）（Select Normal Modes (Yes)）组，将使其填入高斯计算设置（Gaussian Calculation Setup）任务类型（Job Type）面板中频率任务对应的 原子（Atoms）字段，可根据需要手动修改该列表，但这样做不会影响原子组编辑器 选择简正模式（Select Normal Modes）组类中组的定义。

    设置扫描（Scan）计算¶

    刚性扫描和弛豫扫描需要不同的步骤。

    弛豫扫描¶

    设置弛豫扫描计算时，首先必须在冗余坐标编辑器中指定要扫描的坐标。

    本例中，我们将扫描两个苯环之间绕键旋转的二面角，初始键角为 90 度，希望以每步 10 度扫描 9 步。首先单击 添加（Add）按钮，再从下拉菜单选择 二面角（Dihedral），将第二个下拉菜单改为 扫描坐标（Scan Coordinate）。然后在视图窗口（view window）中单击要扫描的二面角，冗余坐标编辑器对话框中的 坐标（Coordinate:）字段将填入所选原子，还会出现两个新的输入字段，用于指定扫描步数和每步步长。本例中，我们填写 9 步、每步 10 度。

    用冗余坐标编辑器添加扫描变量

    打开 高斯计算设置（Gaussian Calculation Setup）的 任务类型（Job Type）面板时，扫描、弛豫（冗余坐标）（Scan, Relaxed (Redundant Coord)）已填好，表示计算将按冗余坐标编辑器中指定的设置运行。在下图所示 高斯计算设置（Gaussian Calculation Setup）的 预览（Preview）面板中，可在输入末尾看到冗余坐标编辑器创建的输入。

    刚性扫描¶

    要设置刚性扫描计算，我们用原子列表编辑器确定要扫描的结构参数。本例中，打开原子列表编辑器，然后单击 Z 和 O 按钮以显示 Z-矩阵和优化标志列。我们要扫描 C2-C3-C12-C13 二面角，它位于表格第 13 行，将该行 Opt 3 列中的 Yes 改为 Rxn/Scan。

    用原子列表编辑器为刚性扫描添加扫描变量

    关闭原子列表编辑器，然后打开 高斯计算设置（Gaussian Calculation Setup）的 任务类型（Job Type）面板，选择 扫描（Scan），扫描类型选 刚性（Rigid）。扫描坐标 1（Scan Coordinate 1）子面板显示扫描坐标，可在此指定步数、步长和/或终值，改变任一数值都会使其他框自动更新。例如，通过改变步数和期望终值，GaussView 会自动计算步长。本例中，我们指定了 9 步、每步 10 度，右侧 预览（Preview）面板对话框显示了包含在分子说明中的扫描输入。

    刚性扫描的输入设置 计算 NMR 自旋-自旋耦合：NMR=(SpinSpin,ReadAtoms)

    在 高斯计算设置（Gaussian Calculation Setup）的 任务类型（Job Type）面板中选择 NMR 计算时，会出现计算自旋-自旋耦合（compute spin-spin couplings）弹出菜单。当选择任一 yes 选项时，右侧括号中的原子列表对应原子组编辑器中定义的 NMR 自旋-自旋（是）（NMR Spin-Spin (Yes)）组的成员。默认所有原子都在该组中，原子列表显示为 all atoms；当 NMR 自旋-自旋（否）（NMR Spin-Spin (No)）组中至少含有一个原子时，此处显示特定的原子组。

    指定片段特定的电荷和自旋多重度¶

    可为通过原子组编辑器定义的每个片段指定各自的电荷和自旋多重度，该功能适用于设置片段初猜任务（Guess=Fragment）以模拟反铁磁耦合、Counterpoise 计算（Counterpoise）以计算 Counterpoise 校正和基组重叠误差等。下图示例了为模拟反铁磁耦合设置体系。

    指定每个片段的电荷和自旋 反铁磁耦合是对高自旋多重度分子很重要的效应，该 Fe2Cl6 化合物是一个简单例子。这里，我们定义了三个片段，每个铁原子各为一个片段，六个氯原子为第三个片段。两个铁片段各指派 +3 电荷，均定义为六重态但自旋相反（即自旋多重度分别为 6 和 -6），含氯原子的片段定义为单重态、电荷为 -6。这些数值将放入 GaussView 设置的 Gaussian 任务的路径行中。

    高斯计算设置（Gaussian Calculation Setup）的 常规（General）面板包含与这两类计算相关的功能：写出 Gaussian 片段数据（Write Gaussian Fragment Data）（两类均用）和 使用 Counterpoise（Use Counterpoise）（Counterpoise 计算用）。此外，初猜（Guess）面板有两个适用于片段初猜任务第一步的项目：仅做初猜（无 SCF）（Only do Guess (no SCF)）和 使用片段（原子组）生成初猜（Use fragments (atom groups) for generating guess），分别对应 Guess=Only 和 Guess=Fragment。通常，此类任务之后会接第二个任务，用 Guess=Read Geom=AllCheck Stable=Opt 计算包含反铁磁耦合的能量。

    设置激发态计算¶

    在方法节的第一个选择菜单中，可看到表示电子态的各种选项，第一项为基态（Ground State），其余选项均为激发态。

    从方法节选择电子态 选择任一激发态选项后，将出现 态（States）菜单，可用于指定求解哪些态，还会出现 求解更多态（Solve for More States）和 感兴趣的态（State of Interest）选项，求解更多态（Solve for More States）可选择求解的态数，感兴趣的态（State of Interest）可选择预测性质所针对的态。此外需注意，激发态 ZINDO 不使用基组（Basis Set）字段。

    快速启动（Quick Launch）功能¶

    快速启动（Quick Launch）功能极大简化了 Gaussian 计算的运行。可用 快速启动（Quick Launch）工具栏按钮、高斯计算设置（Gaussian Calculation Setup）对话框中的 快速启动（Quick Launch）按钮或 计算（Calculate）=>高斯快速启动（Gaussian Quick Launch）菜单路径启动任务。单击 高斯计算设置（Gaussian Calculation Setup）对话框中的按钮，或工具栏图标中小箭头左侧部分，将使用当前计算方案和临时文件立即启动 Gaussian 任务。

    工具栏图标箭头和 计算（Calculate）菜单项都会引出子菜单，其 临时文件（Temp File）项也会从临时输入文件启动任务，保存文件（Save File）选项将提示保存输入文件并随后将该文件作为 Gaussian 任务提交，保存并编辑文件（Save and Edit File）选项将提示保存输入文件然后在外部编辑器中打开该文件，当前输入文件（Current Input File）菜单项将使用当前打开的输入文件中的数据运行计算。

    用 快速启动（Quick Launch）开始新计算时，会打开与之对应的新视图窗口（view window）。任务运行时，视图窗口的状态栏中会放置标识该任务的文本消息、停止按钮和流式输出文件按钮。任务成功完成后，结果文件会自动打开。当一次计算产生多个结果文件（例如同时生成日志文件和检查点文件）时，系统将提示选择要打开的文件。

    可用 文件（File）=>保存临时文件（Save Temp Files）菜单项保存 快速启动（Quick Launch）操作生成的临时文件，该项在此情况下取代通常的 相关文件（Related Files）选项。

    计算（Calculate）=>当前任务（Current Jobs）菜单路径打开如下所示的任务管理器（Job Manager）对话框，工具栏上的 当前任务（Current Jobs）按钮功能相同：。注意 GaussView 6 还包含更强大的计算管理工具：SC 任务管理器（SC Job Manager）。

    该窗口显示 GaussView 启动的所有当前运行任务，注意仅显示当前 GaussView 会话期间启动的任务。可能显示的任务示例包括从 Gaussian 对话框提交的 Gaussian 任务、从 GaussView 启动的 Gaussian 输入文件编辑会话、为显示而构建表面（surface）的 CubeGen 进程、生成振动（vibration）分析数据的 FreqChk 进程和/或其他 Gaussian 工具的进程。

    当前任务（Current Jobs）对话框 该对话框允许查看和控制 Gaussian 任务以及 CubeGen 等运行 Gaussian 工具的任务，可用 终止（Kill）按钮终止任务。

    单击 任务日志（Jobs Log）按钮显示当前 GaussView 任务日志，其中包含与 GaussView 外部进程执行相关的系统消息。生成窗口中的 清除（Clear）按钮从任务列表删除旧任务，关闭（Close）按钮关闭任务列表窗口。

    注意 任务日志（Jobs Log）按钮不显示运行中 Gaussian 任务相关的日志文件，后者通过 Gaussian 计算的 流式输出文件（Stream Output File）按钮实现，也可通过 结果（Results）=>流式输出文件（Stream Output File）菜单路径访问。对某些任务类型（例如 cube 生成任务）选择该按钮时，将显示 GaussView 能找到的与该任务相关的文件（通常为 Gaussian 输入文件）。

    定义计算方案¶

    方案是命名的计算关键词和选项集合，可定义并保存任意多个。可在 高斯计算设置（Gaussian Calculation Setup）对话框底部的计算方案、工具栏中的方案弹出菜单以及 计算（Calculate）=>高斯计算方案（Gaussian Calculation Scheme）子菜单中查看生效的计算方案，也可用这些控件将方案应用于当前分子。

    从文件打开新分子时，方案将设为与其设置匹配的方案（若有），否则为 未命名方案（Unnamed Scheme）。

    对于新分子，初始应用 默认（Default）方案。如前所述修改 高斯设置（Gaussian Setup）偏好，其效果是修改名为 默认（Default）的 Gaussian 计算方案，不过该方案也可在本对话框中编辑。

    可用 方案（Schemes）按钮或从任一方案列表选择 更多方案（More Schemes）查看和修改各已定义方案的属性，生成的对话框如下所示：

    查看和修改计算方案 该对话框显示组织为两组的四个方案，本对话框中的可编辑字段如下：

    • 名称（Name）：方案名，将出现在 方案（Schemes）菜单中。

    • 关键词（Keywords）：Gaussian 任务的关键词节。

    • Link 0：Gaussian 任务的 Link 0 节，多行之间用空格分隔。

    • 标题（Title）：任务标题。

    • 附加输入（Additional Input）：任务的附加输入节，上例中 ORD 方案包含 CPHF=RdFreq 选项的入射光频率。编辑该单元格时，会打开另一个更大的窗口以允许多行输入。

    方案中的任一字段都可通过单击编辑。注意 默认（Default）方案和 Main 组均不可重命名或删除。

    右键单击方案会生成上下文菜单：

    计算方案上下文菜单 该菜单项含义如下：

    • 新建组（New Group）：添加新的方案组。

    • 新建方案（New Scheme）：向当前方案组添加新方案。

    • 打开文件（Open File）：打开以前保存的方案组。

    • 保存文件（Save File）：将当前方案组保存在所选位置。

    • 编辑单元格（Edit Cell）：允许文本编辑方案组中当前选中的单元格。

    • 剪切、复制、粘贴、删除（Cut, Copy, Paste, Delete）：简单文本编辑，与其他文字处理软件功能相同。

    • 字体、文本颜色、背景颜色（Font, Text Color, Background Color）：允许更改方案组的字体、文本颜色和背景颜色。

    • 显示网格（Show Grid）：在方案组中显示网格。

    分子组表（Molecule Group Table）¶

    分子组表（Molecule Group Table）对话框用于查看和编辑已打开分子的信息，适用于创建结果表：

    分子组表（Molecule Group Table）对话框 该窗口允许用户按多种条件排列组中分子，还允许对单个分子做 3D 导航。单击列标题可排序表格。

    选项（Options）下拉菜单默认包含以下选项：

    • 约束行高相等（Constrain Row Heights to be Equal）：启用时，该选项使所有行高度相等。

    • 显示名称列（Show Name Column）：启用时，表中显示项目的名称，名称可编辑，默认为文件名。

    • 显示 3D 视图列（Show 3D View Column）：启用时，表中显示分子的 3D 视图。

    • 显示来源列（Show Source Column）：启用时，表中显示文件的来源。

    • 显示符号列（Show Symbol Column）：启用时，包含用于输入符号文本的列。

    • 显示注释列（Show Comments Column）：启用时，显示用于输入注释的列。

    复制（Copy）下拉菜单（如上例对话框所示）允许在单元格与行之间复制数据，有以下选项：
