    过渡态构象¶

    在成功用 NEB-TS 搜索到过渡态之后，我们应当通过 GOAT 的全自动构象搜索来考察其构象柔性。 这一点很重要，因为过渡态的构象会显著影响所得的反应势垒。由于相邻取代基和配体之间的空间拥挤，过渡态往往比反应物和产物的极小点结构受影响更大。

    图：反应物、过渡态和产物构象空间的示意图。

    默认情况下，GOAT 会搜索弛豫的全局极小结构及相应构象。对于过渡态构象搜索，我们通常希望固定直接参与化学转化的原子。 为此，可以使用 ORCA 中的约束功能来修改 GOAT 流程。

    !XTB GOAT

%GEOM 
 Constraints
  {C 0 C}         # Constrain Cartesian coordinate of atom 0 
  {B 0 1 C}       # Constrain bond of atoms 0 and 1
  {A 0 1 2 C }    # Constrain angle between atoms 0, 1, and 2
  {D 0 1 2 3 C }  # Constrain dihedral angle between atoms 0, 1, 2, and 3
 END
END

*XYZFILE 0 1 ts.xyz

    警告 请注意，ORCA 的原子编号从 0 开始！因此，XYZ 文件中的第一个原子是原子 0。

    该反应的过渡态是用 NEB-TS 流程在 GFN2-xTB 方法下找到并优化的。在本例中，参与反应的重要原子是中心的钼原子以及原卡宾配体和进攻烯烃上相邻的碳原子。我们也可以把烯烃的 \(\beta\)-碳原子包括进来，但在本例中约束三个原子就足够了。现在我们通过 ORCA 输入文件设置约束：
    

    !XTB GOAT

%PAL 
 NPROCS 16 
END

%GEOM 
 Constraints
  { C 0 C }
  { C 1 C }
  { C 2 C }
 END
END

*XYZFILE 0 1 ts.xyz

    

    

    注意
请注意，我们将处理核心数增加到 16，以充分利用 GOAT 方法的高度并行性。对大型柔性分子进行构象搜索可能非常耗时。因此，建议将 GFN2-xTB 等快速半经验方法与更多核心数组合使用。
    

    

    现在我们对 Mo0、C1 和 C2 这三个原子的笛卡尔坐标加以约束，运行 GOAT 构象搜索。GOAT 运行成功后，将给出一份生成构象的列表，按相对于新找到的全局极小结构的能量递增顺序排列。

    重要
由于我们在 GOAT 运行中使用了约束，生成的构象并不是完全优化的过渡态结构！无论如何，它们最终都应使用 OptTS 关键词进行优化。这也会影响能量排序。一般而言，构象系综随后还应使用更精确的 DFT 或 WFT 方法进行精修，以获得更可靠的结果。
    

    

    现在我们可以可视化存储在 basename.finalensemble.xyz 文件中的一部分生成构象，可以看到在 GOAT 运行期间被约束的原子被完美地保持在原位。
    

    

    图：a) 所选构象的叠加。b) 所选构象的结构及其相对能量（\(\mathrm{kcal \cdot mol}^{-1}\)）。
    

    如果将 GOAT 运行中尚未优化的过渡态构象能量与输入的过渡态能量进行比较，可以看到新的全局极小结构即使在没有进一步优化的情况下，能量也低了 \(6.44 \ \mathrm{kcal \cdot mol}^{-1}\)！相应的绝对能量可以在 basename.xyz（起始结构）和 basename.globalminimum.xyz 文件的第二行中找到。
