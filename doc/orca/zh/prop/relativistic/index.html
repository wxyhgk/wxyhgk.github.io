    相对论校正¶

    在计算含有重元素（第四周期及更重）体系的性质或几何结构时，相对论效应（relativistic effects）可能产生很大影响，不应被忽略。 甚至有研究表明，对某些第三周期元素而言，相对论效应也可能变得显著。

    目前，ORCA 中有四种方法可用于包含相对论效应

    1. 有效核心势（Effective Core Potentials, ECPs）
    2. 零阶正则近似（Zeroth-Order Regular Approximation, ZORA，[Baerends1996]）
    3. 一阶和二阶 Douglas-Kroll-Hess（DKH，[Kroll1974] [Hess1985]）哈密顿量
    4. 精确二分量方法（exact two component treatment, X2C）的无自旋变体（[Weigend2013]）

    它们在原理上有所不同，各具优势——因此应仔细考察计算结果——但其中应用最广泛的或许是 ZORA 及其变体。

    有效核心势（ECPs）¶

    赝势（pseudopotentials）或有效核心势是处理相对论效应一种非常便捷高效的方式。它们用有效势替换核心电子，并可通过参数化来涵盖相对论效应。ECP 的另一个好处是减少了需要显式处理的电子数，从而缩短计算时间。最著名且最稳健的 ECP 系列之一是 Dolg 及其合作者提出的 def2-ECPs。[Dolg2000] 它们通常与 Ahlrichs 的匹配 def2 基组配合使用。[Ahlrichs2005] 在 ORCA 中，只要请求了相应的基组，就会自动使用这些 ECP。例如，如果对 Hg 原子使用 def2-TZVP 基组，输出中会标明使用了相应的 ECP。

    1
structure
Hg 0 0 0
    !wB97X-V def2-TZVP

*XYZ 0 1 
Hg 0 0 0
*
    -------------------------
ECP PARAMETER INFORMATION
-------------------------

 Group 1, Type Hg ECP Def2-ECP (replacing 60 core electrons, lmax=3)

    ECP 还可以在 %basis 模块中单独指定

    %basis
  ECP       "def2-ECP"     # All heavy elements for which the ECP is defined
  NewECP Pt "def2-SD" end  # Different ECP for Pt
end

    这里，我们为所有重元素定义了 def2-ECP，并仅为铂替换为 def2-SD ECP。

    注意 ORCA 中提供了许多不同的 ECP 选项。然而，使用 ECP 仍然是一种近似，需要谨慎对待。Head-Gordon [Head-Gordon2023] 及其合作者最近的一项研究讨论了各种 ECP 系列及其优缺点。

    警告 在计算核性质（如 NMR 化学屏蔽张量）时，绝不应使用 ECP！

    标量相对论哈密顿量（ZORA/DKH/X2C）¶

    也可以用 ZORA、DKH 或 X2C 等标量相对论哈密顿量（scalar-relativistic Hamiltonians）对核心电子进行显式的相对论处理。只需简单的输入关键词 ZORA、 DKH 或 X2C 即可轻松调用：

    !PBE0 D4 ZORA ZORA-DEF2-TZVP

    或

    !PBE0 D4 DKH DKH-DEF2-TZVP

    或

    !PBE0 D4 X2C X2C-TZVPALL

    请注意，这里我们为每种方法使用了专用基组，即 ZORA- 或 DKH-DEF2-TZVP 以及 X2C-TZVPALL。这是必要的，因为这些基组是专门为全电子计算设计的，相对论校正不应与常规基组或赝势一起使用。有关选项的详细说明，请查阅 ORCA 手册。

    RI 与 ZORA/DKH/X2C¶

    如果你想使用任何 RI 方法来加速 SCF 计算，则必须使用另一套专用的 /J 辅助基组：

    !PBE0 D4 ZORA ZORA-DEF2-TZVP RIJDX SARC/J

    或

    !PBE0 D4 DKH DKH-DEF2-TZVP RIJDX SARC/J

    或

    !PBE0 D4 X2C X2C-TZVPALL RIJDX X2C/J

    例如，SARC/J 辅助基组可用于所有 ZORA 或 DKH-DEF2 基组。如果没有专用基组，则总是可以使用 AUTOAUX 自动生成一套。

    重要 SARC/J 基组是针对 SCF 部分的 RI 优化的，而不是针对 MP2 或更高等级的相关方法！关于相关计算专用的 /C 基组，请查阅 ORCA 手册，如果没有可用的基组，则使用 !AUTOAUX。

    示例 1：Hg 二聚体¶

    让我们测试这些效应对 Hg 二聚体的影响，其实验键长为 \(3.69 Å\) [Sattler2017]。

    该几何结构可以在常规 DFT 水平下使用 DEF2-TZVP 基组（利用赝势）进行优化，也可以使用匹配基组的全电子哈密顿量进行优化：

    2
structure
Hg 0 0 0
Hg 0 0 3
    !PBE0 D4 DEF2-TZVP OPT

*XYZ 0 1
Hg 0 0 0
Hg 0 0 3
*
    !PBE0 D4 ZORA SARC-ZORA-TZVP SARC/J OPT

    !PBE0 D4 DKH2 SARC-DKH-TZVP SARC/J OPT

    !PBE0 D4 X2C x2c-TZVPall X2C/J OPT

    注意 此处相对论计算中 RIJ 近似所用的辅助基组选用的是相应的 SARC/J。

    现在我们可以将得到的 Hg-Hg 键长与实验值 3.69 Å 进行比较。

    相对论处理方法 d(Hg-Hg) / Å
    ECP 3.64
    ZORA 3.58
    DKH2 3.55
    X2C 3.49
    实验值 3.69

    在本例中，使用 ECP 基组优化得到的几何结构最接近实验值。总体而言，与非相对论的全电子计算相比，所有相对论处理方法都显著改善了与实验的一致性。这也表明，在许多情况下 ECP 足以用于几何优化。

    警告 使用相对论校正的几何优化默认会开启单中心近似，这会改变能量数值。 不要将这些结果与 !OPT 运行中得到的单点能进行比较，这些数值是不兼容的。

    示例 2：^119Sn NMR¶

    在本例中，我们用不同的相对论处理方法计算 ^119Sn 核磁共振化学位移（NMR chemical shift）。为此，我们使用 B97M-V 泛函计算参考分子 \(SnMe_4\) 以及所研究的四价锡化合物的磁屏蔽张量。

    相应的输入文件为：

    !B97M-V X2C X2C-TZVPALL RIJDX X2C/J

*XYZFILE 0 1 structure.xyz

%eprnmr
  Nuclei = all Sn {shift}
end

    !B97M-V ZORA ZORA-DEF2-TZVP RIJDX AUTOAUX

%basis
NewGTO Sn "SARC-ZORA-TZVP" end
end

*XYZFILE 0 1 structure.xyz

%eprnmr
  Nuclei = all Sn {shift}
end

    !B97M-V ZORA DKH-DEF2-TZVP RIJDX AUTOAUX

%basis
NewGTO Sn "SARC-DKH-TZVP" end
end

*XYZFILE 0 1 structure.xyz

%eprnmr
  Nuclei = all Sn {shift}
end

    注意 请注意，如果你为目标核所选的基组并非分子中所有元素都有可用版本， 你可以单独定义各元素的基组。

    如果我们现在按照 NMR 波谱学 教程中描述的方法计算近似化学位移，就得到以下数值：

    相对论处理方法 δ(^119Sn) / ppm
    ECP -6.0
    ZORA -137.4
    DKH2 -140.5
    X2C -169.8
    实验值 -115.5

    这里我们可以看到，在锡核上使用有效核心势（ECP）得到的结果与实验相比非常差。考虑到我们的计算中缺少自旋轨道耦合（spin-orbit coupling）和环境效应，所有其他标量相对论方法都与实验相当吻合。
