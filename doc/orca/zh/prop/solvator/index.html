    显式溶剂化（SOLVATOR）¶

    隐式溶剂化模型是模拟溶剂化效应的一种高效方式。然而，如果溶质与溶剂之间存在强相互作用，或者溶质作为反应物，则需要对溶剂分子进行显式处理。SOLVATOR 是一种全自动纳入显式溶剂分子并生成溶剂化层（solvation shell）的算法。可以通过 %solvator 块方便地请求：

    ! XTB ALPB(WATER)

%solvator
nsolv 30 
end

* XYZFILE 0 1 solute.xyz

    注意 若无其他输入，SOLVATOR 可以使用 ALPB 可用的所有溶剂。当然，也可以通过输入定义自定义溶剂。

    如果需要加入大量溶剂分子，可以使用 SOLVATOR 中的随机模式（stochastic mode），以牺牲一些精度为代价大幅加快流程。

    ! XTB ALPB(WATER)

%SOLVATOR 
    NSOLV       100 
    CLUSTERMODE STOCHASTIC
END
*XYZFILE 0 1 solute.xyz

    现在运行 SOLVATOR，即可在倍半硅氧烷分子周围得到一个球形氦液滴。
    

    !XTB

%SOLVATOR
    SOLVENTFILE "he.xyz"
    NSOLV       2000
    CLUSTERMODE STOCHASTIC
    DROPLET     true
END

* XYZFILE 0 1 solute.xyz
