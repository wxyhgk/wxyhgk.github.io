    自旋轨道耦合¶

    自旋轨道耦合（spin-orbit coupling, SOC）是混叠不同多重度态（例如单重态和三重态）的相对论效应。在 Dirac 方程框架下——它由于在量子力学中考虑了相对论而最接近真实的物理——自旋与常规角动量之间没有区分，因此实际上并不存在纯自旋态这样的东西。

    通常，这是一种主要影响含重原子体系的效应，因此并非每个计算都需要包含它。尽管如此，许多实验现象都源于此，例如磷光（phosphorescence）、激发态之间的系间窜越（intersystem crossing）、TADF（热活化延迟荧光），甚至一些通过非常规自旋态进行的反应性。

    作为一个例子，让我们尝试预测 Ir(ppy)_3 配合物在溶液中的磷光寿命和颜色。它是一种黄绿色发光体，是用于制造 OLED 的一类重要化合物的一员：

    用 TD-DFT 处理 SOC¶

    在 ORCA 中，有许多方法可以在各种理论水平上把 SOC 包含到你的计算中，也许最简单的一种是使用 TD-DFT [Iszak2019c]。从现在起，我们将假定与该节相关的一切都已知，只讨论与 SOC 相关的新内容。

    不过，在进入更复杂的铱(III)配合物之前，让我们先从更简单的分子开始：甲醛。这是一个除了是有机分子之外还表现出相当强 SOC 的分子。

    这是因为 \(\pi-\pi^*\) 和 \(n-\pi^*\) 激发态可以与其他态正交，而自旋的改变可以由跃迁过程中电子"旋转"引起的角动量变化来补偿（稍后详述）[Turro2010]。要计算激发态及其 SOC，只需运行（例如用 B3LYP）：

    铱(III)配合物中的 SOC¶

    现在让我们回到前面提到的磷光铱(III)配合物的例子。这是一个 SOC 非常强的情形，以至于不再有清晰的单重态或三重态，而且激发态因耦合而发生剧烈变化。

    第一步是优化这个重金属配合物。我们将关注 fac-\(Ir(ppy)_3\)，因为对于这个异构体我们有大量的实验数据可供比较。优化可以通过运行以下输入完成：

    !B3LYP DEF2-TZVP OPT CPCM(CH2CL2) D4
* XYZFILE 0 1 fac-Irppy_guess.xyz

    这里我们使用 B3LYP 泛函和 DEF2-TZVP 基组，实际上对 Ir 等重原子使用了赝势（pseudo-potential）。这有助于加速计算，并且由于赝势是拟合相对论计算得到的，也在一定程度上考虑了相对论效应对几何结构的影响。

    我们还使用了更大的格点，当存在这类重原子时这很重要，同时用 CPCM 进行溶剂化校正、用 D4 处理色散相互作用。结果是：

    它与 CCDB 中找到的平均实验键长值 [Yersin2005] 吻合良好。优化之后，可以再次调用 SOC-TD-DFT：

    !B3LYP ZORA ZORA-DEF2-TZVP SARC/J CPCM(CH2CL2) RI-SOMF(1X)
%TDDFT  NROOTS  25
        DOSOC   TRUE
        TDA     FALSE
END
%BASIS  NEWGTO  IR      "SARC-ZORA-TZVP" END
END
* XYZFILE 0 1 fac-Irppy_optimized.xyz

    现在我们使用 ZORA 及其所需基组进行含相对论校正的完整计算。请注意，我们还需要为 Ir 指定 SARC-ZORA-TZVP 基组，因为没有简单的 ZORA-DEF2-TZVP 可用于该元素。这里我们添加了 RI-SOMF(1X) 来加速 SOC 积分，并选择 TDA FALSE 来做完整的 TD-DFT 计算，以便稍后比较。

    而先前的"三重态"——现在是 SOC 态——实际上与基态之间有非常明亮的跃迁。

    近似的零场分裂（zero-field splitting, ZFS）由 SOC 态 3 与 SOC 态 1 之间的能量差得到，约为 \(70 cm^{-1}\)，与实验值 \(85-170 cm^{-1}\) [Wang2014] 吻合得相当好。

    由振子强度还可以预测这些配合物的磷光寿命，使用同一参考文献中式 (4) 的计算值约为 \(1.17 \mu s\)，也接近测量的 \(1.6-1.8 \mu s\)。

    用一个非常简化的方法，如果取 \(S_1\) 到基态的能量差并假定零点能（ZPE）差为 \(2000 cm^{-1}\)，预期的发射颜色将是蓝色。即使单独使用 \(T_1\) 能量，也会是绿色，但不够黄。现在使用 SOC 态 1，约 \(532 nm\) 处的颜色与该配合物的黄绿色发射颜色相当吻合：

    用其他方法处理 SOC¶

    SOC 的包含也可以通过 ORCA 在许多其他理论水平上完成，如 CASSCF、ROCIS、STEOM 和 MRCI。输入因方法而略有不同，但输出大体相同。关于这些其他方法的更详细信息，请查阅 ORCA 手册。
