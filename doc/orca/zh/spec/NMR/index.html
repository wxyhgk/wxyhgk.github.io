    核磁共振（NMR）¶

    一般用法¶

    核磁共振（NMR）谱学是分析任何分子结构特征的强大工具。在 ORCA 中，可以计算 NMR 谱学性质，如屏蔽 张量和化学位移、J 耦合常数以及 NMR 自旋-转动常数。这些性质可以用多种不同的方法计算，我们一般建议查阅近期的基准研究，如 Kaupp 及其同事的工作 [Kaupp2021a][Kaupp2021b]，以找到合适的方法。

    重要 以下部分教程中使用的 pcSseg-2 和 pcSseg-1 基组只适用到 Kr 元素。如果存在更重的元素而你并不想对它们计算 NMR 性质，可以改为给这些原子添加 另一个可用的基组（如 def2-TZVP）并配合相应的 ECP。更多信息请查阅 ORCA 手册。

    NMR 屏蔽张量¶

    基本的 NMR 屏蔽张量计算可以通过 NMR 输入关键词来请求。

    !BP86 DEF2-TZVP NMR

*XYZFILE 0 1 structure.xyz

    这个输入将计算给定分子中所有原子核的屏蔽张量。

    J 耦合常数¶

    J 耦合常数可以通过 %EPRNMR 块中的 SSALL 关键词来请求：

    !BP86 DEF2-TZVP NMR

* XYZFILE 0 1 structure.xyz

%EPRNMR
     NUCLEI = ALL H {SHIFT, SSALL}
END

    重要 %EPRNMR 块必须放在坐标指定之后！

    提示 上例中的 SHIFT 关键词会将计算的屏蔽限制在 H 原子上。

    自旋-转动常数¶

    自旋-转动常数（spin-rotation constants）可以通过 SROT 关键词来请求。

    1
structure
  C          -1.98519000000000      1.12204043805165      0.00000000000000
    !BP86 DEF2-TZVP MASS2016

*XYZ 0 1
  C          -1.98519000000000      1.12204043805165      0.00000000000000
  O          -1.98519000000000     -0.00136043805165      0.00000000000000 M=16.999131
*

%EPRNMR
  NUCLEI = ALL O {SROT, IST=17}
END

    注意 我们必须通过坐标输入来定义单独请求的原子核的质量！MASS2016 关键词只会使用 2016 年重新确定的最丰度同位素的原子质量。IST 关键词定义将通过所选同位素使用的磁旋比，在本例中为 ^17O。

    警告 ORCA 的实现遵循 [Helgaker1996] 中的描述。因此，转动常数分量的符号约定与不同来源比较时可能不同。

    示例 1：丙酸的 ^13C-NMR 化学位移¶

    在本例中，我们将计算丙酸在 \(CHCl_3\) 溶液中 ^13C 原子核的各向同性屏蔽。该分子的实验数据可以在 SDBS 数据库中找到。

    图：丙酸的分子结构及其实验 ^13C NMR 化学位移。

    这些将被用来按照下式计算各原子核相对于 TMS（四甲基硅烷）的化学位移：

    \[ \delta_{calc.} = \frac{\sigma_{ref.} - \sigma_{calc.}}{1 - \sigma_{ref.}} \approx \sigma_{ref.} - \sigma_{calc.} \]

    重要 对于非常大的屏蔽张量，例如 Pb 等很重的原子核，分母（\(1 - \sigma_{ref.})\) 就不能再忽略了。

    由于我们使用 TMS 作为参比，我们将首先用 TPSS meta-GGA 泛函和 Jensen 的 pcSseg-1 基组计算 TMS 分子的各向同性屏蔽。TPSS 通常能为大多数原子核给出相当好的 NMR 性质。请注意，为了得到更精确的结果，应至少使用如 pcSseg-2 或 def2-TZVP 这样的三 zeta 基组。

    重要 对于 TPSS 这类 meta-GGA 泛函，应当使用动能密度处理的规范不变（gauge-invariant）选项！推荐使用 Dobson 方法的电流密度相关、规范不变版本，可以通过在 %EPRNMR 块中用 TAU DOBSON 调用。

    !TPSS PCSSEG-1 AUTOAUX NMR CPCM(CHCl3)

%EPRNMR
   TAU DOBSON
END

*XYZFILE 0 1 tms.xyz

    提示 除了计算参比分子，你也可以使用内标。在这种情况下，你只需对计算的谱峰施加一个恒定的位移，使其中一个等于已知值。 例如，可以使用一个已指认的甲基或芳香 H 或 C 的值，并从可能的误差相消中获益。如果参比物 与目标分子差别太大或难以模拟（比如 ^31P-NMR 中水里的磷酸），这样做也更有意义。

    SCF 计算成功后，ORCA 将启动性质计算并汇总所请求的性质：

    ChimeraX 提供许多设置，包括参比位移的选择、脉冲频率以及等价原子核的手动选择。光谱还可以导出为图片或 .csv 数据以便进一步处理。

    示例 3：用双杂化 DFT 计算 NMR 化学位移¶

    在 ORCA 中，NMR 屏蔽常数也可以用双杂化泛函（double-hybrid functionals）计算，这类泛函通过向 DFT 添加 MP2 相关而受益 [Neese2018]。

    !revDSD-PBEP86-D4/2021 PCSSEG-3 AUTOAUX NMR NOFROZENCORE

*XYZFILE 0 1 opt.xyz

    重要 默认情况下，MP2 和双杂化 DFT 使用冻结核近似。由于 NMR 性质强烈受内层电子影响，我们需要用 NOFROZENCORE 关键词关闭它。

    注意 请注意，双杂化泛函通常需要像 pcSseg-3 这样更大的基组才能得到收敛的结果。

    ORCA 将首先在 SCF DFT 水平上计算 NMR 性质：

    -------------------
CHEMICAL SHIELDINGS (ppm)
-------------------

Method             : SCF
Type of density    : Electron Density
[...]

    随后计算基于未弛豫和弛豫 MP2 密度的性质：

    -------------------
CHEMICAL SHIELDINGS (ppm)
-------------------

Method             : MP2
Type of density    : Electron Density
Type of derivative : Magnetic Field (with GIAOs) (Direction=X)
Multiplicity       :   1
Level              : Unrelaxed density

    -------------------
CHEMICAL SHIELDINGS (ppm)
-------------------

Method             : MP2
Type of density    : Electron Density
Type of derivative : Magnetic Field (with GIAOs) (Direction=X)
Multiplicity       :   1
Level              : Relaxed density

    基于弛豫密度的结果就是所需的性质。

    警告 双杂化泛函通常给出比低水平 DFT 方法更好的结果，然而对于某些体系，例如 HOMO-LUMO 能隙很小的体系或 3d 过渡金属配合物， 基于 MP2 的方法容易产生较大误差，此时宜改用稳健的 meta-GGA（如 B97M-V 和 r^2SCAN）或杂化泛函（如 r^2SCAN0、TPSSh 和 ωB97X-V）。

    提示 尽管 MP2 或双杂化 DFT 无法给出 J 耦合常数，但可以通过混合不同理论水平来获得耦合谱。例如， 我们可以把双杂化 DFT 水平计算的化学位移与杂化 DFT 计算得到的 J 耦合常数组合起来。

    示例 4：^12C^17O 的自旋-转动常数¶

    在本例中，我们将计算 ^12C^17O 的 NMR 自旋-转动常数。在相应的输入中，我们把 O 的原子质量定义为匹配 ^17O，并为所选同位素调整了 磁旋比。

    1
structure
  C          -1.98519000000000      1.12204043805165      0.00000000000000
    ! TPSSh PCSSEG-3 AUTOAUX MASS2016

*XYZ 0 1
  C          -1.98519000000000      1.12204043805165      0.00000000000000
  O          -1.98519000000000     -0.00136043805165      0.00000000000000 M=16.999131
*

%EPRNMR
   NUCLEI = ALL O {SROT, IST=17}
   TAU DOBSON
END
