    用 orca_asa 程序模拟和拟合电子谱中的振动结构、共振拉曼激发轮廓与谱图（Simulation and Fit of Vibronic Structure in Electronic Spectra, Resonance Raman Excitation Profiles and Spectra with the orca_asa Program）¶

    自 ORCA 6.0.0 起已弃用

    • orca_asa 程序不再受支持。 它仍包含在 6.0.0 发行版中，文档保存如下。 但它可能无法正常工作，并将在未来的 ORCA 版本中被移除！
    • !NMScan 和 !NMGrad 关键词仍可用，但这些计算可能 失败或无法为 orca_asa 生成有效输入。 若适用，请改用 ESD 模块。

    本节讨论光谱（包括吸收、荧光和共振拉曼）模拟与拟合的各个方面。 ORCA 的这一部分相当独立，也可用于数据分析语境， 而不仅限于"量子化学"模式。该程序名为 orca_asa， 其中 ASA 代表 "[A]{.underline}dvanced [ S]{.underline}pectral [ A]{.underline}nalysis"（高级光谱分析）。该程序完全由 Taras Petrenko 博士设计。

    总体思路如下：一次 ORCA 运行产生喂入 orca_asa 程序所需的必要数据， 并写出一个初始输入文件。该输入文件可用于直接运行 orca_asa 以预测吸收、荧光或共振拉曼谱。也可以编辑该输入文件 以更改模拟中使用的参数。最后——但绝非最不重要—— orca_asa 程序可用于对模型参数进行相对实验数据的拟合。

    :height: 400px

    下面所有例子均取自 petrenko2007analysis， 若您使用 orca_asa 程序进行任何工作，必须引用该文献！

    程序的一般描述（General Description of the Program）¶

    程序输入包含以下信息：(1) 模型以及刻画分子电子结构的模型参数 和线型因子的说明；(2) 模拟的光谱范围和分辨率； (3) 用于 rR 激发轮廓和谱图生成的振动跃迁说明； (4) 依模型而定的若干算法选择选项；(5) 拟合选项。

    所有可选参数 (1)–(3) 都在 %sim 块中给出， 拟合选项在 %fit 块中。模型参数在下文描述的各个块中指定。 程序 orca_asa 与 ORCA 相接口，并沿用其输入风格。 orca_asa 运行的输入也可在 ORCA 运行时生成。

    当前实现提供所谓的"简单"（simple）、"独立模位移简谐振子" （independent mode, displaced harmonic oscillator, IMDHO） 以及"含频率改变的独立模位移简谐振子" （independent mode, displaced harmonic oscillator with frequency alteration, IMDHOFA）模型。

    光谱模拟流程：输入结构与模型参数（Spectral Simulation Procedures: Input Structure and Model Parameters）¶

    示例：简单模式（Example: Simple Mode）¶

    该模型代表最简单的方法，通常用于吸收谱分析。 它忽略电子跃迁的振动结构，并用标准线型——通常是高斯、 洛伦兹或混合（Voigt）函数——近似每一条电子谱带。 只有当电子谱中振动精细结构未被分辨时，该模型才有意义。 在此近似下，吸收谱强度取决于入射光子能量（\(E_{L} )\)、 电子跃迁能（\(E_{T} )\)、跃迁电偶极矩 （\(\mathrm{M }\)，在基态平衡几何处计算）。 线型因子由均匀线宽 \(\Gamma\) 和对应于跃迁能高斯分布的 标准差参数 \(\sigma\) 指定。下例说明了使用不同强度和线型参数 模拟吸收带形的一个简单输入。

    # example001.inp
#
# Input file to generate absorption spectrum consisting
# of 3 bands   with different lineshape factors:
#
# 1. Lorentzian centered at 18000cm**-1 (damping factor Gamma= 100 cm**-1)
# 2. Gaussian   centered at 20000cm**-1
#    (standard deviation Sigma= 100 cm**-1)
# 3. Mixed Gaussian-Lorentzian band representing Voigt profile
#    centered at 21000 cm**-1

%sim
         Model Simple

         # Spectral range for absorption simulation:
         AbsRange     17000.0,   23000.0

         # Number of points to simulate absorption spectrum:
         NAbsPoints  2000

end

#---------------------------------------------------------------------------
#  Transition        Gamma    Sigma  Transition Dipole Moment (atomic unit)
#  Energy (cm**-1)  (cm**-1) (cm**-1)      Mx          My        Mz
#---------------------------------------------------------------------------

$el_states
3     # number of electronic states
   1  18000.0        100.00      0.0        1.0         0.0       0.0
   2  20000.0          0.00    100.0        1.0         0.0       0.0
   3  22000.0         50.00     50.0        1.0         0.0       0.0

    由各跃迁到达的末态电子态参数在 $el_states 块中指定。 计算中使用的光谱范围和分辨率由 %sim 块中的 AbsRange 和 NAbsPoints 关键词定义。 若 NAbsPoints>1，将自动调用吸收谱计算。 orca_asa 运行结束后，您会在目录中找到文件 example001.abs.dat，它以简单的两列 ASCII 格式包含吸收谱， 适合用任何电子表格程序绘图。与各个电子跃迁对应的吸收谱 存储在文件 example001.abs.as.dat 中（后缀 "as" 代表 "All States"，即所有态）。

    对文件 example001.inp. 运行 orca_asa 后生成的吸收谱。 三条谱带具有不同的线型参数。 请注意，尽管所有跃迁都具有相同的跃迁电偶极矩， 它们的强度却按跃迁能成比例缩放。

    程序运行的输出还包含每个电子谱带对应的振子强度 和半高全宽（FWHM）参数：

    ----------------------------------------------
   State       EV        fosc    Stokes shift
            (cm**-1)               (cm**-1)
----------------------------------------------
    1:      18000.00   0.054676      0.00
    2:      20000.00   0.060751      0.00
    3:      22000.00   0.066826      0.00

----------------------------------------
   BROADENING PARAMETETRS (cm**-1)
----------------------------------------
   State     Gamma     Sigma      FWHM
----------------------------------------
    1:        100.00      0.00    200.00
    2:          0.00    100.00    235.48
    3:         50.00     50.00    180.07

    请注意，尽管三种线型函数都是对称的， 单条吸收带的整体形状却并非如此， 因为消光系数（吸收截面）也与入射光子能量成正比。 因此，若线宽大于峰位能量的 10%，电子谱带的不对称性可能相当明显。

    示例：IMDHO 模型中吸收与荧光谱的建模（Example: Modelling of Absorption and Fluorescence Spectra within the IMDHO Model）¶

    IMDHO 模型是最简单的方法，能成功预测大量真实体系 电子谱中的振动结构以及 rR 强度。该模型假设：

    1. 基态和激发态势能面为简谐的；

    2. 激发态势能面相对基态势能面发生原点位移；

    3. 激发态中不发生振动频率改变或简正模旋转；

    4. 电子跃迁偶极矩不依赖于坐标。

    除了上文"简单模型"中引入的参数外，它还需要关于振动自由度的信息。 所需信息包括基态振动频率 \(\left\{{ \omega_{gm} } ight\}\) 和 （无量纲）原点位移 \(\left\{{ \Delta_{mi} } ight\}\)， 其中 \(i\) 和 \(m\) 分别指电子态和简正模。 \(\Delta\) 以无量纲简正坐标表示。 因此，对 IMDHO 模型需要指定以下各块

    • $el_states 块包含每个电子态的参数 \(E_{T}, \Gamma, \sigma, \mathrm{M }\)。 默认假定 \(E_{T}\) 为绝热极小分离能。 也可以将其重定义为垂直跃迁能。这通过在 %sim 块中 指定关键词 EnInput=EV 实现。

    • $vib_freq_gs 块指定基态振动频率。

    • $sdnc 块以矩阵形式包含参数 \(\left\{{ \Delta_{mi} } ight\}\)，使得第 \(i\) 列表示 第 \(i\) 个激发态势能面沿所有简正模的无量纲位移。

    文件 example002.inp 提供了对一个沿 5 个简正坐标具有显著 激发态原点位移的体系模拟吸收和荧光谱的输入。

    # example002.inp
#
# Input file for simulation  of vibrational structure
# in absorption and fluorescence spectra assuming
# origin shift of excited PES along 5 normal coordinates.
# The simulated spectra closely reproduce the experimental
# optical bandshapes for the tetracene molecule.
#
%sim
     Model IMDHO

     # spectral range for absorption simulation (cm**-1)
     AbsRange    20000.0, 27000.0
     NAbsPoints  2000             # number of points in absorption spectrum

     # spectral range for simulation of fluorescence (cm**-1)
     FlRange     22000.0, 16000.0
     NFlPoints   2000      # number of points in fluorescence spectrum

     # the following options require the spectra to be normalized
     # so that their maxima are equal to 1.0
     AbsScaleMode Rel
     FlScaleMode  Rel   # default  for fluorescence

     # for absorption spectrum the default option is AbsScaleMode= Ext
     # which stands for extinction coefficient

end

#---------------------------------------------------------------------------
#   Transition        Gamma    Sigma  Transition Dipole Moment (atomic unit)
#   Energy (cm**-1)  (cm**-1) (cm**-1)      Mx          My          Mz
#---------------------------------------------------------------------------

$el_states
1
   1  21140.0         50.00    100.0        1.0         0.0         0.0

# Block specifying Stokes Shift parameter for each electronic state
# This information is optional
$ss
1   # number of excited states
  1   300.0      # the Stokes shift for the 1st electronic transition

# Block providing the values of VIBrational FREQuencies
# for 5 Ground-State normal modes.
# Obligatory for IMDHO and IMDHOFA models.
$vib_freq_gs
5
    1      310.0
    2     1193.0
    3     1386.0
    4     1500.0
    5     1530.0

# Block specifying origin Shift of the excite-state PES
# along each normal mode in terms of the ground-state
# Dimensionless Normal Coordinates
# Obligatory for IMDHO and IMDHOFA models.
$sdnc
5 1
               1
     1       0.698
     2      -0.574
     3       0.932
     4      -0.692
     5       0.561

    若参数 NAbsPoints>1 和 NFlPoints> 1，将自动调用吸收和荧光谱的计算。 输入文件还包含可选块 $ss，它为每个电子跃迁指定 Stokes 位移 \(\lambda\)。该参数等于吸收谱和荧光谱中 0-0 振动峰之间的能量差， 如 fig:716 所示。一般而言，\(\lambda\) 包含溶剂诱导效应 以及输入中未指定的低频模对应的未分辨振动结构。 请注意，我们在 %sim 块中指定了参数 AbsScaleMode=Rel 和 FlScaleMode=Rel， 以确保模拟谱归一化为 1。计算得到的吸收谱和荧光谱 分别存储在 example002.abs.dat 和 example002.fl.dat 文件中。

    对文件 example002.inp. 运行 orca_asa 后生成的吸收谱和荧光谱。 若均匀展宽设为 \(\Gamma = 10 \, \text{cm}^{-1}\)， 可以分辨出隐含的振动精细结构。

    示例：IMDHOFA 模型中吸收与荧光谱的建模（Example: Modelling of Absorption and Fluorescence Spectra within the IMDHOFA Model）¶

    IMDHOFA（含频率改变的独立模位移简谐振子， Independent Mode Displaced Harmonic Oscillators with Frequency Alteration）基于与 IMDHO 模型相同的假设， 只是激发态中可以发生振动频率改变。 文件 example003.inp 的输入参数与 example002.inp 几乎相同。 IMDHOFA 模型通过 %sim 块中的关键词 Model=IMDHOFA 调用。 此外，必须提供必需块 $vib_freq_es。 它以矩阵形式包含激发态振动频率 \(\left\{{ \omega_{emi} } ight\}\)， 使得第 \(i\) 列表示第 \(i\) 个激发态势能面所有简正模的振动频率。

    # Block providing the values of VIBrational FREQuencies
# for 5 Excited-State normal modes.
# Obligatory for IMDHOFA model.

$vib_freq_es
5  1         # number of modes and number of excited states
             1
    1      410.0
    2     1293.0
    3     1400.0
    4     1600.0
    5     1730.0

    对文件 example003.inp 运行 orca_asa 后生成的吸收谱和荧光谱。 图中还给出了对应于均匀展宽 \(\Gamma = 10 \, \text{cm}^{-1}\) 的高分辨谱。

    # example004.inp
#
#
%sim
     Model IMDHOT
     TK 300 # temperature (in Kelvin)

     # spectral range for absorption simulation (cm**-1)
     AbsRange    18000.0, 35000.0
     NAbsPoints  5000             # number of points in absorption spectrum

     # spectral range for simulation of fluorescence (cm**-1)
     FlRange     22000.0, 10000.0
     NFlPoints   5000      # number of points in fluorescence spectrum

     # the following options require the spectra to be normalized
     # so that their maxima are equal to 1.0
     AbsScaleMode Rel
     FlScaleMode  Rel   # default  for fluorescence
end

    实验谱的拟合（Fitting of Experimental Spectra）¶

    示例：吸收谱的高斯拟合（Example: Gauss-Fit of Absorption Spectrum）¶

    吸收谱基本上由若干吸收带组成。每条吸收带对应于 基电子态到激发电子态的一个跃迁。在分子中这类跃迁通常相当宽。 许多情形下谱带会相互重叠，需要将宽的吸收包络解卷积为 各个跃迁的贡献。在"简单模型"内，orca_asa 程序能用 标准线型函数（高斯、洛伦兹）或更一般的 Voigt 函数之和 对吸收谱进行拟合。在大多数情形下，只需进行"高斯拟合"， 即假定每条谱带的形状为高斯函数。 然后使用必要数量（可多可少）的高斯函数以精确表示吸收包络。 为说明"简单模型"内的拟合流程，让我们考察 fig:723 中的实验吸收谱：

    实验吸收谱。竖线标出在谱拟合输入中用作初始猜测的跃迁能。

    约束块 $el_states_c 的功能应按如下方式理解： 1) 0 标志表示 $el_state 块中相应的参数在拟合中不变； 2) 若某个参数对应的数字与相应电子态的编号一致， 则该参数将独立变化。因此，输入中的 $el_states_c 块表明 所有跃迁能、非均匀线宽和跃迁电偶极矩的 x 分量将独立变化， 而均匀线宽、跃迁偶极矩的 y 和 z 分量将固定为其初始值。

    以下几点很重要：

    • 由于常规吸收光谱处理的是取向平均的吸收截面， 信号强度与跃迁电偶极矩的平方 \(\left|{ \mathrm{M }} \right|^{2}\) 成正比。 因此，只要 \(\left|{ \mathrm{M }} \right|^{2}= \text{const}\)， 强度就不依赖于 \(\mathrm{M }\) 各分量的数值。 因此，我们只允许 \(M_{x}\) 分量变化。 否则拟合算法的收敛可能出现问题。

    • 进入最小化所用的平均绝对差函数的实验点权重之和 始终保持等于实验点数目。若实验光子能量是等间距的， 所有权重均设为相等。然而，在实验电子谱中， 从高能到低能光谱区域谱点密度可能显著增加， 这是因为实验吸收谱最初是在波长标度上采集的。 在这种情形下，拟合质量会明显偏向低能光谱区域。 因此，建议按实验点的密度调整其相对权重， 这由 %fit 块中的关键词 WeightsAdjust 控制。 尽管该参数对本例并不关键，但一般而言它会给出更均衡的拟合。

    • %fit 块中的参数 E0Step、TMStep、E0SDStep 指定 \(E_{T} ,\mathrm{M }, \sigma\) 空间中单纯形的初始尺度， 应大致对应于 $el_states 块中这些参数的初始猜测 相对其实际值的预期不确定度。 若指定初始步长的参数过低或过高，拟合质量可能明显变差。

    k    int   I  W
          modes m1,m2,...mn  
          quanta q1,q2,...qn;

    这意味着第 \(k\) 个跃迁具有强度 \(I\) 和权重 \(W\)， 后者进入用于最小化的平均绝对差函数（\(W\) 是可选参数）。 随后两行通过给出模 \(m_{i}\) 的激发数 \(q_{i}\) 指定振动跃迁， 相应的拉曼位移等于 \(\nu =\sum\limits_ { q_{i} \nu _{i} }\)，其中 \(\nu_{i}\) 是模 \(m_{i}\) 的振动频率。

    需要变化的参数在约束块 $el_states_c 和 $sdnc_c 中指定。 两个块的结构和参数数目分别与 $el_states 和 $sdnc 相同。 若 $el_states_c 块中的对应参数等于电子态的编号， 则假定 $el_states 块中的该参数独立变化。 同样，若 $sdnc_c 块中的对应参数等于简正模的编号， 则假定 $sdnc 块中的该参数独立变化。 在相应约束块中设为 0 的模型参数在拟合中不变。 以下参数的数值对拟合质量可能很重要：

    • %fit 块中的 SDNCStep 指定 \(\left\{{ \Delta_{m} } \right\}\) 空间中 单纯形的初始尺度，应大致对应于 $sdnc块中 \(\left\{{ \Delta_{m} } \right\}\) 的初始猜测相对其实际值的预期不确定度。 您可以在本例中注意到，若该参数过大（>2.0）或过小（<0.4）， 拟合质量可能显著变差

    关于正确比较实验与量子化学计算的共振拉曼谱的重要说明（Important Notes about Proper Comparison of Experimental and Quantum Chemically Calculated Resonance Raman Spectra）¶

    为比较实验与理论 rR 谱，必须在两种情形下使用大约与吸收谱中 同一振动跃迁共振的激发能。因此，对于弥散的吸收谱 （即不显示已分辨振动结构的谱），需要调整 %el_states 块中的 跃迁能和线宽参数，使实验与理论谱的包络大致重合， 然后使用实验激发能数值构造理论 rR 谱。 通常在弥散吸收谱情形下 rR 轮廓相当平滑。 因此，即使激发能不与吸收谱中同一振动跃迁共振， 在这样的不匹配情形下 rR 谱预计也不会显著变化。

    对于具有已分辨或部分分辨振动结构的吸收谱， 必须修改 %el_states 块中的跃迁能， 使计算与实验观测的 0-0 振动峰重合， 并修改线宽参数，使计算与实验谱中低能斜率的行为相似。
