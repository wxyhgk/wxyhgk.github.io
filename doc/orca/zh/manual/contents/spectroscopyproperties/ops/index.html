    单光子光谱（One Photon Spectroscopy）¶

    一般性描述（General Description）¶

    单光子光谱（One Photon Spectroscopy，OPS）工具在 Orca 6.0 中引入，负责计算单光子吸收（OPA）、发射（OPE）以及电圆二色（natural electric circular dichroism，ECD）强度。 在每种情形下，由初态 \(I\) 与末态 \(J\) 之间跃迁产生的谱强度（\(I(\omega)\)）由跃迁矩 \(T_{IJ}=\langle \Psi_I | \hat{H}_1 | \Psi_J \rangle\) 的模平方决定，并按态 \(I\) 与 \(J\) 的布居 \(N_I\) 和 \(N_J\) 加权：

    \[ I(\omega) = \alpha \omega ^{-1} \sum_{IJ} (N_I - N_J) | \langle \Psi_I | \hat{H}_1 | \Psi_J \rangle |^2 \delta(E_{JI} \pm \hslash \omega )\qquad \text{(eqn:masterabs)} \]

    其中，\(\alpha\) 为正常数，\(\hslash \omega\) 代表光子能量，\(\hat{H}_1\) 的表达式取决于对光-物质相互作用的具体建模方式。

    光-物质相互作用方法（Light-matter interaction approaches）¶

    \(\hat{H}_1\) 的表达式可以从不同的理论视角推导。出于教学目的，这里采用经典电动力学方法。通过用矢量势 \(\text{(}A\text{)}\) 和标量势 \(\text{(}\phi = 0\text{)}\) 对光进行经典表示，可以将辐射纳入描述分子体系的哈密顿量中。

    \[ \begin{split} \hat{H} =& \sum_{i=1}^N \frac{1}{2m_e} \Big[\hat{p}_i - \frac{e}{c} A (r_i,t)\Big]^2 - \frac{ge}{2m_ec}\sum_{i=1}^{N}B(r_i,t) \cdot \hat{s}_i+ V(r_1,...,r_N)\\ \end{split} \]

    忽略光的磁场与自旋之间的耦合以及 \(|A|^2\) 项，并应用费米黄金规则（Fermi's golden rule），可导出完全半经典光-物质相互作用（Full-Semiclassical Light-Matter interaction）下 \(\langle \Psi_I | \hat{H}_1 | \Psi_J \rangle\) 的表达式。

    \[ \begin{split} T_{IJ}^{FFMIO} = \frac{e}{m_e} { \sum_{i=1}^N \langle I| \mathcal{E} \cdot \Big[e^{ik\cdot r_i} \hat{p}_i \Big] |J\rangle} \end{split}\qquad \text{(eqn:TFFMIO)} \]

    其中 \(T_{IJ}^{FFMIO}\) 是完全（半经典）场-物质相互作用算符（Full (semiclassical) Field-Matter Interaction Operator，FFMIO）的跃迁矩，而 \(k\) 和 \(\mathcal{E}\) 分别表示描述光的波矢量和偏振矢量。\(r_i\) 和 \(p_i\) 分别代表第 i 个电子的位置和线动量算符。

    从式 Eq 出发，用泰勒展开近似 \(T_{IJ}^{FFMIO}\) 中的指数项，可得到不同阶的相互作用。零阶（\(T_{IJ}^{[0]}\)）给出电偶极速度表述 \(\text{(}ED\ vel\text{)}\)，经分子取向平均后得到：

    \[ \epsilon_{ED\ vel} (\omega) = \sum_{IJ} (N_I - N_J) \frac{2}{3 E_{JI}} | \langle \Psi_I | \hat{p} | \Psi_J \rangle |^2 \delta(E_{JI} \pm \hslash \omega )\qquad \text{(eqn:EDvelocity)} \]

    对于哈密顿量的精确解，或在构造上满足超维里定理（Hypervirial theorem）的理论中，方程 Eq 可以变换为长度表述 Eq \(\text{(}ED\ len\text{)}\)：

    \[ \epsilon_{ED\ len} (\omega) = \sum_{IJ} (N_I - N_J) \frac{2 E_{JI} }{3} | \langle \Psi_I | \hat{\mu} | \Psi_J \rangle |^2 \delta(E_{JI} \pm \hslash \omega )\qquad \text{(eqn:EDlength)} \]

    在所有使用 OPS 的 Orca 模块中，只要在相应模块的块中分别将 DoDipoleLength 和 DoDipoleVelocity 设为 true，即可得到 \(ED\ len\) 与 \(ED\ vel\) 表述下的吸收谱。结果以如下表格形式呈现：

    \[ \langle \Psi_I |(T_{EQlen})_{\alpha \beta} | \Psi_J \rangle = \frac{e E_{JI}}{2 m_e} \sum_i k_\alpha \epsilon_\beta \langle \Psi_I | r_\alpha r_\beta | \Psi_J \rangle\qquad \text{(eqn:Qlengh)} \]

    电圆二色（Natural electric circular dichroism）¶

    在 ECD 建模中，强度通过计算两个吸收谱的差值来确定：一个使用左旋圆偏振光获得，另一个使用右旋圆偏振光获得。

    \[ \Delta I(\omega) = I_{left} (\omega) - I_{rigth} (\omega) \]

    要启动这些计算，应将关键词 DoCD 设为 true。共有三种可用实现，分别涉及使用电偶极矩的长度表示或速度表示，以及使用 FFMIO，通过分别包含关键词 DoDipoleLength、DoDipoleVelocity 和 DoFullSemiclassical 来选择。

    OPS 关键词完整列表（OPS full list of keywords）¶

    以下关键词列表可直接包含在相应模块块中，以触发 OPS 计算相应的强度。

    DoCD                 # request circular dichroism calculation
DoDipoleLength       # request the use of electric moments in a 
                     # length formulation
DoDipoleVelocity     # request the use of electric moments in a 
                     # velocity formulation
DoFullSemiclassical  # request the calculation of complete 
                     # semiclassical multipolar moments
DecomposeFosc        # request the decomposition of the oscillator 
                     # strengths in a multipolar expansion

    在 Orca 6.1 中，可用 OPS 的模块包括：%cis、%tddft、%rocis、%casscf、%mrci、%mdci、%lft、%mcrpa、%rasci 和 %xes。

    注释（Notes）¶

    1. OPS 表格中的所有数值均以原子单位（au）表示，除非另有说明。
    2. 必要时关键词会自动进行内部修正。
    3. 重要（IMPORTANT）：所有使用 OPS 的模块中输入关键词已标准化；Orca 5.x 的关键词不再有效。
    4. 重要（IMPORTANT）：在 CASSCF 和 MRCI 中，控制吸收谱和 ECD 谱的关键词不再属于 %rel 块。
    5. Origin-adjusted 表述在 SOC/SSC 公式中是近似的。
    6. OPS 不适用于 sTDDFT 和 sTDADFT。
    7. MDCI 模块报告左解、右解和双解的光谱。
    8. ADC2 和 EOM-CCSD 方法仅使用 ED 长度表格。
    9. 从 ORCA 6.1 开始，关键词 DoHigherMoments、DecomposeFoscLength 和 DecomposeFoscVelocity 已合并为一个简化后的关键词：DecomposeFosc。
