    核磁共振（NMR）参数（Nuclear Magnetic Resonance Parameters）¶

    NMR 化学位移（NMR Chemical Shifts）¶

    HF、DFT（标准 GGA 和杂化泛函）、CASSCF， 以及 RI- 和 DLPNO-MP2 与双杂化 DFT 水平 （参见 eprnmr.MP2magnetic 一节及其中的参考文献）， 再加上耦合簇（GIAO-CCSD、GIAO-CCSD(T)，参见 autoci.autociresp） 的 NMR 化学位移，均可从 ORCA 的 EPR/NMR 模块获得。 为计算 NMR 屏蔽张量，程序采用规范包含原子轨道 （GIAO，Gauge Including Atomic Orbitals——有时也称为 London 轨道）。londonPR37,ditchfieldJCP72,helgakerChemRev99 在这一途径中引入依赖于磁场的基函数， 从而最小化规范原点依赖性，并保证结果随单电子基组迅速收敛。GaussNIC2000 请注意，GIAO 目前不可用于 CASSCF 线性响应， 且必须在 %eprnmr 块中提供规范原点 （参见 spectroscopyproperties.casscfresp）。 CASSCF 响应的 GIAO 即将登陆 ORCA！ eprnmr 模块的完整关键词列表见 properties.eprnmr。

    需要注意的一点是，为与实验比较，必须为所关注的核类型选取标准分子。 在实验中，NMR 化学位移通常相对于某种标准确定， 例如质子位移用 CH\(_{4}\) 或 TMS。 因此，需要分别计算感兴趣分子和给定标准分子的屏蔽， 再用计算值减去参考值得到相对屏蔽。 当然，重要的是参考计算和目标计算必须使用相同的基组和泛函。 若标准选得合适，这也有助于利用误差相消 （一种选择甚至是考虑"内标"——例如用感兴趣的化合物内部 甲基的 \(^{13}\)C 屏蔽作为参考）。

    让我们看一个例子——丙酸（CH\(_3\)-CH\(_2\)COOH）。 在 AIST（http://sdbs.db.aist.go.jp）等数据库中 可以找到 CDCl\(_3\) 中的 \(^{13}\)C 谱。 化学位移给出为 \(\delta_1\) = 8.9 ppm、\(\delta_2\) = 27.6 ppm、\(\delta_3\) = 181.5 ppm。 虽然直觉已告诉我们羧基的碳屏蔽最小， 因而向低场位移（\(\delta\) 值较大）， 但让我们看看用 SVP 和 TZVPP 基组 在 HF、BP86 和 B3LYP 理论水平下计算得到什么：

    method \(\sigma_1\) \(\sigma_2\) \(\sigma_3\)
    HF/SVP 191.7 176.6 23.7
    HF/TZVPP 183.5 167.1 9.7
    B86/SVP 181.9 165.8 26.5
    B86/TZVPP 174.7 155.5 7.6
    B3LYP/SVP 181.8 165.8 22.9
    B3LYP/TZVPP 173.9 155.0 2.9

    观察这些结果，我们可以发现几点—— 首先，使用过小基组的显著影响，差异超过 10 ppm。 其次，通过 DFT 纳入电子相关后结果变化很大，且依赖于泛函。 最后但同样重要的是，这些数值与实验值毫无共同之处 （变化顺序是错的）， 因为计算给出的是如上表那样的绝对屏蔽， 而实验值是相对位移，这里相对于 TMS。

    为获得相对位移，我们计算标准分子（TMS）的屏蔽 \(\sigma_{TMS}\)（TMS HF/TZVPP: 194.1 ppm， BP86/TZVPP: 184.8 ppm，B3LYP/TZVPP: 184.3 ppm）， 再用 \(\delta_{mol} = \sigma_{ref} - \sigma_{mol}\) 即可计算化学位移（单位 ppm）并与实验直接比较：

    method \(\delta_1\) \(\delta_2\) \(\delta_3\)
    HF/TZVPP 10.6 27.0 184.4
    B86/TZVPP 10.1 29.3 177.2
    B3LYP/TZVPP 10.4 29.3 181.4
    Exp. 8.9 27.6 181.5

    关于 ORCA 中 GIAO 的实现，有几点需要说明。 使用 GIAO 会导致一些相当复杂的分子单电子和双电子积分， 以及耦合微扰 SCF 方程右端的若干额外项。 其中双电子贡献尤其耗时。 因此实现了 RIJK、RIJDX 和 RIJCOSX 近似并作了测试。stoychevNMRBench 默认情况下，SCF 所用的近似也应用于 GIAO 积分， 但后者可通过 eprnmr 输入块中的 GIAO_2el 关键词更改 （参见 properties.eprnmr 一节）。 请注意，虽然默认的 COSX 网格对化学位移通常足够精确， 但对特殊情形或 post-HF 计算建议使用 defgrid3。

    用户可以精细控制对哪些核计算位移 （尽管这不会显著降低计算成本，后者由磁场的 CP-SCF 方程主导）。 其方式与下一节描述的超精细耦合和四极耦合完全相同。例如：

    NMR 化学位移也已与隐式溶剂模型结合实现， 因此 NMR 关键词可与 CPCM 输入块组合使用。 请注意，对于包含隐式溶剂的计算， 强烈建议也用同一模型优化几何结构。 无论如何，NMR 中可观测的显式溶剂-溶质相互作用（如氢键） 无法用这样的模型描述：溶剂分子必须显式包含在计算中。

    NMR 自旋-自旋耦合常数（NMR Spin-Spin Coupling Constants）¶

    溶液中分子 NMR 谱观测到的间接自旋-自旋耦合常数 由四项贡献组成：抗磁自旋-轨道项：

    \[ \hat{H}_{DSO}=\frac{1}{2} \sum_{ikl} \frac{ (\vec{M}_k \times \vec{r}_{ik})(\vec{M}_l \times \vec{r}_{il}) }{r_{ik}^3 ~ r_{il}^3}\qquad \text{(eqn:SSCC_DSO)} \]

    顺磁自旋-轨道项：

    \[ \hat{H}_{PSO}=\sum_{ik}\frac{\vec{M}_k ~ \vec{l}_{ik} }{r_{ik}^3}\qquad \text{(eqn:SSCC_PSO)} \]

    费米接触项：

    \[ \hat{H}_{FC}=\frac{8 ~ \pi}{3}\sum_{ik}\delta(r_i-r_k) ~ m_k\qquad \text{(eqn:SSCC_FC)} \]

    以及自旋偶极项：

    \[ \hat{H}_{SD}=\sum_{ik} m_k^T ~ \frac{3 ~ r_{ik} ~ r_{ik}^{~T}-r_{ik}^2 }{ r_{ik}^5} ~ s_{i}\qquad \text{(eqn:SSCC_SD)} \]

    虽然费米接触项通常最重要， 但所有贡献都可在 ORCA 的 HF 和 DFT 理论水平下计算。 为此，需在 eprnmr 输入块中调用关键词 ssall， 而四个项可分别用 ssdso、sspso、ssfc 和 sssd 请求。例如：

    Nucleus  Element    Isotropic     Anisotropy
  -------  -------  ------------   ------------
      0       C          229.484         59.356
      1       C          227.642         62.878
      2       H           56.015         12.469
      3       H           55.460         15.284
      4       H           55.460         15.284
      5       O          334.125        110.616
      6       H           47.337         27.101
      7       H           47.337         27.101
      8       H           64.252         32.114

    结果以 Hz 给出。请注意，默认使用的同位素 可能不是计算 NMR 性质所期望的， 因此建议用 ist 标志定义相应的同位素。 也可以用标志 PrintReducedCoupling=True 打印约化耦合常数 \(K\)（单位为 \(10^{19}\cdot\mathrm T\cdot \mathrm J^{-2}\)）， 它与核同位素无关。

    CP-SCF 方程必须对每一对中的一个核求解，是计算的瓶颈。 因此，自旋-自旋耦合常数只在彼此距离一定范围内 （默认 5 埃）的核之间计算。 后者可用关键词 SpinSpinRThresh 更改。

    若请求了多个核素，也可用关键词 SpinSpinElemPairs 只选择某些元素对（例如只选 C--H 和 H--H，不含 C--C）。 类似地，关键词 SpinSpinAtomPairs 选择要考虑的实际核对。 后两选项的并集用于缩减用 Nuclei 输入所做的选择， 之后再应用 SpinSpinRThresh。

    模拟 NMR 谱（Simulating NMR Spectra）¶

    由计算得到的 NMR 屏蔽和自旋-自旋耦合常数， 可以模拟耦合的 NMR 谱。 最典型的 NMR 实验是去耦的 \(^{13}\)C 谱和耦合的 \(^1H\) 谱， 因此这里我们聚焦于这两种。 为模拟完整的 NMR 谱，我们以巴豆酸乙酯为例， 需要三个步骤：1) 计算自旋-自旋耦合常数， 2) 计算化学位移屏蔽，3) 用自旋哈密顿量形式模拟谱图。 请注意，这些步骤可以独立进行， 屏蔽和耦合可以使用不同的理论水平， 且步骤 1 和 2 的顺序无关紧要。

    此外，若谱图要以 TMS 为参考进行模拟， 则需要 TMS 的屏蔽值（此处氢和碳的值分别为 31.77 和 188.10 ppm）。 下面是耦合常数计算的输入，命名为 ethylcrotonate_sscc.inp：

    orca_nmrspectrum ethylcrotonate_nmr.gbw ethylcrotonate.nmrspec > output

    \[ {H}_{NMR}(p,q)= \sigma_{p} \delta_{pq} + J_{pq} I_p I_q.\qquad \text{(eqn:effNMRspinH)} \]

    与核无关的化学位移（Nucleus-independent chemical shielding）¶

    芳香性是化学中的一个基本概念， 其分析在量子化学中备受关注。 理解芳香性的一种可能是 在 \(\pi\) 体系附近采样 NMR 中的环电流效应。 由于这不是通过检查任何原子的化学位移来完成的， 该量称为与核无关的化学位移（nucleus independent chemical shielding，NICS）。 通常，一个"哑"原子被放在环的中心和/或距环一定距离处。 在 ORCA 中，需要使用虚原子（ghost atom），例如 "H:"， 以确保程序在感兴趣的区域生成 DFT 或 COSX 网格点。 出于技术原因，该原子也必须至少有一个基函数， 可用 NewGTO 设置。 一个指数足够大的 s 函数不会与分子中任何其他基函数重叠， 因此不会影响结果，只是满足技术要求 （请注意，额外的网格点可能通过提高数值积分精度 改变部分计算结果）。 若使用 RI，还必须向 AuxJ、AuxJK 和/或 AuxC 基组添加哑拟合函数。 苯的典型输入如下：

    屏蔽张量的轨道分解（Shielding tensor orbital decomposition）¶

    可以将 NMR 屏蔽张量分解为轨道或轨道对贡献。 一种选择是自然化学位移（Natural Chemical Shielding）分析 （参见 nbo.ncsanalysis 一节）， 这里介绍另一种。 核 \(A\) 的屏蔽张量可精确分解如下：

    \[ \begin{aligned} \sigma^A &= \sum_{p}\left( \sigma^{A,\text{para} }_p + \sigma^{A,\text{dia} }_p \right)\\ \sigma^{A,\text{para/dia} }_i &= \sigma^{A,\text{para/dia} }_{ii} +\frac{1}{2}\sum_{j\ne i}\left( \sigma^{A,\text{para/dia} }_{ij} + \sigma^{A,\text{para/dia} }_{ji} \right) +\sum_{a}\left( \sigma^{A,\text{para/dia} }_{ia} + \sigma^{A,\text{para/dia} }_{ai} \right)\\ \sigma^{A,\text{para/dia} }_a &= \sigma^{A,\text{para/dia} }_{aa} +\frac{1}{2}\sum_{b\ne a}\left( \sigma^{A,\text{para/dia} }_{ab} + \sigma^{A,\text{para/dia} }_{ba} \right) \\ \sigma^{A,\text{para} }_{pq} &= D^B_{pq} h^{M_A}_{pq} \\ \sigma^{A,\text{dia} }_{pq} &= D_{pq} h^{B,M_A}_{pq} \\ D_{pq} &= \sum_{\mu\nu\kappa\lambda} c_{\mu p} S_{\mu\nu} D_{\nu\kappa} S_{\kappa\lambda} c_{\lambda q} \\ D^B_{pq} &= \sum_{\mu\nu\kappa\lambda} c_{\mu p} S_{\mu\nu} D^B_{\nu\kappa} S_{\kappa\lambda} c_{\lambda q} \\ h^{M_A}_{pq} &= \sum_{\mu\nu} c_{\mu p} h^{M_A}_{\mu\nu} c_{\nu q} \\ h^{B,M_A}_{pq} &= \sum_{\mu\nu} c_{\mu p} h^{B,M_A}_{\mu\nu} c_{\nu q}\end{aligned} \]

    请注意，对于 SCF 方法（HF 或 DFT）， \(\sigma^{A,\text{para/dia} }_a=0\)。 要请求该分析，必须用关键词 LocOrbGBW 给出有效的 GBW 文件， 其中可含同一基下的任何正交归一 MO， 例如正则轨道或定域轨道， 不过上述分解假定布里渊条件成立， 若对例如 NBO 执行可能会有误导。 打印超过 0.01 ppm 的轨道贡献——目前用户不可配置。 分离的轨道对贡献也可用 Printlevel=3 打印。 下面的示例输入为甲醛计算 HF 和 RI-MP2 屏蔽， 并将其分解到 Pipek--Mezey 定域轨道上 （注意虚轨道可能定域得不好——AHFB 在那里更合适）。 第二个子计算只是打印 LMO，以便用 Avogadro 方便地可视化。

    ! PBE pcJ-3 autoaux tightscf  
*xyzfile 0 1 ethylcrotonate.xyz
%eprnmr

end

    Meta-GGA 泛函中 Tau 的处理¶

    对于基于 GIAO 的 meta-GGA 计算， 动能密度 \(\tau\) 有不同的可选方案。 与流无关的 \(\tau_0\) 不是规范不变的。 忽略产生规范依赖性的那些项， 会导出一种特设的规范不变处理（直到 ORCA 5 这一直是默认）。 Maximoff 和 Scuseria 提出了一种含外磁场显式依赖的 规范不变定义 \(\tau_\text{MS}\)。Maximoff2004 然而，该拟设会对屏蔽张量产生非物理的顺磁贡献。Schattenberg2021 最后一种方案由 Dobson 引入 Dobson1993， 它是规范不变的，但即使对纯密度泛函也需要求解 CP-SCF 方程。 关于这些方案的讨论和比较见参考文献 Bates2012（在 TDDFT 语境下） 和 Reimann2015,Schattenberg2021（在 NMR 屏蔽语境下）。 请注意，不同方案计算得到的屏蔽可能相差很大！ 其他一些电子结构程序默认使用 MS 拟设， 因此在比较不同代码的结果时要小心。 在 ORCA 中，基于 GIAO 的计算中 \(\tau\) 的处理选择如下

    %eprnmr 
  Tau 0      # gauge-variant
      GI     # ad-hoc gauge-invariant
      MS     # field-dependent, gauge-invariant version of Maximoff and Scuseria
      Dobson # (default) current density-dependent, gauge-invariant version
             # of Dobson
  end

    EPR 和 NMR 张量的笛卡尔指标约定（Cartesian Index Conventions）¶

    NMR 屏蔽张量 \(\sigma\) 以及 EPR \(g\) 和 \(A\) 张量 一般是非对称矩阵。因此了解其笛卡尔指标的约定很重要。 这些约定规定了各自自旋哈密顿量中矢量-矩阵-矢量乘法的顺序。 除非另有说明，ORCA 采用如下约定： 对于 NMR 屏蔽张量，核塞曼哈密顿量取如下形式：

    \[ H_{\!I} = -g_N\beta_NB(1 - \sigma)I, \]

    其中 \(B\) 是外加磁场矢量。 对于 EPR \(g\) 和 \(A\) 张量，EPR 自旋哈密顿量取如下形式：

    \[ H_S = \beta_e BgS + SAI.\qquad \text{(eq:g_A_convention)} \]

    顺磁 NMR 屏蔽张量（Paramagnetic NMR Shielding Tensors）¶

    对于自旋 \(S>0\) 的体系，核屏蔽包含一项来自 未配对电子顺磁性的贡献。3 该项依赖于温度，称为"顺磁屏蔽"（\(\sigma^\mathrm{p}\)）。 它加到与温度无关的屏蔽贡献（也称为"轨道"贡献）上：

    \[ \sigma = \sigma^\mathrm{orb} + \sigma^\mathrm{p}. \]

    ORCA 目前支持对顺磁性可用有效 EPR 自旋哈密顿量描述的体系 计算 \(\sigma^\mathrm{p}\)：

    \[ H_S = SDS + \beta_e BgS + SAI.\qquad \text{(eq:pnmr_SHam)} \]

    理论背景见参考文献 VandenHeuvel2013,Soncini2013。这里我们复述主要方程。

    对于由式 Eq 描述的自旋态， 顺磁屏蔽张量由下式给出

    \[ \sigma^\mathrm{p} = -\frac{\beta_e S(S+1) }{g_N\beta_N 3kT} gZA,\qquad \text{(eq:pnmr_sigma)} \]

    其中 \(Z\) 是一个无量纲的 \(3\times3\) 矩阵， 由 ZFS 和温度确定，如下： 对角化 ZFS 哈密顿量 \(SDS\) 得到能级 \(E_\lambda\) 和本征态 \(|S\lambda a\rangle\)， 其中若 \(E_\lambda\) 简并，则 \(a\) 标记简并态。 然后 \(Z\) 定义为（\(i,j=x,y,z\)）

    \[ \begin{gathered} Z_{ij} = \frac{3}{S(S+1) }\frac{1}{Q_0} \sum_\lambda e^{-E_\lambda/kT} \Bigg[\sum_{a,a'}\langle S\lambda a|S_i|S\lambda a'\rangle\langle S\lambda a'|S_j|S\lambda a\rangle\\ +2kT\sum_{\lambda'\neq\lambda}\sum_{a,a'} \frac{\langle S\lambda a|S_i|S\lambda' a'\rangle\langle S\lambda' a'|S_j|S\lambda a\rangle }{E_{\lambda'}-E_\lambda} \Bigg],\end{gathered} \]

    其中 \(Q_0 = \sum_{\lambda',a} e^{-E_\lambda/kT}\) 表示配分函数。 按上式定义的 \(Z\) 矩阵的一个重要性质是： 当 \(D/kT\) 趋于零时，它趋于单位矩阵。

    屏蔽的轨道部分 \(\sigma^\mathrm{orb}\) 按与闭壳层分子相同的方式计算。 它在 ORCA 中适用于非限制 HF 和 DFT 方法以及 MP2 （关于后者，更多信息见 eprnmr.MP2magnetic 一节）。

    orca_pnmr 工具使用式 [eq:pnmr_sigma]{reference-type="eqref" reference="eq:pnmr_sigma"} 来计算 \(\sigma^\mathrm{p}\)。 orca_pnmr 的用法见 utilities.pnmr 一节。

    自旋-转动常数（Spin-rotation Constants）¶

    自旋-转动常数的计算按照 Gauss1996_spinrot 采用依赖于微扰的原子轨道实现。 如该文献式 34 所给，核 \(K\) 的自旋-转动张量 \(M_K\)， 与用 GIAO 计算的核屏蔽张量 \(\sigma_K^\text{GIAO}\)、 以及规范原点设在该核处的屏蔽张量抗磁部分 \(\sigma_K^\text{dia}(R_K)\) 相关联：

    \[ M_K = 2 \gamma_K \left( \sigma_K^\text{GIAO} - \sigma_K^\text{dia}(R_K) \right) I^{-1} - M_K^\text{nuc} \]

    其中 \(M_K^\text{nuc}\) 是核分量（见该文献式 14）， \(I\) 是惯量张量，\(\gamma_K\) 是核旋磁比。 因此，当请求自旋-转动常数时，ORCA 也会自动用 GIAO 计算 NMR 屏蔽。 请注意，eprnmr 模块的完整关键词列表见 properties.eprnmr。

    下面的输入展示了 H{sub}212C{sup}17O 中 \(M(^{17}\text{O})\) 的示例计算：

    • 计算惯量张量所用的质量与所选同位素无关！ 上面的例子通过 Mass2016 关键词请求最丰度同位素的原子质量， 并显式指定 {sup}12C（这是默认）和 {sup}17O 的质量。

      #         and spin-rotation constants (overrides ist)

  # For example:
  # calculates the hyperfine coupling for all nitrogen atoms
  Nuclei = all N { aiso, adip, fgrad, rho};

  # calculates the spin-spin coupling constants for all carbon atoms
  # assuming all carbon atoms are 13C
  Nuclei = all C { ssall, ist = 13};

  # You can also calculate properties for individual atoms
  # as in the following example:
  Nuclei = 1,5,8 { aiso, adip};

  # NOTE: Counting starts with atom 1!
  # WARNING: All the nuclei, mentioned in one line 
  # as above will be assigned the same parameters !

  # For spin-spin coupling constants, a distance threshold is 
  # applied in the eprnmr block to restrict the number of couplings
  # to be computed, given in Angstroms:
  SpinSpinRThresh 5.0 # default

  # Coupling can be restricted to certain element pairs
  # (if they are added to the "Nuclei" list and are within RThresh).
  # The syntax accepts multiple pairs of element symbols or
  # atomic numbers or "*" as a wildcard
  SpinSpinElemPairs {C C} {H *} {6 7} # default is {* *}, i.e. all

  # Similarly, coupling can be restricted to certain atom pairs
  # (if they are added to the "Nuclei" list and are within RThresh).
  # The syntax accepts multiple pairs of indices (starting at 0!)
  # or "*" as a wildcard
  SpinSpinAtomPairs {1 0} {5 *} # default is {* *}, i.e. all

  # whether to print reduced spin-spin coupling constants
  PrintReducedCoupling false

  end
