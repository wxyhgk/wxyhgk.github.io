    DeltaSCF¶

    DeltaSCF 是含时 DFT 的一种不含时替代方法，用于在平均场 DFT 框架内描述激发电子态， 已有研究表明，对于乙烯分子（光化学的典型范例）中避免交叉和圆锥交叉的拓扑结构， 它比常用线性响应绝热近似下的 TDDFT 给出更好的结果Schmerwitz2022； 对于电荷转移激发态也是如此——TDDFT 的绝对误差随电荷转移距离迅速增大， 而 DeltaSCF 可给出均衡的描述Selenius2024。

    通常，SCF 过程用于获得基电子态，即能量面关于电子轨道旋转自由度上的一个极小值。 \(\Delta\)SCF 的思想是收敛到电子能量面上一个更高能量的解（通常是一个鞍点）， 以找到激发电子态的平均场表示。由于仅仅形成一个接近该激发态解的初始猜测 并使用常规 SCF 方法通常是不够的，人们在 ORCA 中开发并实现了多种策略， 使 SCF 收敛到目标鞍点并防止所谓的变分坍缩（variational collapse）—— 即收敛到不需要的低能量解。

    Peter Gill 课题组gilbert_self-consistent_2008 引入了一种简单但往往有效的方法， 即最大重叠法（Maximum Overlap Method，MOM）。在 ORCA 中，我们还提供了 Hrant Hratchian 课题组较新的 PMOMcorzo_using_2022。此外，ORCA 还提供了一种 SOSCF 优化技术，它利用有限内存对称秩 1 拟牛顿方法， 以及广义模式追踪（generalized mode following）方法，两者都能系统地 收敛到鞍点解。激发态初始猜测可以通过 freeze-and-release SOSCF 策略中的 约束优化来细化。\(\Delta\)SCF 也被称为 "用于电子激发态的轨道优化 DFT"（orbital optimized DFT for electronic excited states）Hait2021 和"激发态平均场理论"（excited state mean-field theory）Hardikar2020。

    图 fig:deltascf_basics 展示了 \(\Delta\)SCF 中一般 HOMO-LUMO 激发的示意图。首先，通过常规 SCF 计算获得基态。然后， 将占据数改变为反映目标激发的非 aufbau 占据。 对于 HOMO-LUMO 激发，选择两个自旋通道之一的 HOMO 使其空出， 而 LUMO 被占据。这种非 aufbau 占据连同基态轨道一起 作为变分鞍点搜索的初始猜测，从而得到 \(\Delta\)SCF 激发态解。

    ../../images/deltascf_basics.*

    使用 \(\Delta\)SCF 的 HOMO-LUMO 激发态的简单示意图

    使用 ORCA 的 DeltaSCF，我们可以选择将 SCF 收敛到 HOMO/LUMO 激发态。 激发态通过完全弛豫轨道获得，可以包含任何贡献，例如 VV10 相关或 CPCM 溶剂化。由于波函数的变分优化， Hellman-Feynman 定理成立，这意味着可以得到原子核位置上的梯度， 从而可用于几何优化、分子动力学模拟、反应路径计算 以及 ORCA 提供的所有其他几何搜索功能。此外，ORCA 用基态 SCF 密度计算的所有性质也都可以用激发态 \(\Delta\)SCF 密度计算。

    Warning

    \(\Delta\)SCF 态由 DFT 框架内的单行列式波函数表示。 正如基态 DFT 在多行列式情形下会遇到困难一样，激发态 DFT 也是如此。 处理这类情形时请牢记这一点！

    例如，这种描述在以下情况下相对合理： 1. 激发态可以用粒子-空穴相互作用描述。例如，苯分子的 HOMO-LUMO 激发 或大多数 \(\pi\)-\(\pi^{*}\) 激发态不属于这种情况， 2. 占据轨道和虚拟轨道在空间上分离，使得相关交换积分为零。 例子包括某些 \(n\)-\(\pi^{*}\) 态、长程电荷转移态等， 3. 对于可用单行列式波函数表示的闭壳层双激发态。

    此外，\(\Delta\)SCF 波函数可能破坏哈密顿量的对称性（这对基态和 激发态都成立）。开壳层单重激发态本身就破坏自旋对称性， 需要自旋纯化Ziegler1977。

    理论（Theory）¶

    本节讨论 \(\Delta\)SCF 方法背后的理论。

    SOSCF L-SR1 方法（SOSCF L-SR1 method）¶

    在 \(\Delta\)SCF 中，人们寻找能量面关于电子轨道旋转自由度的驻点， 这些自由度收集在轨道旋转矩阵中

    \[ \kappa = \begin{pmatrix}\kappa_{\mathrm{oo}} = 0 & \kappa_{\mathrm{ov}}\\ -\kappa_{\mathrm{ov}}^{+} & \kappa_{\mathrm{vv}} = 0\end{pmatrix}\,, \]

    其中 oo、ov 和 vv 分别表示 \(\kappa\) 中包含混合两个占据轨道、 一个占据与一个虚拟轨道、以及两个虚拟轨道的成对轨道旋转的块。 驻点由下式求得

    \[ C_{\mathrm{stat}} = C_{0}e^{\kappa}\,, \]

    能量梯度为

    \[ \frac{\partial E}{\partial \kappa_{ij}} = \frac{2 - \delta_{ij}}{2}\left[\in t_{0}^{1}dte^{t\kappa}Le^{-t\kappa}\right]_{ji} = \frac{2 - \delta_{ij}}{2}\left[L + \frac{1}{2!}\left[\kappa, L\right] + \frac{1}{3!}\left[\kappa, \left[\kappa, L\right]\right] + ...\right]_{ji}\,, \]

    其中右边是 Baker-Campbell-Hausdorff 公式的一个特例，之所以成立 是因为 \(\kappa\) 的空间构成其指数所对应李群的李代数。 由于梯度对 \(\kappa_{\mathrm{oo}}\) 和 \(\kappa_{\mathrm{vv}}\) 的所有元素总是为零， 这些 \(\kappa\) 块在优化中被丢弃为自由度。 由于要求 \(e^{\kappa}\) 是幺正的， \(\kappa\) 必须是反厄米的，这又在优化中丢弃了 若干轨道旋转自由度。

    鞍点搜索使用 L-SR1 拟牛顿优化器进行，它能够形成不定模型 Hessian， 从激发态初始猜测开始。为提高方法的性能并使其更稳健， 使用了以下标准 SOSCF 预条件子，并允许其也变为不定的：

    \[ \frac{\partial^{2}E}{\partial \kappa_{ij}^{2}} \approx 2\left(f_{j} - f_{i}\right)\left(\epsilon_{i} - \epsilon_{j}\right)\,, \]

    其中 \(f_{i}\) 是轨道 \(i\) 的占据数，\(\epsilon_{i}\) 是其能量。

    广义模式追踪（Generalized Mode Following）¶

    广义模式追踪（GMF）方法Schmerwitz2023,Schmerwitz2024b 是一种更稳健 但也稍贵一些的鞍点搜索方法，可用于收敛到 \(\Delta\)SCF 激发态解。 该方法通过修改梯度将鞍点搜索重新表述为极小化问题， 使得它对应于一个修改后的目标函数，该函数在能量函数具有 目标鞍点处取得极小值。现在可以执行极小化来定位 对应于目标激发态的目标鞍点，这意味着可以使用稳健的 L-BFGS 优化器代替 L-SR1 优化器，预条件子可以设为正定的， 而且通过构造，变分坍缩到目标之外的低能量解变得不可能， 因此 GMF 不需要 MOM。为此，需要在计算开始时估计目标解的 鞍点阶数 \(n\)，并且在每个电子优化步骤中需要用有限差分 Davidson 方法求电子 Hessian 的最低 \(n\) 个本征对。

    一旦在每个优化步骤求得电子 Hessian 的最低 \(n\) 个本征向量 \(v_{i}\)， 修改后的梯度按下式计算

    \[ g^{\mathrm{\,mod}} = g - 2\sum_{i = 1}^{n}v_{i}v_{i}^{\mathrm{T}}g\,. \]

    Freeze-and-release 策略（Freeze-and-release strategy）¶

    在棘手的情形下，特别是激发导致大量电荷转移时， 改用 freeze-and-release SOSCF 策略Schmerwitz2025 可能更为有利， 它分两步收敛 DeltaSCF：

    1. 约束优化，冻结所有被激发的轨道，即占据数与 aufbau 占据不同的那些轨道。 这一步对未受约束的轨道归结为极小化。

    2. 像往常一样进行无约束优化。

    第 1 步考虑了激发后电子密度一阶变化对未参与激发的轨道的轨道弛豫效应。 它可以看作是为第 2 步激发态鞍点搜索生成优质初始猜测的一种精细方式。

    让我们从尝试收敛到甲醛的第一激发态并在该电子态下优化几何结构开始， 从常规平面结构出发：

    除了常规关键词（如方法、基组、OPT 和 FREQ）外，需要在简单输入中 指定 DELTASCF，本例中还需要 UHF，因为由于单激发，alpha 和 beta 轨道将会不同（对于双激发态 RHF 可能就足够了）。

    还需要在 %SCF 块下添加 ALPHACONF 或 BETACONF。这是您想要收敛到的 组态的最小表示。本例中，0,1 表示 HOMO/LUMO 跃迁，其中 HOMO 占据为零、 LUMO 占据为一。对于 HOMO-1/LUMO 跃迁，应为 ALPHACONF 0,1,1。 对于 HOMO/LUMO+1，应为 ALPHACONF 0,0,1，依此类推。 只要想象一下前线轨道的占据应该是什么样即可。 第一个零以下的任何轨道都被假定为占据，最后一个占据以上的任何轨道 都被假定为空。

    常规启动之后，\(\Delta\)SCF 特有的打印显示：

    在这里您可以跟踪初始组态以及其他一些重要事项：

    1. Hessian update 指的是用于 SOSCF Hessian 更新的方法。ORCA 的默认值是 L-BFGS，它强制电子 Hessian 为正定，并且总是将体系推向极小值。 由于我们要去鞍点，DeltaSCF 默认设置 L-SR1。关于 Hessian 更新 及其后果的更多细节见 Hannes Jónsson 课题组的这篇参考文献Levi2020b。

    2. Aufbau metric 是衡量实际波函数与参考波函数之间"重叠"的方式 （更多细节见 corzo_using_2022）。默认是 MOM， 但也可以设置 %SCF PMOM TRUE END 来使用 PMOM。

    3. Keep initial reference TRUE 意味着我们将始终尝试保持 guess 阶段 之后定义的初始参考态。这在文献中有时称为 IMOM barca_simple_2018。如果设置了 %SCF KEEPINITIALREF FALSE END， 则总是取最后一次 SCF 迭代作为参考。

    Warning

    这里我们使用 PMODEL 猜测的轨道，因为它很简单。一般而言， 我们建议始终通过读取先前收敛的基态 SCF 轨道来启动 SCF！ 请查看 initialguess.restart 获取更多信息。

    芯电离态（Core-ionized States）¶

    \(\Delta\)SCF 的另一个大优点是可能收敛到芯激发和/或芯电离态。 我们有一个简单关键词可以从任何轨道（甚至是深层芯轨道）移除电子：

    %SCF IONIZEALPHA 2 END

    透热耦合（Diabatic Couplings）¶

    \(\Delta\)SCF 也是获得透热耦合的一种相当精确的方法， 这些耦合随后可用于 Marcus 理论计算电子转移速率。 它们可以通过计算电子转移态之间的能量差并使用 广义 Mulliken-Hush 方法（GMH）来计算。 更多细节请参考例如 Blumberger 课题组的这篇论文 kubas_electronic_2014。

    这里没有足够的篇幅详述细节，但基本上可以通过一次常规基态 SCF 加一次激发态 \(\Delta\)SCF 来获得这些透热耦合。 对于对称体系，这是简单的：

    \[ 2|H_{ab}| = \Delta E_{12} \]

    其中态 \(a\) 和 \(b\) 是透热态，\(\Delta E_{12}\) 是绝热态 \(1\) 和 \(2\) 之间的能量差（通过 SCF 解获得）。下面是苯二聚体透热耦合的例子， 通过从基态阳离子开始并激发 beta 电子获得：

    %SCF BETACONF 0,1 END

    \(\Delta\)SCF 使用 wB97M-V/DEF2-TZVPP 得到的透热耦合，单位 meV。

    通常，freeze-and-release 方法比常规 SOSCF 多需要几次迭代， 但它能更可靠地避免变分坍缩。在所展示的情形中，常规 SOSCF 总共需要 38 次能量/梯度评估收敛，而 freeze-and-release 策略 只需要 21 次能量/梯度评估。

    Note

    Scaled step length from x to 0.100000 这句话表示即将采取 一个相对较大的步长。将其缩小通常会导致更稳健但效率较低的收敛。 可以根据所研究体系的挑战进行调整。

    freeze-and-release 策略可以与 GMF 结合，产生更稳健的策略。 在这种情况下，目标鞍点阶数在约束极小化步的解处估计， 因为此时估计的质量更高。对于杂化泛函，默认估计在第一次 Davidson 运行中获得。否则，使用轨道能。
