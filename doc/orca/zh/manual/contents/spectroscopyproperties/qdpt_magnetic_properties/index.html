    通过准简并微扰理论计算磁性质（Magnetic Properties Through Quasi Degenerate Perturbation Theory）¶

    准简并微扰理论（QDPT）简介¶

    准简并微扰理论（Quasi Degenerate Perturbation Theory，QDPT） 为几乎所有基于波函数的激发态方法的多种磁性质 提供了一种通用且准确的途径。

    简言之，在非相对论极限下， 对任何单参考或多参考的激发态波函数方法 （以 CASSCF、MRCI 或 ROCIS 型的零级波函数为基础）， 都可以建立一个激发问题， 它是零级波函数与激发的自旋适配组态状态函数 （configuration state functions，CSF）\(\left| \Phi_{\mu}^{SS} \right \rangle\) 的组合。

    其形式为：

    \[ \left| \Psi_{I}^{SS} \right\rangle= \sum\nolimits_{\mu} { C_{\mu l} \left| \Phi_{\mu}^{SS} \right \rangle }\qquad \text{(eqn:H_BO)} \]

    这里上标 \(SS\) 表示自旋量子数为 \(S\)、 自旋投影 \(M_{S} = S\) 的波函数。 由于 BO 哈密顿量不含任何复值算符， 解 \(\left| \Psi_{I}^{SS}\right\rangle\) 可取为实值。

    求解上述本征值问题可给出 CSF 进入所选波函数的系数， 以及无自旋算符的本征态。 这些本征态可通过建立相应的准简并本征值问题 来向相对论本征态展开。 事实上，自旋-轨道耦合（SOC）和自旋-自旋耦合（SSC）效应 连同塞曼相互作用都可以通过准简并微扰理论（QDPT）纳入。 在这一途径中，SOC、SSC 和塞曼算符 在预先选定的 BO 哈密顿量解 \(\left\{{ \Psi_{I}^{SM} }\right\}\) 的基下计算。

    \[ \left\langle { \Psi_{I}^{SM} \left|{ \hat{{H} }_{\text{BO} } +\hat{{H} }_{\text{SOC} } +\hat{{H} }_{\text{SSC} } +\hat{{H} }_{\text{Z} } } \right|\Psi_{J}^{{S}'{M}'} } \right\rangle=\delta_{IJ} \delta_{S{S}'} \delta_{M{M}'} E_{I}^{\left( S \right)} +\left\langle { \Psi_{I}^{SM} \left|{ \hat{{H} }_{\text{SOC} } +\hat{{H} }_{\text{SSC} } +\hat{{H} }_{\text{Z} } } \right|\Psi_{J}^{{S}'{M}'} } \right\rangle\qquad \text{(eqn:H_QDPT)} \]

    该矩阵的对角化给出耦合态的能级和本征矢。 这些本征矢实际上是 \(\hat{{H} }_{\text{BO} }\) 的解 以复系数构成的线性组合。

    二次量子化形式的有效单电子 SOC 算符可写为 neese2005jchemphys：

    \[ \hat{{H} }_{\text{SOMF} } =\frac{1}{2}\sum\limits_{pq} { z_{pq}^{-} \hat{{a} }_{p}^{\uparrow } \hat{{b} }_{q} +z_{pq}^{+} \hat{{b} }_{p}^{\uparrow } \hat{{a} }_{q} +z_{pq}^{0} \left[{ \hat{{a} }_{p}^{\uparrow } \hat{{a} }_{q} -\hat{{b} }_{p}^{\uparrow } \hat{{b} }_{q} } \right]}\qquad \text{(eqn:H_SOMF)} \]

    其中，\(\hat{{a} }_{p}^{\uparrow }\) 和 \(\hat{{b} }_{p}^{\uparrow }\) 分别表示 \(\alpha\) 和 \(\beta\) 电子的产生； \(\hat{{a} }_{p}\) 和 \(\hat{{b} }_{p}\) 表示相应的湮灭算符。 矩阵元 \(z_{pq}^{-} = z_{pq}^{x} - iz_{pq}^{y}\)、\(z_{pq}^{+} = z_{pq}^{x} + iz_{pq}^{y}\) 以及 \(z_{pq}^{0} = z_{pq}^{z}\) （上标 \(x\)、\(y\)、\(z\) 表示笛卡尔分量） 由 epr.D 一节所述的矩阵元构建。

    在这一框架下，SOC 哈密顿量为：

    \[ \left\langle {{\Psi}_I^{SM}\left|{ \hat{{H} }_{\text{SOC} } } \right|{\Psi}_J^{S^\prime M^\prime}} \right\rangle= \sum_{m=0,\pm1}\left(-1\right) \left( \begin{matrix}S^\prime&1\\M^\prime&m\\\end{matrix} \left|{\begin{matrix} S\\ M\\ \end{matrix} } \right. \right) \underset{Y_{II^\prime}^{SS^\prime}(m)}{\underbrace{\left\langle {{\Psi}_I^{SS}||H_{-m}^{SOC}||{\Psi}_J^{SS}} \right\rangle}}\qquad \text{(eqn:H_SOC)} \]

    其中 \(m\) 代表标准矢量算符分量。 \(\left( \begin{matrix}S^\prime&1\\M^\prime&m\\\end{matrix} \left|{\begin{matrix} S\\ M\\ \end{matrix} } \right. \right)\) 是 Clebsch–Gordon 系数， 它是一个有表可查的确定数值。 它满足一定的选择定则，并包含 SOC 矩阵元对 M 的全部依赖关系。 量 \(Y_{II^\prime}^{SS^\prime}(m)\) 是约化矩阵元。 它只依赖于所涉及两个态的标准分量。 \(Y_{II^\prime}^{SS^\prime}(m)\) 只有三种非零情形， 来自总自旋相同或相差一个单位的态对。neese1998inorgchem

    SSC 哈密顿量为：

    \[ \hat{{H} }_{\text{SSC} } =-\frac{3g_{e}^{2} \alpha^{2} }{8}\sum\limits_{i\ne j} {\sum\limits_{m=0,\pm 1,\pm 2} { \frac{\left({ -1} \right)^{m} }{r_{ij}^{5} } } \left[{ \mathrm{r }_{ij} \times \mathrm{r }_{ij} } \right]_{-m}^{\left( 2 \right)} \left[{ \mathrm{S }\left( i \right)\times \mathrm{S }\left( j \right)} \right]}_{m}^{\left( 2 \right)}\qquad \text{(eqn:H_SSC)} \]

    对于相同多重度的态之间的矩阵元，它可简化为

    \[ \begin{array}{l} \left\langle { aSM\left|{ \hat{{H} }_{\text{SSC} } } \right|a'SM'} \right\rangle=\frac{\sqrt{ \left({ S+1} \right)\left({ 2S+3} \right)} }{\sqrt{ S\left({2S-1} \right)} } \\ \hspace{2cm} \times \sum\limits_m { \left({ -1} \right)^{m} } \left(\begin{matrix}{ S'} & 2 \\ { M'} & m \end{matrix} \left|{\begin{matrix} S \\ M \\ \end{matrix} } \right. \right) \sum\nolimits_{pqrs} { D_{pqrs}^{\left({ -m} \right)} \left\langle { aSS\left|{ Q_{pqrs}^{0} } \right|a'SS} \right\rangle} \end{array}\qquad \text{(eqn:SSC_RMEs)} \]

    其中，

    \[ Q_{pqrs}^{\left( 0 \right)} =\frac{1}{4\sqrt 6 }\left\{{ E_{pq} \delta _{sr} -S_{ps}^{z} S_{rq}^{z} +\frac{1}{2}\left({ S_{pq}^{z} S_{rs}^{z} -E_{pq} E_{rs} } \right)} \right\}\qquad \text{(eqn:Qpqrs)} \]

    代表双电子五重态密度。 算符 \(E_{pq}=\hat{{a} }_{p}^{\uparrow } \hat{{a} }_{q} +\hat{{b} }_{p}^{\uparrow } \hat{{b} }_{q}\) 和 \(S_{pq}^{z} =\hat{{a} }_{p}^{\uparrow } \hat{{a} }_{q} -\hat{{b} }_{p}^{\uparrow } \hat{{b} }_{q}\) 分别表示单电子密度算符和自旋密度算符。 空间部分

    \[ D_{pqrs}^{\left( 0 \right)} =\frac{1}{\sqrt 6 }\iint{ \varphi_{p} \left({ \mathrm{r }_{1} } \right)\varphi_{r} \left({ \mathrm{r }_{2} } \right)}\frac{3r_{1z} r_{2z} -\mathrm{r }_{1} \mathrm{r }_{2} }{r_{12}^{5} }\varphi_{q} \left({ \mathrm{r }_{1} } \right)\varphi _{s} \left({ \mathrm{r }_{2} } \right)d\mathrm{r }_{1} d\mathrm{r }_{2}\qquad \text{(eqn:Dpqrs)} \]

    表示双电子场梯度积分。 这些双电子积分可用 RI 近似评估。

    最后，塞曼哈密顿量以下述形式纳入：

    \[ \hat{{H} }_{\text{Z} } =\mu_{B} \left({ \mathrm{\hat{{L} } }+g_{e} \mathrm{\hat{{S} } }} \right)\mathrm{B }\qquad \text{(eqn:H_Zeeman)} \]

    其中 \(\mathrm{\hat{{L} }}\) 表示总轨道动量算符， \(\mathrm{\hat{{S} }}\) 为总自旋算符。

    在这一框架下，求解所选相对论哈密顿量可获得众多磁性质， 即 EPR 性质（properties.eprnmr） 以及磁化率和磁化强度性质 （soc.magnet）。 此外，监测外磁场对相对论本征态和本征矢的影响 （soc.magField）也变得简单直接。

    总体而言，在 QDPT 框架下可获得以下磁性质：

    • 常见 QDPT 磁性质

    (1) g 张量/矩阵 \ (2) D 张量/矩阵（零场分裂，ZFS） \ (3) A 张量/矩阵（超精细，HFC） \ (4) 电场梯度 \ (5) 磁化强度 \ (6) 磁化率 \ (7) 外磁场的纳入

    • 特殊处理还包括

    (8) 用二阶态求和（sum-over-states）近似的 g 张量/矩阵和 A 张量/矩阵 \ (9) spectroscopyproperties.magrelax 功能

    通过有效哈密顿量计算磁性质¶

    由于低能自旋-轨道态的能量和波函数都可获得， 有效哈密顿量理论可用于提取 EPR 参数， 如完整的 g 张量、零场分裂（Zero Field Splitting，ZFS） 和超精细 A 张量。

    前提是基态非简并。通过在模型空间 （即基态的 \(|S, M_S\rangle\) 分量）的基下作用该哈密顿量， 构建相互作用矩阵。

    有效哈密顿量的构建依赖于低能自旋-轨道态的能量和波函数两方面所含的信息。 按照 des Cloizeaux 形式，有效哈密顿量重现"精确"哈密顿量的能级 \(E_k\) 以及低能态投影到模型空间的波函数 \(\tilde{\Psi}\)：

    \[ \hat{H}_{\text{eff} }|\tilde{\Psi}_{k}\rangle = E_{k}|\tilde{\Psi}_{k}\rangle \]

    然后对这些投影矢量作对称正交归一化， 得到厄米的有效哈密顿量，可写为：

    \[ \hat{H}_{\text{eff} }|\tilde{\Psi}\rangle = \sum_{k}|S^{-\frac{1}{2} }\tilde{\Psi}_{k}\rangle E_{k} \langle S^{-\frac{1}{2} }\tilde{\Psi}_{k}| \]

    将该哈密顿量在属于模型空间的行列式基下展开，得到有效相互作用矩阵， 再与模型哈密顿量展开所得的矩阵作比较。 基于奇异值分解（singular value decomposition）过程， 可提取 g、A 和/或 ZFS 张量的全部 9 个分量。

    QDPT 关键词¶

    从 ORCA 6.0 开始，所有可用关联类型模块中 通过准简并微扰理论（QDPT）计算磁性质的方式被统一和简化。 按照 ORCA 6.0 的总体架构设计， 所有相关磁性质的计算由一个称为 QDPT Driver 的驱动数据结构集中执行。 该 Driver 考虑了相关模块填入的所有特定变量， 并以统一的方式计算和表示所请求的性质。 这目前涉及 casscf、mrci、rocis 和 lft 模块。

    这样， 1) 从用户角度对结果的分析被简化 2) 跨模块的关联和比较易于进行

    启用 QDPT 性质生成的通用关键词是：

    %METHOD (casscf, mrci, rasci, rocis, lft, ...)
  REL            # the name of the relativistic block
    DoSOC true   # include the SOC contribution
    DoSSC true   # include the SSC contribution
  END
END

    从 ORCA 6.1 开始，相对论块在所有连接到 QDPT driver 的方法中具有统一的结构。 因此，rel 是所有连接方法的默认块名。 对于 %mrci 块，soc 是一个备选名称， 以在本版本中保持与旧输入相对论块的兼容性。 soc 块名将在下个版本中弃用， 因此建议使用 rel 块名来请求 QDPT 性质。

    QDPT 关键词如下：

   MAGTemperatureMAX 4.0   # maximum temperature (K) for magnetization

   MAGFieldMAX 70000.0     # maximum field (Gauss) for magnetization

   DoXESSOC True
