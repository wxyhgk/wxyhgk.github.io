    激发态计算（Excited States Calculations）¶

    ORCA 中存在大量计算激发态的方法。 这里我们简要概述主要方法，重点介绍每种方法的基本用法 和当前功能。每种方法的详细文档在各小节中指出。

    多参考方法（如 NEVPT2 或 MRCI）在手册的其他地方描述 （modelchemistries.nevpt2、modelchemistries.mrci）。

    用 RPA、CIS、TD-DFT 和 SF-TDA 计算激发态（Excited States with RPA, CIS, TD-DFT and SF-TDA）¶

    ORCA 提供一个模块来执行 TD-DFT、单激发组态相互作用（CIS）和 RPA。 该模块适用于闭壳层（RHF 或 RKS）或非限制性（UHF 或 UKS）参考波函数。 对于 DFT 模型，模块自动选择 TD-DFT；对于 HF 波函数，则选择 CIS 模型。 如果 SCF 部分使用了 RI 近似，在激发态计算中也会使用它。 详细文档见章节 spectroscopyproperties.tddft

    功能（Capabilities）¶

    目前，TD-DFT/CIS 模块能够计算激发能、吸收谱和圆二色谱。 在 TD-DFT 方法内，还可以计算磁圆二色（见 spectroscopyproperties.mcd） 和瞬态光谱。

    TD-DFT 在限制性和非限制性形式以及共线自旋翻转变体中 都有解析梯度，从而可以进行激发态的几何优化， 如 tddft.geometry 中所述。

    用限制性开壳层 CIS - ROCIS 计算激发态（Excited States with Restricted Open-shell CIS - ROCIS）¶

    除了 CIS/TD-DFT 对激发态的描述外，ORCA 还提供 ROCIS 方法roemelt2013、roemelt2013b，它使用 限制性开壳层 Hartree-Fock（ROHF）参考进行单激发 组态相互作用计算。

    从 ORCA 6.0 开始，提供了一般自旋 ROCIS（GS-ROCIS）gouveia2025JPCA 实现。 这一新实现可以处理通过 CSF-ROHF 方法获得的、具有任意自旋耦合的 CSF 作为参考。

    ROCIS 的主要用途是计算 L 边和 M 边 X 射线吸收谱（XAS）以及 X 射线 磁圆二色（XMCD）和共振非弹性 X 射线散射（RIXS）。计算成本 通常高于 TD-DFT，但显著低于基于耦合簇的方法。 结合对自然轨道方法（PNO-ROCIS），中等到大分子尺寸的光谱 也是可行的。

    详细文档见 spectroscopyproperties.rocis。

 H 0  0.9910 -0.3174
 H 0 -0.9910 -0.3174
end

    功能（Capabilities）¶

    ROCIS 模块可以计算激发能、振子强度、跃迁偶极矩以及 X 射线吸收谱。它还支持计算 X 射线磁圆二色（XMCD）谱 和共振非弹性 X 射线散射（RIXS）截面。 ROCIS 方法适用于开壳层体系，特别适合过渡金属配合物的 L 边和 M 边光谱。

    用 CASSCF 线性响应（MC-RPA）计算开壳层分子的激发态（Excited States for Open-Shell Molecules with CASSCF Linear Response (MC-RPA)）¶

    MCRPA 是 CASSCF 线性响应理论的同义表述，主要用于 开壳层和强相关体系。在完成基态 CASSCF 计算后， 可以计算激发能、振子强度和旋光强度。 详细文档见 spectroscopyproperties.mcrpa。

    一般用法（General Use）¶

    在收敛的 CASSCF 计算之后，通过在 %mcrpa 块中指定根数 来启动 MCRPA 计算：

    #casscf + mcrpa input example

    功能（Capabilities）¶

    MCRPA 可以计算激发能、振子强度和旋光强度。 它特别适合开壳层和强相关体系。还可以使用 CVS 近似 计算 X 射线吸收谱（XAS）。

    用 ADC2 计算激发态（Excited States with ADC2）¶

    ADC2（代数图解构造二阶）方法是 CC2 的一种近似， 提供了一种比 EOM-CCSD 更经济的计算激发能的途径。 ADC2 方法在 ORCA 中实现，用于计算激发能和跃迁矩。

    一般用法（General Use）¶

    通过在简单输入中使用 !ADC2 关键词并指定基组 来调用 ADC2 计算。需要在 %mdci 块中指定根数：

    !ADC2 def2-TZVP TightSCF

%mdci
NRoots 10
end

    功能（Capabilities）¶

    ADC2 模块可以计算激发能和跃迁矩。它提供比 EOM-CCSD 更经济的计算，但精度略低。ADC2 的计算标度为 O(\(N^{5}\))。

    用 STEOM-CCSD 计算激发态（Excited States with STEOM-CCSD）¶

    STEOM-CCSD 方法是对 EOM-CCSD 的改进，通过第二次相似变换 将最终的矩阵对角化步骤压缩到 CIS 空间。 详细文档见 spectroscopyproperties.steom。

    一般用法（General Use）¶

    STEOM-CCSD 通过在简单输入中使用 !STEOM-CCSD 关键词来调用。 主要步骤包括基态 CCSD 计算、IP-EOM 和 EA-EOM 计算， 以及最终的 CIS 空间对角化。

    功能（Capabilities）¶

    STEOM-CCSD 可以计算激发能和跃迁矩。它提供比 EOM-CCSD 更高效的计算，适用于中等到大分子。还可以计算 芯激发能（见 eomcore.core-excitation）。

    用 IH-FSMR-CCSD 计算激发态（Excited States with IH-FSMR-CCSD）¶

    IH-FSMR-CCSD 是另一种解耦单激发空间与更高激发空间的方法。 详细文档见 spectroscopyproperties.ihfsmrcc。

    一般用法（General Use）¶

    IH-FSMR-CCSD 计算涉及基态 CCSD、IP-EOM、EA-EOM 和 最终的 CIS 空间对角化步骤。

    功能（Capabilities）¶

    IH-FSMR-CCSD 可以计算激发能和跃迁矩。它特别适合 需要考虑多重参考效应的体系。

    用基于 PNO 的耦合簇方法计算激发态（Excited States with PNO based coupled cluster methods）¶

    基于 PNO 的方法（bt-PNO）通过将基态 DLPNO 量反变换回 正则基，在保持精度的同时大幅降低计算成本。 详细文档见 spectroscopyproperties.dleom。

    一般用法（General Use）¶

    bt-PNO 方法通过在简单输入中使用 !bt-PNO-EOM-CCSD 关键词来调用。 它适用于闭壳层和开壳层体系。

    功能（Capabilities）¶

    bt-PNO 方法可以计算激发能、电离势和电子亲和能。 它提供与正则 EOM-CCSD 相当的精度，但计算成本显著降低。

    用基于 DLPNO 的耦合簇方法计算激发态（Excited States with DLPNO based coupled cluster methods）¶

    DLPNO 方法是 PNO 方法的进一步加速版本，适用于 更大的分子体系。详细文档见 excitedstates.dlpnoeom。

    一般用法（General Use）¶

    DLPNO-EOM 方法通过在简单输入中使用 !IP-EOM-DLPNO-CCSD 或类似关键词来调用。它适用于大分子体系。

    功能（Capabilities）¶

    DLPNO 方法可以计算激发能，适用于大分子体系。 它的精度略低于正则方法，但计算成本大幅降低。
