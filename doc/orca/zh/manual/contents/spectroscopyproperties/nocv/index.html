    含化学价自然轨道的扩展过渡态方法（ETS-NOCV/EDA-NOCV）¶

    Note

    ORCA 5.0 中的 NOCV 实现已重写 cardenas2025。 因此，NOCV 的生成不再需要用户事先对分子片段做单点能计算。 这种产生 NOCV 的方式已弃用。

    在 ORCA 中可用 EDA-NOCV 框架分析化学键 cardenas2025。 该框架将扩展过渡态（Extended Transition State，ETS）能量分解方法 与化学价自然轨道（Natural Orbitals for Chemical Valence，NOCV）相结合， 以分析成键时发生的电子密度重排 nocv2009。 ETS 方法将与成键相关的能量分解为四个分量：

    \[ \Delta E_\text{int}=\Delta E_\text{elstat}+ \Delta E_\text{Pauli} +\Delta E_\text{orb} + \Delta E_\text{disp} \]

    这表示两个不相互作用的分子片段之间导致成键过程的"瞬时"相互作用。 分子片段的确定是按照所研究的化学键将分子划分为两个片段。 所谓不相互作用，是指分子片段被视为处在无穷远距离， 且每个片段的电子密度保持冻结。 第一个能量项对应于两个不相互作用的分子片段 被置于它们在分子中所占位置时所经历的静电相互作用。 第二项包含由泡利不相容原理引起的总"交换排斥" 以及片段相互靠近时交换-相关能的变化。

    \[ \Delta E_{Pauli}=\Delta \tilde{E}_{Pauli}+\Delta E^{0}_{XC} \]

    需要强调的是，EDA/ETS 分解中报告为 Pauli Energy 的值对应于 \(\tilde{E}_{Pauli}\)。

    ETS 分解的第三项对应于一个分子片段的占据轨道 与另一个分子片段的未占据轨道之间相互作用相关的能量。 因此，它与成键过程中电子密度的变化相关。

    最后一项表示相互作用的"色散"（dispersion）贡献， 当使用半经典校正方案（如 Grimme 的 D4 校正） 或非局域（non-local，如 NL 和 SCNL）校正时会出现该项。 这些校正适用于局域泛函、杂化泛函和双杂化泛函， 更多细节参见 modelchemistries.dispersioncorrections 一节。

    一个用于更细致研究色散贡献的补充框架是 伦敦色散能的原子分解（Atomic Decomposition of London Dispersion Energy）regni2025ADLD （ADLD）。 用户可以为片段和加合物的 DFT-D 校正 都设置这种色散分解。然后便可考察色散贡献的原子分辨变化。

    EDA-NOCV 方法将该项分解为与轨道对相关的贡献。 这些轨道通过将分子与由不相互作用的分子片段构成的"超分子"（supermolecule） 之间的差密度矩阵对角化得到。

    \[ \Delta E_{orb}=\sum_{k=1}^{N/2} \Delta E_{k}^{orb} \]

    在 ORCA 中运行 EDA-NOCV 分析¶

    Note

    ORCA 6.1 中 EDA-NOCV 方法的当前实现对开壳层和闭壳层计算均支持平均场方法。

    要执行 EDA-NOCV 分析，必须指定三个关键要素：

    1. 计算类型：这定义了整体计算框架，并确定分析是用限制性还是非限制性平均场方法进行。
    2. 各片段所用的方法：包括对每个片段单独采用的基组、交换-相关泛函或其他理论方法的选择。通常，每个片段应与加合物在同一理论水平上处理。
    3. 对应于每个片段的原子：这需要定义分子体系中哪些原子属于哪个片段，以便 ORCA 相应地划分分子。

    EDA-NOCV 分析通过简单输入行中的 EDA 关键词执行。 在下面的例子中，我们给出乙烷分子中两个碳原子之间化学键的 EDA-NOCV 分析输入文件。 新实现允许将两个甲基作为分子片段来研究该体系， 且未配对电子的自旋相反。

%basis
  FragBasis 1 "TZVP"
  FragBasis 2 "def2-SVP"
end

%EDA
  FRAG1 "B3LYP TZVP"
  FRAG2 "B3LYP def2-SVP"
end

    若片段计算需要额外参数，可通过关键词 FRAG1_METHODFILE 和 FRAG2_METHODFILE 将其传递到单独的文件中。

  FRAG2_METHODFILE "method.txt"

    BP86 TZVP

%CPCM            #CPCM block
  epsilon 80          #Dielectric constant
  refrac  1.0         #Refractive index
END

    Note

    为每个片段指定方法时不需要 "!" 符号。 无论是在 %EDA 块中使用 FRAG1 和 FRAG2 关键词， 还是在使用 FRAG1_METHODFILE 和 FRAG2_METHODFILE 时的方法文件中，都是如此。

    当前实现允许带电和开壳层片段。 要指定每个片段的电荷，必须使用关键词 FRAG1_C 和 FRAG2_C。 类似地，关键词 FRAG1_M 和 FRAG2_M 可用于指定每个片段的多重度。 除非另有说明，默认每个片段被视为中性闭壳层。 各片段的总电荷必须等于分子的电荷。

    新实现还允许指定其中一个片段中未配对电子的自旋。 例如，在研究 CH\(_3\)-CH\(_3\) 体系时， 先前的 ORCA 实现只允许使用带电的闭壳层片段 CH\(_3^{+1}\) 和 CH\(_3^{-1}\)。 现在则可以考虑中性开壳层的甲基作为分子片段。 默认情况下，ORCA 中开壳层体系的未配对电子被视为自旋向上电子， 但可通过关键词 FRAG1_SF 和 FRAG2_SF 加以改变。 这一调整可减小两个甲基片段之间的泡利排斥。

    分子片段可用 %Frag 块指定，也可在每个原子旁标出它们属于哪个分子片段。 具体做法是在每个原子旁的括号中放置数字 1（第一个片段）或数字 2（第二个片段）。

    EDA-NOCV 输出分为两部分。 第一部分对应 ETS 能量分解分析（Energy Decomposition Analysis）。 在这一部分中，ETS 分解方法的每个能量项以 Hartree 和 kcal/mol 为单位打印。 此外，若计算中使用了色散校正， 还会打印分子的色散校正与分子片段的色散校正之差。 以下是上一节中 Li\(^+\)-NH\(_3\) 输入的 EDA-NOCV 结果：

    用 orca_plot 可视化变形密度贡献¶

    变形密度（deformation density）可表示为与成对 NOCV 相关的一组贡献： \(\Delta \rho(r)=\sum_{k=1}^{n/2} v_k \left[ -\psi_{-k}^2 +\psi_{k}^2 \right]= \sum_{k=1}^{n/2} \Delta \rho_k(r)\)

    新的 ORCA 实现允许可视化这些变形密度贡献。 这些密度保存在 EDA-NOCV 分析过程中生成的密度容器中。 可以用 orca_plot 将这些密度转换为标准可视化程序可读的格式来显示它们。 为此，需要使用以下命令：

    orca_plot gbwfilename -i

    这会显示一组用于生成相应文件的不同选项。

           1 - Enter type of plot
       2 - Enter no of orbital to plot
       3 - Enter operator of orbital (0=alpha,1=beta)
       4 - Enter number of grid intervals
       5 - Select output file format
       6 - Plot CIS/TD-DFT difference densities
       7 - Plot CIS/TD-DFT transition densities
       8 - Set AO(=1) vs MO(=0) to plot
       9 - List all available densities
      10 - Perform Density Algebraic Operations

      11 - Generate the plot
      12 - exit this program

    选项 9 会列出 EDA-NOCV 计算过程中保存的所有密度。 对应于 NOCV 对的密度记为 base_name.NOCV0_0.tmp， 其中 "base_name" 是输入文件的名称， .tmp 扩展名前的数字对应于对变形密度的贡献。 保存前五个密度贡献，因此该数字范围为 0 到 4。 在开壳层计算中，保存前五个自旋向上和自旋向下的贡献。 自旋向上贡献标记为 .NOCV0，自旋向下贡献标记为 .NOCV1。

    处理基态简并的片段¶

    在片段基态电子组态简并的体系中， 可能需要采取额外的预防措施才能得到 EDA-NOCV 分解的准确结果。 处理简并片段时，预分子（promolecule）和分子的部分占据分子轨道 可能不具有相同的取向。 这表现为 NOCV 分解的本征值为整数，并且轨道能量较高。 其成因是：由于片段基态电子组态的简并， 从片段分子轨道构建预分子分子轨道时轨道占据不恰当。

    一个例子是考虑 C 和 O 片段处于三重态基态时的 C-O 体系。 在此情形下，C 原子的电子组态为 \(2s^22p^2\)， 而 O 原子的组态为 \(2s^22p^4\)。 两个片段的 2p 轨道都是简并的。 当它们结合成键时，分子片段按 fig:co_orbitals 所示方式组合。 因此，一个片段中含有未配对电子的轨道 应当与另一个片段中相应的轨道相一致。 这可通过确保两个片段中部分占据轨道具有相同取向来实现。

    CO 分子的分子轨道

    所以在 C-O 体系中，我们必须确保 C 原子的两个未配对电子 处于相应的 \(2p^1_y\) 和 \(2p^1_z\) 轨道上， 以便它们能与 O 原子 \(2p^1_y\) 和 \(2p^1_z\) 轨道上的两个相应未配对电子组合。 在此情形下，这相当于将 C 原子的第一个部分占据轨道 \(2p^1_x\) 与未占据轨道 \(2p^0_z\) 交换。 为此，我们需要先对需要修改的片段运行一次单点计算。 然后，我们可以在 EDA-NOCV 分析中通过在相应片段的方法文件中 指定 MOREAD 关键词、并用 %moinp 传递 .gbw 文件， 将该计算的轨道用作 C 片段计算的输入。 接着我们需要指定要交换的片段分子轨道。 这可用 %scf 块中的 Rotate 功能完成。

    %scf
  Rotate
   { MO1, MO2, Angle }
   { MO1, MO2, Angle, Operator1, Operator2 }
   { MO1, MO2} # Shortcut to swap MO1 and MO2. Angle=90 degrees.
  end
end

    其中 MO1 和 MO2 指我们想要交换的分子轨道的索引。 更多细节参见 改变初始猜测 MO 的顺序并破坏初始猜测对称性 一节。

    Note

    分子轨道的索引从零开始。

    下一个输入对应于由三重态基态片段计算 C-O 体系。 关键词 FRAG1_FS 用于翻转 C 原子未配对电子的自旋。

    为获得正确的占据数，需要交换 C 片段的分子轨道。 下一个输入对应于 C 片段的方法文件。 通过在简单输入行使用关键词 MOREAD 并用 %moinp 传递 .gbw 文件， 其中含有 C 原子前一次单点计算的分子轨道。 在 Rotate 小节中，交换 \(2p_x^1\) 和 \(2p_z^0\) 轨道， 即索引 2 和 4。 这样碳的 \(p\) 轨道就从 \(2p^1_x2p^1_y2p^0_z\) 变为 \(2p^0_x2p^1_y2p^1_z\)， 与氧的 \(2p^2x2p^1_y2p^1_z\) 相一致。

  end

    这确保了预分子与分子轨道之间的一致性，并使轨道能量最小化。

    EDA-NOCV 与双杂化泛函¶

    ORCA 的新特性之一是可以对 EDA-NOCV 分析使用双杂化泛函。 这些泛函将 MP2 相关能贡献引入 DFT 计算所得的能量中。 使用这些泛函时，在能量分解分析中会新增一个标记为 MP2 correlation 的项。 该项对应于分子与其片段之间 MP2 相关分量之差。

    使用双杂化泛函时，必须指定所计算密度的类型： relaxed 或 unrelaxed， 且必须用 %mp2 块为分子和片段分别指定，如下所示：

    !B2PLYP def2-TZVP def2-TZVP/C EDA
%mp2 Density relaxed end

    NOCV 分解是用 DFT 计算的密度进行的。 也可以获得并绘制与 MP2 相关对变形密度矩阵的贡献所对应的密度。 该密度贡献定义为 \(DP_{mp2\_contribution}=\Delta P_{mp2\_level}-\Delta P_{DFT\_level}\)。 对于限制性计算，该密度保存为 base_name.DP0.mp2； 对于非限制性计算，自旋向上贡献保存为 base_name.DP0.mp2， 自旋向下贡献保存为 base_name.DP1.mp2。
