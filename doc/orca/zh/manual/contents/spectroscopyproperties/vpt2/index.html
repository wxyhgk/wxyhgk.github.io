    • 使用 VPT2 进行分子性质的振动修正（Vibrational corrections of molecular properties using VPT2）

    使用 VPT2/GVPT2 和 orca_vpt2 进行非谐分析与振动修正（Anharmonic Analysis and Vibrational Corrections using VPT2/GVPT2 and orca_vpt2）¶

    在（解析的）谐振 Hessian 计算基础上，可以计算三次加半四次力场 以及更高阶的性质导数。为此，VPT2 模块将计算 Hessian，然后为每个 自由度生成两个位移几何结构，并对每个位移再计算一个 Hessian （在振动修正情形下还要计算另一个性质）。这些是按照二阶振动 微扰理论（second-order vibrational perturbation theory）进行 非谐分析所必需的。总体而言，使用 VPT2 的代价较高，因为数值导数 需要进行大量计算，并且对收敛、近似及其他设置引起的数值噪声 非常敏感。VPT2 计算既可以通过简单输入命令 !VPT2 启动， 也可以通过 %vpt2 块中的 VPT2 关键词启动。更精细的控制可通过 %VPT2 块实现，如下面对水分子的分析所示。

    3
structure (0 1)
O  0.00000000000000 0.06256176106279 0.06256176106280
H  0.00000000000000 -0.06185639479702 0.99929463373422
H  0.00000000000000 0.99929463373424 -0.06185639479703
    # VPT2 Analysis of H2O
!RHF def2-SVP ExtremeSCF VPT2

%vpt2
  VPT2               On      # do a VPT2 analysis, same as !VPT2 (see above)
  AnharmDisp         0.05    # anharmonic displacement factor, default is 0.05
  HessianCutoff      1e-12   # cut-off for Hessian elements, default is 1e-10
  PrintLevel         1       # VPT2 print level [1, 2, 3, 4]
  MinimiseOrcaPrint  True    # Minimises the remaining orca output
end

%method
    Z_Tol               1e-14
end

* xyz 0 1
  O   0.00000000000000      0.06256176106279      0.06256176106280
  H   0.00000000000000     -0.06185639479702      0.99929463373422
  H   0.00000000000000      0.99929463373424     -0.06185639479703
*

    分析完成后，工作目录中应存在一个 <basename>.vpt2 文件。 所有力场和性质导数都保存在该文件中。它作为 orca_vpt2 程序的输入，该程序会在初始位移计算之后自动调用。也可以 通过命令 orca_vpt2 <basename>.vpt2 单独调用该程序。

    Note

    关于 VPT2 计算的几点说明：

    • VPT2 的起始几何结构必须始终紧密收敛。对于小分子， !TightOPT 选项是不够的！ 根据您的结构，可能需要尝试 %geom 块中的 TolE、TolRMSG 和 TolMaxG 关键词。

    • 同样，SCF 必须良好收敛。建议使用 ExtremeSCF 关键词，或至少使用 VeryTightSCF。

    • CP-SCF 方程应至少收敛到 \(10^{-12}\) （通过 %method 块中的 Z_Tol 设置修改）。

    • 对于 DFT 计算，强烈建议使用 DEFGRID3 等密集网格。

    • 目前尚不支持线性分子

    • 目前仅支持具有解析 Hessian 的方法。此外，对于不提供解析 Hessian 的 DFT 泛函，无法进行 VPT2 计算。

    • 默认情况下，使用更新后的原子质量来生成半四次力场 （见 frequencies.massdependencies）。 质量也会打印在 <basename>.vpt2 文件中

    • 可以通过运行 orca_vpt2 <basename>.vpt2 对先前的计算重复进行 VPT2 分析。

    • VPT2 具有有限的重启能力。如果执行 VPT2 的目录中已存在 <basename>.hess 或 <basename>_eprnmr.property.txt 文件， 程序将跳过这些点并使用文件中提供的信息。

    VPT2 提供振动分析，从而可以获得： - 位移的均值和均方期望值 - 离心畸变常数 - Watson 对称约化与非对称约化哈密顿量参数 - 非谐常数 - 费米共振分析 - 转动常数和振动-转动常数 - 基频跃迁（非谐频率） - 零点转振能量 - 含强度的倍频与组合频 （与具有完整 VPT2/GVBT2 处理的 NEARIR 相比） - 面向 SPCAT 等程序的专用文件接口

    如果计算数据要用于 SPCAT 等程序进行光谱模拟， ORCA 可以提供一个专用文件作为输入的基础。在运行 VPT2 计算时， 可在 %output 块中触发此功能：

    %output 
 Pickettname "pickett.txt"
end

    这样，ORCA 将生成一个名为 pickett.txt 的文件，其中包含 计算数据和 .var 模板，可修改后作为 SPCAT 等程序的输入。 请注意，该功能仍在完善和扩展中。

    使用 VPT2 进行分子性质的振动修正（Vibrational corrections of molecular properties using VPT2）¶

    使用 VPT2 也可以计算分子性质的零点振动修正。目前，这适用于 NMR 化学屏蔽、自旋-自旋耦合常数、g 张量和 A 张量， 并且需要两次连续的计算。第一次计算是如上所示的 VPT2 计算 （<basename>.inp），包含 VPT2 命令以及计算 Hessian 的 理论水平。第二次计算（我们称其为 <basename>_Prop.inp） 将计算性质导数，最后调用 VPT2。为使此流程正常工作， 性质导数计算需要从力场计算中读取 <basename>.hess 和 <basename>.vpt2 文件。这通过指定 %geom inhess read 并使用命令 inhessname "<basename>.hess" 来完成。 之所以需要这种方案，是因为除能量、几何结构或频率之外的性质 通常需要专门的方法和基组。对于力场和性质导数的数值计算， 可以通过在 VPT2 输入块中指定 AnharmDisp 和 PropDisp 使用不同的步长。默认值为 0.05，计算完成后，位移几何结构 存储在名为 myjob_DH001.xyz 和 myjob_DP001.xyz 等文件中。

    一个典型的例子是计算甲醇 \(^{13}\)C NMR 化学位移的振动修正， 采用 B3LYP/def2-TZVP 非谐力场和 TPSS/pcSseg-2 屏蔽张量， 其输入如下所示：标准输入文件（本例中为 vpt2_methanol_FF.inp）包含 Hessian 的理论水平和 VPT2 输入块：

    Note

    请确保给出正确的 Hessian 文件名，且输入文件中 不能包含复合块。您也可以直接使用 orca_vpt2 重新运行 VPT2 分析。 如果有一个名为 myjob_ff 的非谐力场计算和一个名为 myjob_prop 的性质导数计算，只需调用 orca_vpt myjob_ff.vpt2 myjob_prop.vpt2。
