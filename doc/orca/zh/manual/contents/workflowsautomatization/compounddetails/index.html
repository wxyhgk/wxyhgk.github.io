    &¶

    & 符号在 compound 块中具有特殊含义。在 NewStep - StepEnd 块内部使用该符号，用户可以使用定义在块外的变量。字符串变量和数值变量都允许。

    语法（Syntax）：

    &{variable}

    示例

    1
structure (0 1)
H           0.0          0.0          0.0
    # --------------------------------------------
# This script checks the options for the 
#             '&' symbol
# --------------------------------------------
%Compound 

  Variable method   = "BP86";              #string variable'
  Variable basis    = "def2-TZVP def2/J";
  Variable name     = "base";
  Variable number   = 0;                   #integer variable
  Variable distance = 0.8;                 #double variable
  New_step
    ! &{method} &{basis} TightSCF
    %base "&{name}_&{number}"              #combination of variables
    *xyz 0 1
      H 0.0 0.0 0.0
      H 0.0 0.0 &{distance} 
    *
  Step_End
  # ------------------------------------------
  # Add some printing
  # ------------------------------------------
  print("SUMMARY OF VARIABLES\n");
  print("Method:   %s\n",    method);
  print("Basis:    %s\n",    basis);
  print("Name:     %s\n",    name);
  print("Number:   %d\n",    number);
  print("Distance: %.2lf\n", distance);
End

    Abort¶

    当用户想要立即退出程序时使用 Abort。 语法（Syntax）：\ Abort;\ 或者：\ Abort

    示例： 

    %Compound
for i from 0 to 4 do
  print("i: %d\n", i);
  if (i=2) then 
    abort;
  endif
endfor
End

    Alias¶

    Alias 用于将一个整数替换为更有代表性的字符串。当执行多次计算而步骤编号变得过于复杂难以求值时很有用。这种情况下在 Step_End 命令之后使用 Alias_Step 将把前面的计算步骤编号与所提供的名称关联起来。

    语法（Syntax）：\ Alias \(name\);\ 或者：\ Alias \(name\)\ 示例：

    1
structure (0 1)
H           0.0          0.0          0.0
    # ----------------------------------
# This script checks 'alias' keyword
# ----------------------------------
Variable numOfSteps = 20;
Variable Range      = 4.0;
Variable distStart  = 0.4;
Variable Step       = Range/numOfSteps;
Variable distance;
Variable Energies[numOfSteps];
Variable simpleInput  = "BP86 def2-SVP def2/J";

For index from 0 to numOfSteps-1 Do
  Distance =  distStart+ index*Step;
  New_Step
    !&{simpleInput} 
    *xyz 0 1
      H 0.0 0.0 0.0
      H 0.0 0.0 &{Distance}
    *
  Step_End
  Alias currStep;
  print("Current step: %d\n", currStep);
  Read Energies[index] = JOB_INFO_TOTAL_EN[currStep];
EndFor

print("--------------------------------------\n");
print("       Compound Printing              \n");
print("%s  %12s  %16s \n","Step",  "Distance", "Energy");
print("--------------------------------------\n");
For index from 0 to numOfSteps - 1 Do
  Distance = distStart + index*Step;
  print("%4d  %12.4lf   %16.8lf \n", index, Distance, Energies[index]);
EndFor

End

    注意

    对于 Alias 命令，最后的 ';' 是可选的。

    Basenames¶

    Basenames 是每次使用 NewStep 时在 Compound 中自动创建的变量，它保存该步骤的名称。可以在计算运行过程中用它恢复该名称。它实际上是一个向量，其中值零对应于任何 new_step 命令之前的主计算。

    示例：

    2
structure (0 1)
H           0.0          0.0          0.0
H           0.0          0.0          0.8
    *xyz 0 1
  H 0.0 0.0 0.0
  H 0.0 0.0 0.8
*
%Compound
  new_step
    !BP86
  step_end
  alias lala;
  print("Basaenames[0]: %s\n", basenames[0]);
  print("Basaenames[1]: %s\n", basenames[lala]);
End

    Break¶

    当需要在一定条件下中断循环时，可以在 For 循环内部使用 Break（见（见 commands.for））。语法如下：

    语法（Syntax）：\ For variable From Start value To End value Do\ commands\ break ;\ commands\ EndFor;

    注意 break 和 break; 两种形式都是合法的。

    break 实际所做的是将循环的运行索引设为最后一个允许的值，然后跳转到 EndFor（见 commands.endfor））。

    示例： 

    #
# This a script to check Compound 'break' command
#
%Compound
print(" Test for 'break'\n");
print(" It should print 0, 1 and 2\n");
for i from 0 to 6 Do
  if (2*i > 4) then
    break
  endIF
  print("index: %d\n", i);
EndFor

print("Continued outside the 'for' loop\n");

End

    CloseFile¶

    当在 Compound 中使用 openFile 命令（见 commands.openFile）打开文件后，必须用 closeFile 命令关闭它。

    语法（Syntax）：\ closeFile(file);

    file 是由 openFile 命令创建的文件指针。示例见段落 commands.openFile。

    Continue¶

    当需要跳过循环的当前步骤并继续下一步时，可以在 For 循环内部使用 Continue（见（见 commands.for））。语法如下：

    语法（Syntax）：\ For variable From Start value To End value Do\ commands\ continue ;\ commands\ EndFor;

    注意 continue 和 continue; 两种形式都是合法的。

    continue 实际所做的是跳转到 EndFor（见 commands.endfor））。

    示例： 

    # -----------------------------------------------------
# This is a script to check Compound 'continue' command
# ----------------------------------------------------
%Compound
print(" Test for 'continue'\n");
print(" It should print 0, 1, 2 and 4\n");
for i from 0 to 4 Do
  if ( i=3) then
    continue;
  endIf
  print("index: %d\n", i);
EndFor
End

    Dataset¶

    在 Compound 中我们有 Dataset 对象。这些对象可以像 'compDataset' 类型的普通变量一样处理。普通变量与 Dataset 变量的一个重要区别在于声明方式。不是普通的： 

    Variable x;
    我们必须显式声明这是一个数据集。因此数据集声明的语法是：

    语法（Syntax）： 

    Dataset mySet;

    注意 对于数据集，我们不允许每行声明多个数据集。

    下面是在 Dataset 上工作的函数列表。

    • MakeReferenceFromDir(dataset.makeReferenceFromDir)

    • Print(dataset.print)

    示例： 

    Variable x;

    D.MakeReferenceFromDir¶

    MakeReferenceFromDir 命令作用于数据集对象（见 dataset.declaration）。它基于当前文件夹的 xyz 文件创建一个 json 参考文件。 注意* 默认情况下所有电荷和多重度分别设为 0 和 1。

    语法（Syntax）：\ mySet.MakeReferenceFromDir(dirName);

    其中：

    • mySet 是已声明的数据集对象

    • dirName 应包含一些 xyz 文件的目录名称。

    示例： 

    Dataset mySet;

    D.Print¶

    Print 命令作用于数据集对象（见 dataset.declaration）。它打印该数据集对象的所有细节。

    语法（Syntax）：\ mySet.Print();

    其中：

    • mySet 是已声明的数据集对象

    示例： 

    # ----------------------------------------------------
# This is an example script for dataset definition
# -----------------------------------------------------
%Compound
  dataset mySet;
  mySet.Print();
End

    Diagonalize¶

    Compound 可以执行矩阵代数运算，可用的代数运算之一是矩阵对角化。请注意，待对角化的矩阵必须是方阵且对称。还要记住只有矩阵的上三角部分用于对角化。如果一切顺利，该函数将返回矩阵的本征向量和本征值。

    语法（Syntax）：\ A.Diagonalize(eigenValues, eigenVectors);

    其中：

    • A： 待对角化的矩阵。
    • eigenValues： 含本征值的向量
    • eigenVectors： 含初始矩阵本征向量的方阵。

    示例： 

    %Compound
  # ------------------------------------
  #   This is a compound script that will 
  #   check dataset.MakeReferenceFromDir 
  #   function
  #   NOTE: The script assumes that some
  #         xyz files rest in the current
  #         directory
  # ------------------------------------

  # First some definitions
  Variable name = "mySet";
  Variable numOfMolecules = 0;
  dataset mySet;
  Variable myDir="./";
  mySet.MakeReferenceFromDir(myDir);
  mySet.ReadReferenceFile();
  mySet.Print();
End

    End¶

    End 是每个 compound 脚本必须有的最终命令（除非有 EndRun 命令（见 commands.endrun））。Compound 执行完脚本中所写内容后，控制权再次交回常规 ORCA 输入读取。ORCA 将继续分析 Compound 部分之后剩余的输入，但不会运行任何计算。

    EndRun¶

    EndRun 是结束 Compound 脚本执行的 End 命令的替代命令（见 commands.endrun）。end 与 EndRun 的区别在于 EndRun 忽略 Compound 块之后的一切。这使得将 Compound 用作完整工作流运行更加容易。

    EndFor¶

    所有 For 循环（见 commands.for）都必须以 EndFor 结束。语法和示例见 For 章节（见 commands.for）。

    注意 对于 EndFor，EndFor 和 EndFor; 都可以。

    For¶

    For 循环用于执行重复性任务。语法如下：

    语法（Syntax）：

    For variable From Start value To End value Do

    commands

    EndFor 或 EndFor;

    Variable 应是先前未定义的变量名。 Start value 和 End value 应是定义 variable 起始值和结束值的整数。Start value 和 End value 可以是数字、预定义变量或先前定义变量的函数。唯一要求是它们必须是整数。请记住循环将从第一个值执行到 End value，包含 End value。

    示例：

    # ----------------------------------------------------
# This is an example script for dataset definition
# -----------------------------------------------------
%Compound
  dataset mySet;
  mySet.Print();
End

    G.BohrToAngs¶

    BohrToAngs 命令作用于几何结构对象（见见 commands.geometry）。它将加载的几何结构对象的几何结构从 Bohr 转换为 Angstrom。实际上它只是将坐标乘以因子 0.529177249。

    语法（Syntax）：\ myGeom.BohrToAngs();

    其中：

    • myGeom 是已包含几何结构的几何结构对象

    示例： 

    # ----------------------------------------------------
# This is an example script for diagonalization
# -----------------------------------------------------
%Compound
  Variable Dim=3;
  Variable A[Dim][Dim];
  Variable eigenVal;
  Variable eigenVec;
  for i from 0 to Dim-1 Do
    for j from 0 to Dim-1 Do
      if (i<=j) then
        A[i][j] = i+j+1;
      else
        A[i][j] =  A[j][i];
      EndIf
    EndFor
  EndFor
  A.Diagonalize(eigenVal, eigenVec);
  A.PrintMatrix(); 
  eigenVal.PrintMatrix();
  eigenVec.PrintMatrix();
End

    G.CreateBSSE¶

    CreateBSSE 命令作用于几何结构对象（见见 commands.geometry）。如果几何结构对象包含 ghost 原子，则 CreateBSSE 将创建五个新文件： - myFilename_FragmentA.xyz - myFilename_MonomerA.xyz - myFilename_FragmentB.xyz - myFilename_MonomerB.xyz - myFilename_Total.xyz

    语法（Syntax）：\ myGeom.CreateBSSE(filename=myFilename);

    其中：

    • myGeom 是已包含几何结构的几何结构对象

    • filename 是所创建文件的基文件名。

    示例： 

    # ---------------------------------------
# This is a script to check 'for' loops
# ---------------------------------------

# ---------------------------------
# Some necessary initial definitions
# ----------------------------------
Variable x = {0.0, 1.0, 2.0, 3.0, 4.0};
Variable f;
Variable loopStart;
Variable upLimit;

# -----------------------------------
# Case 1. 
# Constant Start / Constant End
# -----------------------------------
print(" --------------  Case 1 --------------\n");
print("     Constant Start / Constant End    \n");
print("          f = index*x[index]          \n");
print( "      for index from 0 to 4 Do     \n");
print(" -------------------------------------\n");
for index from 0 to 4 Do
  f = index*x[index];
  print("Index: %3d    x[index]:  %.2lf   f:   %.2lf\n", index, x[index], f); 
EndFor

loopStart = 0;

    NewGeom¶

    NewGeom 是几何结构操作的平台。基本思想是拥有能够读取几何结构、然后根据我们需要的某些特性产生一个或多个新几何结构的函数。目前 NewGeom 名下有 4 个不同函数，即： Displace、Remove_Atom、Remove_Element。

    注意： 旧语法（New_Geom）仍然兼容，但请不要使用，因为它将来会被弃用。

    Displace¶

    "Displace'" 背后的思想是有一个结构，对其执行解析频率计算（目前我们不在性质文件中存储数值频率），然后从该计算读取 Hessian，根据我们选择的振动简正模式调整几何结构。该命令的语法是：

    语法： NewGeom = (Displace, step, hessian, frequency, scaling)

    其中：\ step 是我们选择原始几何结构的步骤\ hessian 是从性质文件读取的 Hessian\ frequency 定义我们将使用哪个简正模式，\ scaling 是我们希望位移严重程度的因子。

    我们应当注意 Displace 是 new_geom 命令家族中唯一不在磁盘上存储几何结构、而只是将新几何结构在内部传递给下一次计算的命令。该命令用法的示例可以在随 ORCA 提供的脚本 'iterativeOptimization' 中找到。相关部分如下：示例：

    ReadProperty¶
    

    Compound 的基本特性之一是能够轻松地从性质文件读取 ORCA 计算得到的值。
    

    语法（Syntax）：
    

    [res=] readProperty(propertyName=myName, [stepID=myStep], [filename=myFilename], [baseProperty=true/false])
    

    其中：

    变量 - 概述（Variables - General）¶
    

    Compound 语言中的一切都基于变量。它们的含义和用法与任何编程语言中类似：需要先声明变量然后给它赋值。值得注意的是，在 Compound 中，变量必须在赋值之前声明，遵循类似 C 的语言的语法规则。这与 Python 等语言不同，在那些语言中可以不事先声明就给变量赋值。Compound 中这一规则的唯一例外是 for 循环中的索引，它不需要事先声明。
    

    在 Compound 中我们支持下列变量数据类型：
    

      

    • 

      整数（Integer）
      

      • 

    • 

      双精度数（Double）
      

      • 

    • 

      字符串（String）
      

      • 

    • 

      布尔值（Boolean）
      

      • 

    • 

      文件指针（File pointer）
      

      • 

    

    除这些数据类型外 Compound 还支持 Geometry 和 Timer 类型的变量，但它们单独处理
（见 commands.geometry 和 timerrelated.timer）。
    

    Compound 中每个变量有 3 大使用类别：
    

      

    • 

      声明（见 variables.general）

      •

    变量 - 声明（Variables - Declaration）¶
    

    目前在 Compound 中有 6 种不同的变量声明方式。其语法如下：
    

    语法（Syntax）：
    

    A. Variable name;
    

    B. Variable name1, name2;
    

    C. Variable name=value;
    

    D. Variable name[\(n\)];
    

    E. Variable name[\(n1\)][\(n2\)];
    

    F. Variable name={value1, value2, ...};
    

    注意 在以前版本的 Compound 中，对于是矩阵但大小未知的变量，必须用下列语法声明变量：
    

    Variable name = [];
    

    现在已经改变，不再需要空括号，因此该变量可以像情形 A 中那样定义为普通变量。
    

    示例
    

    # ----------------------------------------------------
# This is an example script for ReadMOs
# -----------------------------------------------------
%Compound
  Variable step = 1;
  New_Step
    !BP86
    *xyzfile 0 1 h2o.xyz
  Step_End

  ReadMOs(step);
  New_Step
    !BP86
  Step_End
End

    

    关于不同变量声明情形的一些说明。\
情形 A 是最简单的，我们只是声明变量名。
    

    情形 B 类似于情形 A，但这里同时声明多个变量。
    

    在情形 C 中我们将变量声明与为变量赋值结合起来。值得注意的是这种情况下 Compound 会根据给定的值自动推断变量类型。
    

    情形 D 声明一个给定大小的一维数组。
    

    情形 E 声明一个给定大小的二维数组。对这种情形，以及相应地对情形 E，可以使用先前定义的整数变量代替数字。
    

    情形 F 基于给定值的列表定义数组。数组将根据列表的大小自动定义其大小。列表中的值不必都是同一类型。
    

    注意 过去对情形 F 需要在变量名后写空括号。这不再必要了。
    

    注意 重要的是不要忘记每个声明末尾的最终 ; 符号，因为省略它的结果是未定义的。

    With¶
    

    "with" 命令的目的是增加在调用 compound 时调整 compound 文件中已定义的某些变量的能力。这意味着如果 compound 文件中定义了一个变量并给它赋了值，我们可以在调用期间更改变量的赋值。
    

    可以传递数字、字符串或布尔变量。
    

    应当注意，无法以这种方式调用数组变量。除了这一限制外，with 情况下变量赋值的语法与普通 Compound 脚本中的变量赋值相同。
    

    这里一个重要说明是，如果我们使用 With 命令，即使我们调用的是 Compound 脚本文件，%Compound 块也应以 'End' 结束。\
语法（Syntax）：\
% compound \"filename\"\
With\
var1 = val1;\
var2 = val2;\
End\

    使用 Print 命令（见 stringrelated.print）可以写入 ORCA 输出。不过

语法紧密遵循编程语言 C 的 'fprintf' 命令的语法。参数定义和语法
与 Compound 'Print' 命令的语法相同，只是
应定义一个文件对象来接收打印内容。

细节请参阅章节 stringrelated.print。
