    片段指定（Fragment Specification）¶

    计算中的原子可以被分组为特定的片段（fragments），片段有多种用途。片段定义可用于分配基组和 ECP、在布居分析部分组织输出，以及启用片段约束优化和刚体优化（Rigid Body Optimization）等功能。它们还用于局域能量分解和多层级计算。

    在输入文件中定义片段¶

    有三种方式可以通过输入文件把原子分配到片段。第一种方法是在坐标部分的原子符号后直接放置 (n)，把特定原子分配到特定片段。

    5
structure (-2 2)
Cu         0.00         0.00         0.00
Cl         2.25         0.00         0.00
Cl        -2.25         0.00         0.00
Cl         0.00         2.25         0.00
Cl         0.00        -2.25         0.00
    *xyz -2 2
 Cu(1)  0.00  0.00  0.00
 Cl(2)  2.25  0.00  0.00
 Cl(2) -2.25  0.00  0.00
 Cl(2)  0.00  2.25  0.00
 Cl(2)  0.00 -2.25  0.00
*

    本例中使用片段功能把分子划分为"金属"和"配体"两个片段，程序相应地会打印金属和配体的电荷与布居。

    5
structure
Cu     0.000000     0.000000     0.000000
Cl     2.250000     0.000000     0.000000
Cl    -2.250000     0.000000     0.000000
Cl     0.000000     2.250000     0.000000
Cl     0.000000    -2.250000     0.000000
    

    


    另外，也可以用 %coords 模块块以同样的方式定义片段——在原子符号后直接放置 (n)。
    

    

    5
structure
Cu         0.00         0.00         0.00
Cl         2.25         0.00         0.00
Cl        -2.25         0.00         0.00
Cl         0.00         2.25         0.00
Cl         0.00        -2.25         0.00
    

    

    


    

    重要
    

      

    • 

      当所有原子都被显式分配到片段时，片段编号必须从 1 开始并使用连续整数。不连续或不正确的编号可能导致错误。
      

      • 

    • 

      如果有任何原子未被分配（或被显式分配到片段 0），它将按照自动片段划分一节中描述的片段划分流程自动分配到某个片段。在这种情况下——即只有一部分原子被手动分配到片段——不需要使用连续的片段编号。但输入中指定的最大片段编号必须小于手动与自动流程组合所产生的片段总数。如果这一条件不满足，ORCA 会自动按升序从 1 开始重新排列所有片段编号。
      

      • 

    

    

    最后，第三种定义片段的方式是在 %frag 模块块内使用 Definition。在这种方案中，片段编号写在最前面，随后是用花括号 {} 括起、以 end 结尾的原子列表（原子从 0 开始编号）。连续的原子也可以用 initial_atom:final_atom 记号指定。
    

    

    5
structure (-2 2)
Cu         0.00         0.00         0.00
Cl         2.25         0.00         0.00
Cl        -2.25         0.00         0.00
Cl         0.00         2.25         0.00
Cl         0.00        -2.25         0.00
    

    *xyz -2 2
 Cu  0.00  0.00  0.00
 Cl  2.25  0.00  0.00
 Cl -2.25  0.00  0.00
 Cl  0.00  2.25  0.00
 Cl  0.00 -2.25  0.00
*

%frag
 Definition
  1 {0} end    # atom 0 for fragment 1
  2 {1:4} end  # atoms 1 to 4 for fragment 2
 end
end
    

    


    

    5
structure (-2 2)
Cl         2.25         0.00         0.00
Cl        -2.25         0.00         0.00
Cu         0.00         0.00         0.00
Cl         0.00         2.25         0.00
Cl         0.00        -2.25         0.00
    

    *xyz -2 2
 Cl  2.25  0.00  0.00
 Cl -2.25  0.00  0.00
 Cu  0.00  0.00  0.00
 Cl  0.00  2.25  0.00
 Cl  0.00 -2.25  0.00
*

%frag
 Definition
  1 {2} end        # atom 2 for fragment 1
  2 {0:1 3:4} end  # atoms 0, 1, 3, and 4 for fragment 2
 end
end
    

    


    

    注意
    

      

    • 

      对于最后一种选项（Definition），%frag 模块块必须写在坐标部分之后。
      

      • 

    • 

      %frag Definition 也适用于通过外部文件定义的坐标。
      

      • 

    

    

    

    自动片段划分（Automatic Fragmentation）¶
    

    从 ORCA 6.1 起，引入了一套自动片段划分算法，用于自动识别并将原子分组为片段。
    

    当输入文件中包含 %frag 模块块，或只有部分原子被手动分配到片段时，就会触发自动片段划分流程。
    

    自动片段划分由一组流程完成，用户可在 %frag 模块块中选择。每个流程都会尝试在尚未分配的原子中识别新的片段。例如，考虑下面的例子：前 11 个原子属于一个丙烷分子，最后三个属于一个水分子。FragProc 中的 Water 流程把最后三个原子识别为水分子并分配到第一个片段，而 FunctionalGroups 流程则检测并将丙烷的 CH3 和 CH2 基团分配为片段 2 到 4。
    

    

    

    14

C      0.000000     1.270000    -0.260000
C      0.000000    -0.000000     0.580000
C      0.000000    -1.270000    -0.260000

H      0.890000     1.320000    -0.910000

    注意

      •

      • 

    • 当存在未分配到片段的原子时，约束片段不会自动启用自动片段划分。但可以通过在输入文件中包含 %frag 模块块来激活自动片段划分。
      • 

    

    

    ORCA 提供了 30 多种 FragProc 方法，可以组合成列表，为各种目的生成片段。下面是对各个流程的说明和示例。

    自动片段划分：Atomic 与 NotAssigned¶
    

    FragProc Atomic 和 FragProc NotAssigned 是终止流程。FragProc Atomic 把每个先前未分配的原子各自作为一个独立片段，而 FragProc NotAssigned 把所有剩余未分配的原子分配到同一个片段。
    

    与其他 FragProc 方法类似，自动片段划分工具的输出表明使用了 Atomic 或 Not_assigned 流程来生成相应片段。

    自动片段划分：Delete 与高级片段划分工作流¶
    

    几乎所有的片段划分方案都有一个对应的删除（delete）流程，用于移除该特定方案生成的片段。这使得构建高级片段划分工作流成为可能，其中一个流程可以临时"保护"某些原子不被后续方法划分。这些受保护的片段之后可以被删除，从而允许用不同的片段划分方法重新处理这些原子。
    

    考虑下面的体系，它同时包含一个苯丙氨酸分子和一个苯分子。目标是把苯丙氨酸划分为它的主链、一个 CH2 基团和苯环，同时把苯划分为六个独立的 CH 片段。
    

    一方面，通过组合三个片段划分流程——FragProc AABackbone, Extend, AASCFinegrained——可以实现苯丙氨酸所需的片段划分。AABackbone 和 Extend 选项识别氨基酸主链，而 AASCFinegrained 把 CH2 基团和苯环分离为不同的片段。同时，可以用 FragProc Extlib 通过定义 CH 片段的外部库把苯分子划分为六个独立的 CH 片段。然而这两种片段划分方案并不兼容。当对整个体系应用 FragProc AASCFinegrained 时，它不仅会划分苯丙氨酸侧链，还会把苯环拆成一个苯基和一个氢原子。反之，如果先对苯应用 FragProc Extlib，它可能无意中划分苯丙氨酸残基，导致不希望的结构拆分。
    

    实现目标片段划分的一种可行方法是先用 FragProc Aminoacids 识别氨基酸。该流程分配所有属于氨基酸片段的原子，从而保护它们不被后续片段划分步骤重新分配。然后可以用 FragProc Extlib 通过外部库划分苯分子。最后用 FragProc DelAminoacids 删除苯丙氨酸片段，以便按需要重新划分。所有这些操作只需按如下方式串联流程即可执行：FragProc Aminoacids, Extlib, DelAminoacids, AABackbone, Extend, AASCFinegrained
