    色散校正（Dispersion Corrections）¶

    常规密度泛函理论（以及哈特里-福克理论）的一个主要缺陷是缺乏对包括伦敦色散（London dispersion）在内的长程关联效应（long-range correlation effects）的描述。伦敦色散代表范德华相互作用（van-der-Waals interaction）中的吸引分量，尽管它是一种相当弱的相互作用，但对许多情形而言其正确描述可能至关重要。对于非共价相互作用（non-covalent interactions）和延展分子（extended molecules）尤其如此。不过，已有若干成熟的色散校正方法可在很大程度上弥补这一缺陷。在 ORCA 中提供了多种选项，包括 Grimme 的 D3 grimme2010chem, grimme2011comp 和 D4 caldeweyher2017, caldeweyher2019 校正，以及 VV10 的非局域变体（NL，vydrov2010chem, hujo2011chem）。

    关于色散校正的一些说明（Some notes on dispersion corrections）

    • 色散校正不仅影响非共价配合物（non-covalent complexes），也影响构象能量（conformational energies）和结构——它们在很大程度上受分子内色散（intramolecular dispersion）影响。因此，几乎总是推荐、甚至必须包含色散校正（除少数不能、不应或无需使用的情形外，见下文）。

    • 使用小基组（如双 zeta 基组）的 DFT 计算，即便不加色散校正，也常常给出吸引性的势能面（potential energy surfaces）。然而，这是由基组重叠误差（basis set superposition error, BSSE）造成的，而 BSSE 带来的相互作用能往往与色散导致的真实相互作用能并不吻合（因为二者来源完全不同）。因此，尽管不加色散校正的 DFT 双 zeta 计算看起来可能给出定性正确的结果，偶尔甚至比加色散校正的双 zeta 计算结果更好（因为后者往往会高估总吸引作用），仍强烈建议通过降低 BSSE 并开启色散校正来"因正确的理由得到正确的答案"（get the right answer for the right reason）。BSSE 可以通过多种手段校正，例如：(1) 使用更大的基组；(2) 使用 counterpoise 校正（essentialelements.counterpoise）；或 (3) 使用几何反位校正（geometrical counterpoise correction，章节 counterpoise.gcp）。其中，(3) 几乎不增加额外开销（包括解析梯度贡献），特别适合大分子的几何优化。否则，(1)（或其与 (2) 的组合）由于精度更高，可能更为合适。

    • 含有 VV10 型非局域色散的泛函（一般是以 "-V" 结尾的泛函）不需要（也不能与）色散校正一起使用。同样的情况也适用于后 HF（post-HF）方法和多参考方法，如 MP2、CCSD(T)、CASSCF 和 NEVPT2。不过，可以在 HF 之上添加色散校正。

    • 某些泛函，尤其是 Minnesota 系列泛函（例如 M06-2X），能描述中程色散（medium-range dispersion）但缺失长程色散。它们对中小体系给出合理的色散能，但对大体系可能略微低估色散能。在这种情况下，未经校正的泛函本身已涵盖了色散的主体部分，色散校正远不如 B3LYP 那类情形重要，总体上应视为有益但并非强制。

    Grimme 的 DFT-D3 与 DFT-D4¶

    DFT-D3 和 DFT-D4 是逐原子对（atom-pairwise，逐原子三元组（atom-triplewise））的色散校正，可以添加到 KS-DFT 能量和梯度中grimme2010chem。在 ORCA 中，D3 适用于直至 Pu（Z = 94）的所有元素，D4 适用于直至 Lr（Z = 103）的所有元素。

    \[ E_{\text{DFT-D}} = E_{\text{KS-DFT}} + E_{\text{disp}}\qquad \text{(eqn:modelchemistries.dispersioncorrections.dftd.theory.edftd)} \]

    \(E_{\text{disp}}\) 是色散能的两体（two-body）和三体（three-body）贡献之和，\(E_{\text{disp} } =E^{(2) }+E^{(3) }\)。其中最重要的是两体项，其长程形式为：

    \[ E_{\text{disp} } = - \sum_{A < B} \sum_{n=6,8} s_{n} \frac{C_{n}^{AB} }{r_{AB}^{n} }\qquad \text{(eqn:modelchemistries.dispersioncorrections.dftd.theory.twobody)} \]

    其中\(C_{n}^{AB}\) 表示原子对 AB 的平均（各向同性）\(n\) 阶色散系数，\(r_{AB}\) 是其核间距。\(s_{n}\) 是与泛函相关的缩放因子（见下文）。在一般情形下，必须使用适当的阻尼函数（damping function）。较新的 D4 模型基本采用类似的理论，但进一步引入了原子参考极化率（atomic reference polarizabilities）对原子分电荷的依赖关系。

    阻尼函数（Damping Functions）¶

    为避免小\(r_{AB}\) 时的近奇异性（near-singularities），需要在短距离处对色散贡献进行阻尼处理。一种可行的方式是使用 Becke 和 Johnson 提出的有理阻尼（rational damping）becke2005chem,johnson2005chem,johnson2006chem：

    \[ E^{(2) }= - \sum_{A < B} \sum_{n=6,8} s_{n} \frac{C_{n}^{AB} }{r_{AB}^{n} +f(R_{0}^{AB} )^{n} }\qquad \text{(eqn:modelchemistries.dispersioncorrections.dftd.theory.bj)} \]

    其中johnson2006chem

    \[ R_{0}^{AB} =\sqrt{ \frac{C_{8}^{AB} }{C_{6}^{AB} } }\qquad \text{(eqn:modelchemistries.dispersioncorrections.dftd.theory.r0ab)} \]

    且

    \[ f(R_{0}^{AB} )=a_{1} R_{0}^{AB} +a_{2} .\qquad \text{(eqn:modelchemistries.dispersioncorrections.dftd.theory.fbj)} \]

    将短程区的色散贡献阻尼至零（如参考文献 grimme2010chem 中那样）也是可行的：

    \[ E^{(2) }= - \sum_{A < B} \sum_{n=6,8} s_{n} \frac{C_{n}^{AB} }{r_{AB}^{n} }f_{d,n} (r_{AB} )\qquad \text{(eqn:modelchemistries.dispersioncorrections.dftd.theory.zero)} \]

    其中

    \[ f_{d,n} =\frac{1}{1+6(\frac{r_{AB} }{s_{r,n} R_{0}^{AB} })^{-\alpha_{n} } }\qquad \text{(eqn:modelchemistries.dispersioncorrections.dftd.theory.fzero)} \]

    注意，与该阻尼一起使用的\(R_{0}^{AB}\) 来自参考文献 grimme2010chem。关于所支持的阻尼函数的更多信息，参见参考文献 grimme2011comp。

    三体项（Three-body term）¶

    可以按下式计算三体色散贡献：

    \[ E^{(3) }= - \sum_{A < B < C} \frac{C_{9}^{ABC} (3\cos{\theta_{a} } \cos{\theta_{b} } \cos{\theta_{c} } +1) }{(r_{AB} r_{BC} r_{CA} )^{3} } f_{d,(3) }(\overline{r}_{ABC})\qquad \text{(eqn:modelchemistries.dispersioncorrections.dftd.theory.abc)} \]

    其中\(\theta_{a}\)、\(\theta_{b}\) 和\(\theta_{c}\) 是由\(r_{AB}\)、\(r_{BC}\) 和\(r_{CA}\) 构成的三角形的内角。\(C_{9}\) 系数近似为

    \[ C_{9}^{ABC} \approx -\sqrt{ C_{6}^{AB} C_{6}^{AC} C_{6}^{BC} }\qquad \text{(eqn:modelchemistries.dispersioncorrections.dftd.theory.c9abc)} \]

    三体贡献对中等大小分子的影响很小，并按公式 Eq 进行阻尼。阻尼函数\(f_{d,(3) }(\overline{r}_{ABC})\) 与公式 Eq 中所示的类似，其中\(\overline{r}_{ABC}\) 是\(r_{AB}\)、\(r_{BC}\) 和\(r_{CA}\) 的几何平均值。它可以与\(E^{(2) }\) 项的两种变体一起使用，不过三体项本身始终使用零阻尼（zero damping）方案计算。事实证明，加入三体校正对超分子体系（supramolecular systems）的热化学给出了相当准确的结果grimme2012chemeurj。注意，D4 中默认包含三体项。

    基本用法（Basic Usage）¶

    D3 校正可通过 !D3 关键词调用，它将自动使用默认的 Becke-Johnson 阻尼，因而等同于 !D3BJ。零阻尼方案可用 !D3ZERO。注意，一般推荐使用 Becke-Johnson 方案。

    !PBE D3

    三体项可通过关键词 !ABC 调用。

    !PBE D3 ABC

    注意

    注意，并非所有方法都针对所有阻尼选项进行了参数化。例如，哈特里-福克（HF）只针对 BJ 阻尼进行了参数化，而 M06 只针对零阻尼进行了参数化。

    较新且普遍推荐的 D4 校正可用 !D4 关键词。注意，D4 默认使用 Becke-Johnson 阻尼和三体项。

    !PBE D4

    D4 校正也可以在输入的 %method 块中定义：

    ! PBE def2-TZVP

%method
  DFTDOpt     5     # 5 = D4; 4 = D3(BJ)
end

    自定义参数（Custom parameters）¶

    如果某个泛函的参数已知但尚未在 ORCA 中实现，可以通过 %method 块手动指定。

    警告

    使用自定义参数风险自负，一般不推荐。D3 的部分可用参数列表可以在 Grimme 小组的网站上找到。

    GGA 和杂化泛函（hybrid functionals）应仅与

    \(s_{6}=1.0\) 一起使用，以确保渐近行为正确。双杂化泛函（double-hybrid functionals）已经包含了部分色散相互作用，因此应与\(s_{6} < 1.0\) 一起使用。

    对于采用 Becke-Johnson 阻尼的 D3，可以调整\(s_6\)、\(a_1\)、\(s_8\) 和\(a_2\) 参数：

    !B2PLYP D3

%method
  D3S6 0.6400
  D3S8 0.9147
  D3A1 0.3065
  D3A2 5.0570
end

    对于 D4，三体项的\(s_9\) 参数也可以调整。

    !B2PLYP D4

%method
  D4S6 0.6400
  D4S8 1.1689
  D4A1 0.4415
  D4A2 4.7311
  D4S9 1.0000
end

    对于零阻尼的 D3 变体，可以调整\(s_6\)、\(rs_6\)、\(s_8\) 和\(\alpha_{6}\) 参数。

    !BLYP D3ZERO

%method
  D3S6     1.000
  D3RS6    1.094
  D3S8     1.682
  D3alpha6 14
end

    对于某些泛函，还有专门针对 def2-TZVPP 三 zeta 基组优化的特殊参数。该选项仅在零阻尼下可用，可通过关键词 !D3ZERO D3TZ 调用。参考文献 grimme2010chem 补充材料中的初步结果表明，其结果仅比使用默认参数的四 zeta 基组略差。在未来的大规模计算中使用该选项前应谨慎测试。

    5 激活 D4 校正
    D3S6 <real> 控制 D3 的\(s_6\) 参数

    非局域色散校正（Non-Local Dispersion Correction, VV10）：DFT-NL¶

    校正伦敦色散的另一条途径是范德华密度泛函（van der Waals Density Functional, vdW-DF），由 Langreth 和 Lundquist 开创lee2010phys。这类方法仅使用电子密度来包含此类色散/关联效应，并可自洽地使用，从而不仅校正能量，也校正分子轨道。Vydrov 和 Van Voorhis 的 vdW 关联泛函 VV10vydrov2010chem 目前看来是通用于精确电子结构方法最有希望的候选者。

    我们用 DFT-NL 这一术语指代任意密度泛函与 VV10 泛函的非局域部分（其优化参数\(b\) 见下文定义）的组合。这些方法的表现已在参考文献 hujo2011chem 中使用 GMTKN30goerigk2010chem,goerigk2011chem,goerigk2011phys 数据库和 S66 集resac2011chem 进行了评估。弱氢键（weak hydrogen bonds）的表现则在参考文献 hujo2011phys 中进行了评估。

    DFT-NL 与 DFT-D3/D4 的表现非常相似，但对于金属体系或当基本电子结构发生显著变化时（例如氧化或电离），NL 更可取。作为一个较近的例子，Janes 和 Iron 表明，对于 wB97X-V 这类泛函，当涉及金属时，包含 VV10 关联可得到非常高质量的反应能垒（reaction barriers）iron_evaluating_2019。

    VV10 型泛函的总交换-关联（exchange-correlation, XC）能量定义于公式 Eq。它由标准交换（X）部分和关联（C）部分，以及非局域（NL）项组成——后者涵盖（主要是）长程色散能：

    \[ E_{\text{XC} }^{\text{DFT-NL} } = E_{\text{X} }^{\text{(hybrid)GGA} } +E_{\text{C} }^{\text{GGA} } +E_{\text{C-NL} }^{\text{VV10} }\qquad \text{(eqn:modelchemistries.dispersioncorrections.dftnl.theory.exc-dftnl)} \]

    NL 项由以下双重积分给出：

    \[ E_{\text{C-NL} }^{\text{VV10} } = \in t dr\rho (r)\left[{ \beta +\frac{1}{2}\mathop \in t\nolimits dr'\rho ( { r'} ) \varphi (r,r') } \right]\qquad \text{(eqn:modelchemistries.dispersioncorrections.dftnl.theory.ec-vv10)} \]

    其中\(\rho\) 是总电子密度，核函数\(\varphi (r,r')\) 和\(\beta\) 的定义如下（原子单位制）：

    \[ \varphi \left({ r,r'} \right) = -\frac{3}{2gg'\left({ g+g'} \right)}\qquad \text{(eqn:modelchemistries.dispersioncorrections.dftnl.theory.vv10-phi)} \]

    \[ \beta = \frac{1}{32}\left[{ \frac{3}{b^{2} }} \right]^{3/4}\qquad \text{(eqn:modelchemistries.dispersioncorrections.dftnl.theory.vv10-beta)} \]

    其中

    \[ \begin{aligned} g\left( r \right) &= \omega_{0} \left( r \right)R^{2}+\kappa (r) \\ R &= \left|{ r-r'} \right| \\ \omega_{0} \left( r \right) &= \sqrt{ C\left|{ \frac{\nabla \rho (r) }{\rho (r) }} \right|^{4}+\frac{4\pi }{3}\rho (r) } \\ \kappa \left( r \right) &= b\frac{3\pi }{2}\left[{ \frac{\rho (r) }{9\pi } } \right]^{1/6} \end{aligned}\qquad \text{(eqc:modelchemistries.dispersioncorrections.dftnl.theory.grw0k)} \]

    在原始定义中，出现在\(\kappa\) 和\(\beta\) 中的短程衰减参数\(b\) 是对 S22 非共价相互作用集jurecka2006phys 拟合的（对于 rPW86PBE GGA，\(b = 5.9\)）。出现在\(\omega_{0}\) 中的另一个参数\(C = 0.0093\) 决定长程行为，被设为其原始值。其他 DFT-NL 泛函按类似方式构造。关于公式推导及其物理意义和基础的详细讨论，参见上述参考文献。

    所定义的非局域 DFT-NL 交换-关联泛函的能量可以用两种方式计算：作为基于收敛 SCF 密度的 SCF 后（post-SCF）附加项，或采用自洽（self-consistent）处理。在我们对非自洽 DFT-NL 泛函的实现中，第一步先执行自洽 DFT 计算；第二步，将 DFT 计算得到的优化电子密度作为非局域部分能量计算的输入。在自洽处理中，轨道和密度在完整的 DFT + VV10 交换-关联势存在下进行优化。 根据大量测试计算，对于常规能量评估，很少需要自洽处理。 公式 Eq 中双重积分的计算需要使用积分网格（integration grid），就像常规交换-关联泛函一样。该网格的构建方式与 ORCA 中可用的常规网格类似，参见章节 essentialelements.numericalintegration。

    重要

    Head-Gordon 的\(\omega\)B97X-Vheadgordon2014wB97XV、B97M-V headgordon2015B97MV 和\(\omega\)B97M-Vheadgordon2016wB97MV 泛函是专门拟合的变体，它们使用非局域 VV10 核来捕捉伦敦色散效应。 它们默认采用非自洽 NL 校正，无需使用任何额外的 NL 关键词！自洽处理可通过 !SCNL 关键词调用。

    关于 ORCA 中 NL 校正的一些说明（Some notes on the NL corrections in ORCA）

    • 哈特里-福克方法无法进行自洽计算。

    • 解析梯度（analytic gradients）可用，因此可以计算带有数值频率的几何优化。

    • TD-DFT 计算尚不可用。

    • 任何需要 NL 泛函二阶导数的计算目前尚不可行。CP-SCF 解中实型微扰（real type perturbations）需要这些二阶导数，例如解析 Hessian、偶极极化率（dipole polarizabilities）和双杂化梯度。

    • 严格的虚型微扰（strictly imaginary perturbations），如 NMR 屏蔽（shielding）和 EPR g 张量（两者也支持 GIAO），以及超精细耦合（hyperfine couplings）是可用的。

    自定义参数（Custom parameters）¶

    对于 NL，可以通过 %method 块调整参数\(b\)、\(C\) 以及 NL 关联能项的全局缩放参数。全局缩放参数 NLScal 应用于对 NL 校正进行缩放，适用于那些已经部分涵盖长程关联的方法（如双杂化）。

    !B3LYP NL

%method
  NLb    5.0
  NLC    0.0083
  NLScal 1.0
end

    注意

    为了改善对较大体系的标度行为，还引入了一个距离截断（distance cutoff），由 %method 块中的 vdWdistTCUT 标志控制。默认值为 10 Å，即相距超过 10 Å 的两个格点不会通过 VV10 势发生关联。这一取值已经非常保守，对最终能量的实际影响为零，但如有需要可以更改。
