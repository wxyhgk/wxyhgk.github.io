    全组态相互作用（Full Configuration Interaction）¶

    ORCA 提供了若干精确和近似方法来处理全组态相互作用（full configuration interaction，FCI）问题。这些方法可通过 CASSCF 模块（见 modelchemistries.casscf 一节） 或 ICE 模块（见 modelchemistries.iceci 一节）来使用。

    下面我们用 CASSCF 模块计算氢化锂（lithium hydride）分子的 FCI 能量， 典型的输入需要声明一个活性空间（active space）。活性空间定义了以 FCI 拟设（ansatz）处理的活性电子数与活性轨道数。在所有电子和轨道都以 FCI 拟设处理的特殊情况下，我们可以在 %CASSCF 块中使用关键词 DoFCI， 让程序相应地设定活性空间。在此示例中，我们关注单重态基态。 注意，任意多重度的激发态都可以通过关键词 Mult 和 NRoots 来计算。 FCI 方法对轨道旋转不变，因此 CASSCF 模块中会跳过轨道优化。 尽管如此，采用一组有意义的轨道（例如来自收敛的 Hartree-Fock 计算的轨道） 以减少 FCI 迭代次数仍然很重要。

    2
structure (0 1)
Li            0            0            0
H             0            0        1.597
    # Hartree-Fock orbitals
!def2-tzvp RHF

*xyz 0 1
  Li 0 0 0
  H  0 0 1.597
*

    Hartree-Fock 计算的输出还会报告体系中电子和轨道的总数（见下面的片段）。

    Number of Electrons    NEL             ....    4
Basis Dimension        Dim             ....   20

    在给定示例中，20 个轨道中有 4 个电子，即 "CAS(4,20)"。读入收敛的 RHF 轨道后， 即可启动 FCI 计算。

    2
structure (0 1)
Li            0            0            0
H             0            0        1.597
    !def2-tzvp extremescf

!moread
%moinp "RHF.gbw"

%maxcore 2000

%casscf
  DoFCI true # sets NEL 4 and NORB 20 in this example.
end

*xyz  0 1
  Li 0 0 0
  H  0 0 1.597
*

    除能量外，CASSCF 模块还提供若干性质（g 张量、零场分裂（ZFS）等）， 详见 casscf.properties 一节。

    FCI 问题的精确解标度非常陡峭，因此仅限于较小的问题（最多 16 个电子 在 16 个轨道中的活性空间）。更大的体系可通过近似解来处理， 例如密度矩阵重整化群（density matrix renormalization group，DMRG）方法 （见 modelchemistries.dmrg 一节），或迭代组态展开 （iterative configuration expansion，ICE）方法（见 modelchemistries.iceci 一节）。 为了作一比较，我们再用 ICE-CI 拟设重复该计算，它提供了一种更传统的途径 来获得近似的全 CI 结果。

    2
structure (0 1)
Li            0            0            0
H             0            0        1.597
    !def2-TZVP ExtremeSCF

!moread
%moinp "RHF.gbw"

%maxcore 2000

%ice
  Nel 4
  Norb 20
end

*xyz  0 1
  Li 0 0 0
  H  0 0 1.597
*

    控制精度最重要的单一参数是 TGen。它与更精细的设置一并打印在输出中。 我们顺带指出，波函数展开及其截断可以在 CSF、组态或行列式（determinant）的 基组下进行。Chilkuri 等人chilkuri_ice1,chilkuri_ice2 详细讨论了这些不同的策略。
