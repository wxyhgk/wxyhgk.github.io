    半经验方法（Semiempirical Methods）¶

    半经验量子力学方法（Semi-empirical quantum mechanical methods, SQM）对于处理许多非常大的体系非常有用。它们采用定制的近似（tailored approximations）来大幅降低计算成本，同时在化学空间（chemical space）的很大部分上保持合理的精度水平。它们对于用 NEB-TS 模拟反应路径（reaction paths），或在 ONIOM 等多尺度方法中定义 SQM 区域特别有用。

    微分重叠忽略（Neglect of Differential Overlap）：CNDO、INDO、NDDO¶

    目前已实现若干基于"微分重叠忽略"（neglect of differential overlap）pople1970approx,sedlej1985semi 的方法，可用于能量和解析梯度计算，包括 AM1dewar1985am、PM3stewart1989comp、MNDOdewar1977theor,thiel1992theor,dewar1977am 以及 CNDO、INDO 和 NDDO 的其他变体。MNDO、AM1 和 PM3 方法仅适用于主族元素（main group elements），源自 Dewar 课题组的工作。它们经过优化以重现分子结构和能量学性质。较早的 CNDO/1,2 和 INDO/1,2 由 Pople 课题组开发pople1965chem,pople1966chem,santry1968am,santry1967chem,pople1967chem,clack1972chem,clack1974mol,clack1974theor,boehm1981theor，其设计目标是大致模拟最小基组从头算（ab initio）计算。Zerner 课题组的方法（ZINDO/1,2 和 ZINDO/S）与这些较早的方法密切相关，但针对过渡金属也进行了良好的参数化ridley1973theor,bacon1979theor,zerner1980am,anderson1986inorg,anderson1990inorg,anderson1991int,zerner1990reviews,zerner1992metal,zerner1996metal,cory1991chem,kotzian1992theor。 ZINDO/1（以及较少程度上的 ZINDO/2）适合几何优化。ZINDO/S 在中等组态相互作用（configuration interaction）水平上对电子激发态（electronically excited states）给出良好的结果，在计算大型过渡金属配合物中的电子和自旋分布方面也很成功anderson1991int,zerner1990reviews,zerner1992metal,zerner1996metal,cory1991chem,kotzian1992theor。 ZNDDO/1,2 方法已作为对应 INDO 方法的直接扩展实现到 ORCA 中，未改变任何参数。不过，这些方法受益于 NDDO 近似中对库仑相互作用略为更精确的表述nieke1984theor,koehler1972zchem。对这些方法的初步经验是，它们在过渡金属配合物结构计算方面优于相应的 INDO 方法，但总体上也有类似的缺陷。所有这些方法都提供解析梯度，可用于以较低的计算成本产生合理的分子结构，或对所研究体系的行为获得初步认识。但请勿尝试用 ZINDO/S（或 CNDO/S）做结构优化——这样做没有意义，而且会导致灾难性的结果，因为这些方法中没有对核排斥（nuclear repulsion）的精确表述。

    提示

    尽管 ORCA 没有实现较新的 MNDO 方法（如 PM6 或 RM1），但可以通过 ORCA 的外部优化器功能（External Optimizer feature）配合 MOPAC 来使用它们。这样，MOPAC 可以通过相应的封装脚本（wrapper script）与 ORCA 对接，为 ORCA 提供能量和梯度；该脚本可从 ORCA 外部工具 GitHub 仓库下载。

    基本用法（Basic Usage）¶

    基于 NDDO 的 MNDO、AM1 和 PM3 方法可通过简单输入关键词 !MNDO、!AM1 和 !PM3 调用。

    !MNDO

    !AM1

    !PM3

    这些及其他方法可通过 %method 块进一步定义，例如使用 INDO/1 参数集的 INDO：

    %method
   METHOD   INDO
   VERSION  INDO_1
end

    或通过直接将相应参数化指定为 METHOD：

    %method
   METHOD   INDO_1
end

    注意

    如果需要，也可以将半经验方法与 MP2 结合使用（仅限能量）。例如使用 Method AM1 和 DoMP2 true。这是否能使半经验计算的结果变得更好尚存疑问，但至少在 ORCA 中是可行的。

    自定义参数（Custom Parameters）¶

    您可以通过 %ndoparas 块以直接的方式更改内置的半经验参数。为此，任何元素专属的参数都可以通过数组 "P" 来定义：

    %ndoparas  
   P[<atomic number>,<parameter number>] <real>
end

    例如，我们可以将碳（Z = 6）的共振积分参数（resonance integral parameter）BS（s 壳层 beta，编号 25）设置为 20 eV：

    %ndoparas  
   P[6,25] 20
end

    可修改参数的完整列表见下文。其中大多数只对专家用户有意义。最常修改的参数是 Beta（编号 25 至 28）。注意，大多数程序在此处要求负数。在 ORCA 中，共振积分的定义方式使 Beta 为正值。

    扩展紧束缚方法（Extended Tight-Binding）：GFN0-xTB、GFN-xTB、GFN2-xTB¶

    ORCA 与 Grimme 及其同事的 xtb 程序进行了对接，允许用户使用流行的 GFN0-xTB、GFN-xTB 和 GFN2-xTB 哈密顿量（Hamiltonians）进行各类计算。grimme2017xtb,grimme2019xtb,pracht2019xtb 在技术层面，用户需要提供 Grimme 课题组发布的可执行文件。xtb 程序包可以从 https://github.com/grimme-lab/xtb/releases 免费获取，关于 xtb 独立程序及其工具的详细使用信息可在 https://xtb-docs.readthedocs.io/en/latest/contents.html 找到。ORCA 仅使用其中的 bin/xtb 文件。用户应将该文件复制到其他 ORCA 可执行文件所在的目录，并将其重命名为 otool_xtb。

    警告

    • 请使用 6.7.1 版本（或任何更新版本）的 xtb；较旧的版本与 ORCA 不再完全兼容，或者缺少功能，例如可能无法调用溶剂化模型（solvation model）！此外，Windows 用户应将 libiomp5md.dll 从 XTB 目录复制到 ORCA 目录。
    • 在 Linux 上，只有当默认 shell（即 /bin/sh）符合 POSIX 标准时 xtb 接口才能工作，例如 bash 或 dash，而 csh 或 tcsh 不行。

    xTB 方法可通过 GFN0-xTB、GFN-xTB 和 GFN2-xTB 关键词调用。GFN-FF 通用力场（generic force-field）可通过 GFN-FF 调用：

    ! GFN0-xTB  # Synonym: XTB0

    ! GFN-xTB  # Synonym: XTB1

    ! GFN2-xTB  # Synonym: XTB2

    ! GFN-FF # Synonym: XTBFF

    以下方法可与 XTB 结合使用：

    • 单点能计算（Single Point Energy）

    • 能量与梯度（Energy and Gradient）

    • 优化，支持各类约束（constraints）、弛豫势能面扫描（relaxed surface scans）等

    • 微动弹性带（Nudged-Elastic Band）计算

    • 数值频率计算（Numerical Frequency Calculations）

    • 内禀反应坐标（Intrinsic Reaction Coordinate）

    • 分子动力学计算（Molecular Dynamics Calculations）

    • QM/MM 计算

    注意

    • XTB0 是一种非自洽（non-self-consistent）紧束缚方法，因此其精度通常不如 XTB1 和 XTB2（有时甚至不如 XTBFF），尽管它比 XTB1 和 XTB2 快几倍。根据我们的经验，只有当 XTB1 和 XTB2 对感兴趣的体系都出现定性失败时，才推荐使用 XTB0。

    • 请注意，XTB0、XTB1 和 XTB2 也可用于初始路径的生成，或用于在 XTB 水平上计算初始过渡态（TS）结构，二者均可作为后续更高理论水平 NEB 计算的输入。更多细节请参阅章节 structurereactivity.neb。

    xTB 中的溶剂化（Solvation in xTB）¶

    xTB 计算中可以请求三种隐式溶剂化模型（implicit solvation models）： 1. 解析线性化泊松-玻尔兹曼（analytical linearized Poisson-Boltzmann, ALPB）grimme2021alpb 溶剂化模型 2. 区域分解 COSMO（domain decomposition COSMO, ddCOSMO）ddcosmo2013 3. 扩展类导体极化连续模型（extended conductor-like polarizable continuum model, CPCM-X）。cpcmx2023

    这些模型可通过简单关键词输入来请求：

    ! ALPB(solvent) # use ALPB

    ! DDCOSMO(solvent) # use ddCOSMO

    ! CPCMX(solvent) # use CPCMX

    其中 solvent 可为 tab:modelchemistries.semiempirical.xtb.solvation.solvents 中的任何溶剂。

    它们也可以通过 %xtb 块调用，这里以 ALPB 为例：

    %xtb
  DOALPB true
  ALPBSOLVENT "water"
end

    原生 GFN-xTB 与 GFN2-xTB（Native GFN-xTB and GFN2-xTB）¶

    6.1.0

    GFN1-xTB 和 GFN2-xTB 的原生实现

    ORCA 拥有自己的 GFN-xTB 和 GFN2-xTB 原生实现。与 xtb 程序的接口不同，原生 xTB 实现可以使用 SCF 和 绘图 基础设施。

    原生 xTB 方法可通过 !Native-GFN-xTB、!Native-GFN2-xTB 简单关键词调用：

    ! Native-GFN-xTB  # Synonym: Native-GFN1-xTB, Native-XTB1

    ! Native-GFN2-xTB # Synonym: Native-XTB2

    警告

    为了基于原子电荷和多极矩（multipole moments）实现更快的 SCF 重启（restart），原生 xTB 方法会写入一个 basename.xtbw 文件。如果存在这样的 .xtbw 文件，它将替代 .gbw 文件用于重启。

    自定义参数化（Custom parameterization）¶

    原生实现支持使用自定义半经验参数，方法是读取名为 basename.xtb.json 的 JSON 参数文件。该文件与 dxtb 程序中的 JSON 文件格式相同（dxtb 文档），可通过写出内部参数来生成。半经验参数的读写可通过 %method 块开启和关闭：

    %method
  XTBParamFile "orca.xtb.json" # set parameter filename to orca.xtb.json
  WriteXTBParam true      # if true: write parameters to orca.xtb.json file
  WriteXTBParamDry false  # if true: write parameters to orca.xtb.json file
                          # and exit
  ReadXTBParam false      # if true: read parameters from orca.xtb.json file
end

    默认情况下，参数文件将根据您计算的 basename 命名（basename.xtb.json），但可以通过 method 块中的 XTBParamFile 选项选择其他名称。若要进行一次仅从默认参数生成参数文件的空运行（dry run），请设置 WriteXTBParamDry true。

    警告

    请注意，原生 xTB 实现不允许更改基组。

    自旋极化的原生 xTB（Spin-polarized native xTB）¶

    原始 GFNn-xTB 方法的能量表达式是自旋无关的（spin-independent）。因此，即使对于开壳层体系，计算通常也使用 RHF/RKS 型波函数进行。由于自旋不进入能量表达式，具有较高自旋多重度的电子态其能量总是高于相应的低自旋态。 自旋极化 xTB 方法解决了这一缺陷。自旋极化变体grimme2023spxtb，称为 spGFN1-xTB 和 spGFN2-xTB，采用了一个简单的在位（on-site）自旋依赖项，可以稳定高自旋态，并允许用 xTB 方法筛选潜在的高自旋组态（high-spin configurations）。

    原生自旋极化 xTB 方法可通过 !Native-spGFN1-xTB、!Native-spGFN2-xTB 简单关键词调用：

    ! Native-spGFN1-xTB  # Synonym: Native-spGFN-xTB, Native-spXTB1

    ! Native-spGFN2-xTB # Synonym: Native-spXTB2

    注意，自旋极化项只影响高自旋态。与 RHF/RKS 型计算相比计算成本会增加，因为底层的 UHF/UKS 型波函数需要两次 Fock 矩阵对角化而不是一次——成本大约翻倍。

    使用原生 xTB 的 SCF（SCF with native xTB）¶

    原生 xTB 方法默认采用特殊的 SCF 设置，以模拟 xtb 程序的 SCF 流程，并覆盖所有其他 ORCA SCF 设置。这些特殊设置利用了 xTB 特有的功能，最显著的是 Fock 矩阵可以仅由原子电荷和多极矩构造。 由于这些捷径，这些特殊 SCF 设置对 xTB 方法通常比 ORCA 默认 SCF 更快。不过，默认 SCF 更稳健（robust），可能在 xtb SCF 失败的问题情形下成功收敛。

    若要改用标准的 ORCA SCF 基础设施，请在 %scf 块中将 UseXTBMixer 设为 false：

    %scf
  UseXTBMixer false    # if true (default): special xTB SCF is used
end

    使用 ORCA 默认 SCF 基础设施时，往往可以收敛具有挑战性的电子结构，但结果应谨慎使用。在必须强制 SCF 收敛的情况下，GFNn-xTB 哈密顿量往往不足以描述所处理的体系。此时应检查 Mulliken 电荷是否合理，并且可能需要通过上述参数文件略微调整逐元素的对参数（pair parameters）。

    警告

    注意，对于 xTB 方法，所有 SCF 迭代都是直接（direct）的。

    使用原生 xTB 的 FOD（FOD with native xTB）¶

    为了更好地考虑静态关联（static correlation），xTB 方法默认使用有限温度 SCF，电子温度为 300 K。相应的分数占据数加权密度（fractional occupation number weighted density, FOD）默认不打印，因为 300 K 这一温度太低，不适合作为诊断工具使用。通过在 %scf 输入块中将 XTBFOD 设为 true，可以启用 FOD 打印。电子温度可以像其他方法一样通过 SmearTemp 关键词控制：

    %scf
  XTBFOD true    # if true: Enable FOD printout and add FOD to density container
  SmearTemp 5000 # 5000 K is typically used for FOD plots with xTB methods
end

    原生 xTB 中的溶剂化（Solvation in native xTB）¶

    xTB 的原生实现包含 ALPB 溶剂化模型，可用溶剂与 xtb 程序中相同（见上文）。它通过与外部 ALPB 相同的关键词、经由简单关键词输入来控制：

    ! ALPB(solvent) # use ALPB

    此外，原生实现可以与 ORCA 中提供的其他溶剂化模型 一起使用，但需要注意的是，与 xTB 计算相比 CPCM 和 SMD 模型相当昂贵，因此推荐使用更快的 ALPB 溶剂化模型。
