    密度泛函理论（Density Functional Theory, DFT）¶

    由于其良好的成本-精度比（cost-accuracy ratio），Kohn-Sham 密度泛函理论（DFT）已成为量子化学的主力方法（workhorse）。 在过去几十年间，已经发展出了一整个"泛函动物园"（zoo of density functionals），它们在构造方式和设计理念上各不相同。 Perdew 提出的所谓雅各布天梯（Jacob's Ladder）图景（fig:modelchemistries.dft.jacobsladder）perdew2001jacobsladder 根据密度泛函的基本物理成分将其划分为不同的层级（rungs）。 层级越高，相应泛函的成本越高，但从概念上预期精度也更高。 然而，密度泛函的精度差异很大，通常建议仔细研究基准测试（benchmark studies）的结果。

    *:width: 400px

    密度泛函的雅各布天梯图景（Jacob's ladder picture）。*

    ORCA 在每个层级都提供了多种密度泛函，有的是原生实现，有的则通过 dft.libxc 提供。 这些泛函可以与各种基组和相对论方法结合使用。 此外，ORCA 还提供了一套实用的分辨率恒等式（resolution-of-identity, RI）方法工具包，用于加速 DFT 计算。

    关于可与 DFT 一起使用的色散校正（dispersion corrections）及相应的泛函专属参数，请参阅色散校正章节。

    另请注意，某些泛函（如 SCAN 和 Minnesota 系列）可能需要增强的数值积分网格设置。

    基本用法（Basic Usage）¶

    所有已实现的 DFT 方法都可以通过各自的关键词调用，例如使用简单输入行的 !PBE：

    ! PBE

    警告

    如果只定义了泛函，将使用各种默认设置，包括较小的 def2-SVP 基组、适当的 RI 处理以及默认的数值积分网格！为获得更高的精度，尤其应该调整基组！

    许多泛函也可以通过 %method 块调用，不过由于技术原因双杂化泛函（double-hybrid functionals）不可用：

    %method
   Method DFT        # equivalent to method DFGTO
   Functional PBE
end

    ORCA 还通过 %method 块提供更多实用功能，用于构造和修改泛函。这些专家选项在各泛函层级的相应章节中描述。各种其他泛函也可以通过 dft.libxc 调用。

    警告

    只有在简单输入中选择了 DFT 泛函时，RI/RIJCOSX 才会默认激活！ 如果改用 %method 块，则应通过 !RI 或 !RIJCOSX 显式指定这些近似。

    局域泛函（Local Functionals）¶

    局域交换-关联泛函（local exchange-correlation functionals）是按照公式 Eq 构造的最基本的一类泛函：

    \[ E_{\text{XC} } = E_{\text{LSD} }^{\text{X} } + E_{\text{LSD} }^{\text{C} }\qquad \text{(eqn:modelchemistries.dft.gga.exlocal)} \]

    它们通常将原始的斯莱特交换泛函（Slater exchange functional）与不同的局域关联泛函（如 VWN-Vvosko1980can 或 PW-LDAperdew1992physb）组合使用。 ORCA 中所有可用的局域泛函见 tab:modelchemistries.dft.local。

    梯度校正泛函（Gradient Corrected Functionals）：(meta-)GGA¶

    下一个层级对应于广义梯度近似（generalized gradient approximation, GGA）和 meta-广义梯度近似（meta-GGA）类型的梯度校正泛函。 这些类型泛函的简化交换-关联能量表达式见 Eq。(meta-)GGA 由于计算成本相对较低，特别适用于几何优化和筛选（screening）用途。

    基本泛函的定制（Customization of Basic Functionals）¶

    基本交换-关联泛函也可以通过 %method 块中的 Exchange、Correlation 和 LDAOpt 关键词从其组成部分构造。 这些分别控制泛函的交换部分、关联部分以及关联泛函的局域部分。 例如 BP86（!BP86）由 Becke 的 '88 交换（通过 X_BECKE）和 Perdew 的 '86 关联泛函（通过 C_P86）构造而成。在 ORCA 中，它还通过 C_PWLDA 对关联泛函的局域部分采用 Perdew 和 Wang 的 LDA 重新参数化perdew1992physb PWLDA：

    %method
   Method DFT
   Exchange     X_BECKE
   Correlation  C_P86
   LDAOpt       C_PWLDA
end

    可用组成部分的完整列表见 tab:modelchemistries.dft.gga.customizexc.keywords.block。

    正确选择关联泛函的局域部分对于确保结果的可重复性（reproducibility）至关重要。在 ORCA 中，几乎所有泛函都选择 PWLDAperdew1992physb 作为底层 LDA 泛函，因为它比 VWN 更好地拟合了均匀电子气（uniform electron gas）。对于 VWN（Vosko、Wilk 和 Nusairvosko1980can），存在若干参数化方式。他们在经典论文中给出了两组参数——一组在正文中（RPA 结果的参数化，称为 VWN-III），另一组在他们的关联能表 5 中（Ceperley/Alder 蒙特卡洛（Monte Carlo）结果的参数化，称为 VWN-V）。PW-LDA 的结果与 VWN-V 非常相似，而 VWN-III 给出的值则大不相同。 多年来，不同量子化学程序对同一泛函名称使用不同参数化的做法造成了一些混淆和结果的偏差。一个突出的例子是 ORCA 和 Gaussian 中 B3LYP 杂化泛函的不同实现。ORCA 使用与 TURBOMOLE 程序ahlrichs2000turbo,ahlrichs2000ency,ahlrichs1989chem 一致的 VNW-V，而 Gaussian 程序frisch1998gauss 则采用 VWN-III。使用 LDAOpt 关键词可以构造这两种变体：

    # consistent with TURBOMOLE
%method
   Method DFT
   Functional B3LYP
   LDAOpt C_VWN5
end

    # consistent with Gaussian
%method
   Method DFT
   Functional B3LYP
   LDAOpt C_VWN3
end

    为方便起见，这两种泛函可以分别通过简单输入关键词 !B3LYP（ORCA/TURBOMOLE 变体）和 !B3LYP/G（Gaussian 变体）调用。

    注意

    如果 LYP 是关联泛函lee1988phys，则会出现一种特殊情况，因为 LYP 不是对关联的校正，而是包含了完整的关联。 因此它在 B3LYP 泛函中的用法为：

    \[ E_{\text{B3LYP} }^{\text{C} } =E_{\text{LSD} }^{\text{C} } +c\left({ E_{\text{LYP} }^{\text{C} } -E_{\text{LSD} }^{\text{C} } } \right)\qquad \text{(eqn:modelchemistries.dft.gga.customizexc.ecb3lyp)} \]

    一些泛函还包含经验参数（empirical parameters），可以通过更改这些参数来改善与实验的符合程度。目前有少数几个参数可以更改（杂化泛函中使用的参数除外，后者将在后文描述）。 这些参数中的第一个是斯莱特 X\(_{\alpha }\) 方法中的 \(\alpha\)。理论上它的值为 2/3，HFS 和 LSD 泛函中就使用该值。然而，这一近似使交换贡献被低估了约 10%（相当显著！），对于分子建议使用 0.70-0.75 左右的值。第二个参数是 Becke 梯度校正交换泛函中的 \(\beta\)。 Becke 通过拟合稀有气体原子的交换能确定了值 0.0042。有证据表明，使用较小的基组时，略小一些的值（如 0.0039）对分子能给出改善的结果。 下一个参数是 PBE 交换泛函中出现的值 \(\kappa\)。Perdew 等人为了满足 Lieb-Oxford 界（Lieb-Oxford bound）将其定为 0.804。此后，其他研究者认为该参数取更大的值（约 1.2）会给出更好的能量学结果，revPBE 泛函就采用了这一思路。不过请注意，虽然 revPBE 给出略好的能量学结果，但几何结构也略差。 最后两个参数也与 PBE 有关。在 PBE 关联泛函中，存在 \(\beta_C\)（不要与 Becke 交换泛函中的交换参数 \(\beta\) 混淆），其原始值为 \(\beta_C=0.066725\)。存在具有不同 \(\beta_C\) 值的修正变体，例如 PBEsol 泛函和 PBEh-3c 复合方法。此外，PBE 交换泛函中的 \(\mu\) 参数也可以修改。在原始表述中，它通过 \(\mu = \beta_C \frac{\pi^{2} }{3}\) 与 \(\beta_C\) 相关联，但在后续变体中也已被修改。

    杂化 DFT（Hybrid DFT）¶

    用哈特里-福克理论的精确交换（exact exchange, HFX）替换部分 DFT 交换的想法是 Becke 于 1993 年提出的becke1993chem1,becke1993chem2。 这一方案通常称为杂化 DFT，单参数杂化泛函（one-parameter hybrid functional）最简单的表述见公式 Eq

    \[ E_{\text{hyb}}^{\text{XC}} =aE_{\text{HF}}^{\text{X}} + (1-a){ E_{\text{GGA}}^{\text{X}}} + E_{\text{GGA}}^{\text{C}}\qquad \text{(eqn:modelchemistries.dft.hybriddft.exchybrid)} \]

    更一般的描述由绝热连接模型（adiabatic connection model, ACM）给出。在 ACM 中，杂化泛函按照公式 Eq 用三个参数构造：

    \[ E_{\text{XC} } = a E_{\text{HF} }^{\text{X} } +\left( 1 - a \right)E_{\text{LSD} }^{\text{X} } +bE_{\text{GGA} }^{\text{X} } +E_{\text{LSD} }^{\text{C} } +cE_{\text{GGA} }^{\text{C} }\qquad \text{(eqn:modelchemistries.dft.hybriddft.acm)} \]

    其中，\(E_{\text{XC} }\) 是总交换/关联能，\(E_{\text{HF} }^{\text{X} }\) 是哈特里-福克交换，\(E_{\text{LSD} }^{\text{X} }\) 是局域（Slater）交换，\(E_{\text{GGA} }^{\text{X} }\) 是对交换的梯度校正，\(E_{\text{LSD} }^{\text{C} }\) 是关联能中基于自旋密度的局域部分，\(E_{\text{GGA} }^{\text{C} }\) 是对关联能的梯度校正。 多年来，人们发展出了构造杂化泛函的各种策略。这些策略从依赖尽可能少参数的物理驱动方法（如总体上平衡良好的 PBE0 泛函adamo1999chem）到更经验化的变体（如著名的三参数杂化泛函 B3LYPb3lyp）不一而足。 此外，还发展出了对 HF 交换混合比例的各种处理方式。使用固定比例 HFX 的基本杂化泛函通常称为全局杂化泛函（global hybrids），而具有可变 HFX 比例的泛函包括范围分离杂化泛函（range-separated hybrids）和局域杂化泛函（local hybrids）。ORCA 中提供了各种全局和范围分离杂化泛函。局域杂化泛函可能会在未来版本中实现。 ORCA 还提供了复杂的基础设施，用于创建和定制全局及范围分离杂化泛函。

    注意

    由于理论上杂化泛函比 (meta-)GGA 昂贵得多，ORCA 默认使用复杂的 RIJCOSX 算法来加速杂化 DFT 计算。

    全局杂化泛函的定制（Customization of Global Hybrids）¶

    全局杂化泛函参数可以通过 %method 块定制。关于基本交换和关联组成部分的定制，请参阅基本泛函的定制章节。杂化泛函的重要参数是 ACM 模型中使用的那些参数（参见公式 Eq）。在此，我们将使用 ACM 语法重建 PBE0 泛函（25% HFX）：

   Functional PBE

   ACM_B        0.75      # fraction of the GGA exchange
   ACM_C        1.00      # fraction of the GGA correlation
   ScalLDAC     1.00      # fraction of LDA correlation, must be
                          # equal to ACM_C 
end

    范围分离杂化泛函（Range-Separated Hybrid Functionals）¶

    与全局杂化泛函不同，范围分离杂化（range-separated hybrid, RSH）泛函将用于交换的双电子算符划分为短程（SR）和长程（LR）两个区域，其中短程部分通常由 DFT 交换描述，长程部分由哈特里-福克交换描述。在 ORCA 中，所有范围分离杂化泛函都使用 Hirao 及其同事的误差函数（error function）划分方法来区分这两个区域（参见公式 Eq）。hirao2001rangeseparation 这允许定义这样的 DFT 泛函：其短程部分由 LDA、GGA 或 meta-GGA 层级的适当交换泛函主导，长程部分则由哈特里-福克交换主导。

    \[ r_{12}^{-1} = \underbrace{\text{erfc}(\mu \cdot r_{12}) \cdot r_{12}^{-1} }_{\text{SR} } + \underbrace{\text{erf}(\mu \cdot r_{12}) \cdot r_{12}^{-1} }_{\text{LR} }\qquad \text{(eqn:modelchemistries.dft.hybriddft.rangeseparatedhybrids.erf)} \]

    其中 \(\text{erf}(x) = \frac{2}{\sqrt{\pi} } \in t_{0}^{x} \exp(-t^{2}) dt\)，\(\text{erfc}(x) = 1 - \text{erf}(x)\)。注意该划分仅应用于交换贡献；所有其他贡献（哈密顿量的单电子部分、电子-电子库仑相互作用以及 DFT 关联的近似）都不受影响。后来，Handy 及其同事handy2004CAMB3LYPLC 将这一拟设（ansatz）推广为：

    \[ r_{12}^{-1} = \underbrace{\frac{1 - [ \alpha + \beta \cdot \text{erf}(\mu \cdot r_{12})]}{ r_{12} }}_{\text{SR} } + \underbrace{\frac{\alpha + \beta \cdot \text{erf}(\mu \cdot r_{12}) }{r_{12} }}_{\text{LR} }\qquad \text{(eqn:modelchemistries.dft.hybriddft.rangeseparatedhybrids.erfgeneralized)} \]

    ORCA 中使用的这种划分形式（按照 Handy 及其同事的术语）如 fig:modelchemistries.dft.hybriddft.rangeseparatedhybrids.ansatz 所示。 范围分离拟设（range-separation ansatz）的图形描述。灰色区域对应哈特里-福克交换。\(\alpha\) 和 \(\beta\) 遵循 Handy 的术语handy2004CAMB3LYPLC。

    重要

    目前，RSH 泛函可用于积分直接（integral-direct）单点能计算、涉及一阶核梯度的计算（即几何优化）、频率计算、TDDFT、TDDFT 核梯度以及 EPR/NMR 计算。 与全局杂化泛函一样，默认使用 RIJCOSX 来大幅加速计算。也可以只使用 RIJONX。

    双杂化 DFT（Double-Hybrid DFT）¶

    除了将 HF 交换混合到给定的密度泛函中之外，Grimme 还提出混入一部分用杂化 DFT 轨道计算的MP2 关联能Grimme2006jcp。这类泛函可称为"双"杂化（"double-"hybrid）泛函。Grimme 的原始表达式为：

    \[ E_{\text{XC}} = aE_{\text{X}}^{\text{HF}} +\left({1-a} \right)E_{\text{X}}^{\text{DFT}} +\left({1-c} \right)E_{\text{C}}^{\text{DFT}} +cE_{\text{C}}^{\text{MP2}}\qquad \text{(eqn:modelchemistries.dft.doublehybriddft.exc)} \]

    Grimme 提出的第一个双杂化泛函是 B2PLYP。Grimme2006jcp 该双杂化泛函使用 B88 交换泛函和 LYP 关联泛函。它引入 53% 的哈特里-福克交换（\(a = 0.53\)），并用 MP2 关联能替换 27% 的 DFT 关联能（\(c = 0.27\)）。 此后，人们发展出了许多偏离原始思路的 DH-DFT 方法。例如 Grimme 提出了像 PWPB95goerigk2011chem 这样使用自旋分量缩放 MP2（spin-component-scaled MP2）的 DH 泛函。 此外，还开发并改进了其组成完全根据数据库经验拟合、不受任何物理约束或限制（如公式 Eq 中所提出的那样）的泛函，例如 Martin 的 DSD（dispersion corrected, spin-component scaled double-hybrid，色散校正、自旋分量缩放双杂化）泛函martin2010dsd,martin2011dsd,martin2013dsd，其中 revDSD-PBEP86-D4martin2021revdsd 是最知名的代表之一。XYG\(n\) 系列泛函goddard2009xyg 或 Head-Gordon 的 \(\omega\)B97M(2)Mardirossian2018 则为 DFT 部分和微扰理论部分采用不同构造的密度，后者还基于范围分离杂化泛函。 原则上，其他关联方法（如 dRPA 或更高阶 MP 理论）也可以在双杂化框架内使用。不过最常见的方法是采用经典的 MP2 或其自旋分量缩放变体。MP2 的 DLPNO 近似在 ORCA 中也可用，可用于大幅加速大体系的能量和梯度计算。DLPNO-DH 的精度和效率已由 Bursch、Neese 及其同事进行了广泛研究bursch2023dlpnodhs。 几乎所有双杂化泛函的共同点是其哈特里-福克交换比例相对较高，达 50% 甚至更多。 遵循 Grimme 方案的大多数经典双杂化泛函可用于单点能计算、解析梯度（因而也包括几何优化Neese2007doublehybrid、弛豫扫描和过渡态搜索）、偶极矩及其他一阶性质、磁学二阶性质（化学位移和 g 张量，MP2 部分不使用冻结芯近似），以及数值极化率和频率计算。 一些双杂化泛函还针对激发态应用进行了优化，它们会使用双激发校正（Doubles Corrections）来校正含时 DFT（TD-DFT）框架内的单激发态。其中一些（如 SCS-PBE-QIDH）仅对计算的 CIS(D) 部分使用自旋分量缩放。不过，其中许多最近也已针对基态性质进行了测试。GS_RSDHDFs

    注意

    ORCA 默认采用 RIJCOSX 和 RI-MP2。如果不希望这样，可以使用 !NORI 关键词全局关闭 RI，或者如果只想关闭 MP2 部分的 RI 近似，可通过 %mp2 块： 

    %mp2
   RI false
end
    事实上，几乎没有任何理由使用常规（conventional）MP2。

    注意

    注意，默认情况下不计算 MP2 响应密度（response density），因为其构造会带来显著的额外开销。在这种情况下，只有双杂化能量是正确的。 与解析一阶导数所得一阶性质相一致的 MP2 响应密度的计算，可以通过 %mp2 块中的 %mp2 density relaxed end 语句来请求。成本低得多的非弛豫（unrelaxed，期望值形式的）密度可以通过 %mp2 density unrelaxed end 来请求。不过，我们不推荐这样做，因为根据我们的经验，弛豫密度的变化相当可观，而非弛豫密度的理论地位远弱于其弛豫对应形式。

    全局双杂化泛函（Global Double-Hybrid Functionals）¶

    全局双杂化泛函基于相应的全局杂化泛函，并采用哈特里-福克交换和MP2 关联能的固定混合比例。 当前已实现的全局双杂化泛函列表见 tab:modelchemistries.dft.doublehybriddft.globaldoublehybrids。 Martin 及其同事的 revDSD-PBEP86-D4martin2021revdsd 在大多数热化学应用中已被证明是准确的。

    \(\omega\)B97M(2)¶

    某些双杂化泛函（如 \(\omega\)B97M(2)Mardirossian2018）必须应用于用另一种泛函收敛的轨道。这可以通过使用 MORead 和 MaxIter=1 的两步计算来完成。注意，由于轨道不是自洽获得的，用这种方式只能计算单点能——即不能得到密度、梯度或性质！ 这类泛函的使用可以通过Compound 脚本语言自动化。 一个用于 \(\omega\)B97M(2) 单点能计算的示例 compound 脚本如下所示：

    2
structure (0 1)
H           0.0          0.0          0.0
F           0.0          0.0          0.9
    *xyz 0 1
  H 0.0 0.0 0.0
  F 0.0 0.0 0.9
*
# ------------------------------------------------------------------------------------
# Energy calculation with the wB97M(2) double-hybrid functional, as defined in
# N. Mardirossian, M. Head-Gordon, J. Chem. Phys. 2018, 148, 241736.
# The final energy is calculated non-variatonally using wB97M-V orbitals.
# Note that FrozenCore is on default - one can turn it off using kw2 = "NoFrozenCore".
# Author: Georgi L. Stoychev
# ------------------------------------------------------------------------------------
# Optional variables:
Variable molecule = "water.xyz";
Variable charge   = 0;
Variable mult     = 1;
Variable NLOpt = "SCNL";        # Consistent with Q-Chem. "NL" likely very similar. Only matters for Step 1.
Variable Basis = "def2-TZVP";   # Should be TZ or higher for reliable results
Variable AuxC  = "def2-TZVP/C"; # RI-MP2 is used by default. Must be compatible with the Basis
Variable AuxJ  = "def2/J";      # RIJCOSX is used by default
Variable RIMP2 = True;          # Set to false to turn off RI-MP2
Variable Grid  = "defGrid2";    # Should be OK.
Variable kw1   = "";            # Additional simple input keywords for step 1
Variable kw2   = "";            # Additional simple input keywords for step 2
# Output variables
Variable EwB97MV, EwB97M2;      # Will hold the final energies
# Step 1: wB97M-V calculation to obtain the orbitals
NewStep
  ! wB97M-V &{NLOpt} &{Grid} &{kw1}
  *xyzfile &{charge} &{mult} &{molecule}
  %basis
    Basis "&{Basis}"
    AuxJ  "&{AuxJ}"
  end
StepEnd
EwB97MV.ReadProperty(propertyName="DFT_Total_En");
# Step 2: single iteration with the wB97M(2) functional + MP2 correlation to get the final energy
ReadMOs(1);
NewStep
  ! wB97M(2) &{NLOpt} &{Grid} &{kw2} NoIter CalcGuessEnergy
  %basis
    Basis "&{Basis}"
    AuxC  "&{AuxC}"
    AuxJ  "&{AuxJ}"
  end
  %scf
    IgnoreConv 1
  end
  %mp2 RI &{RIMP2} end
Step_End
EwB97M2.ReadProperty(propertyName="MP2_Total_Energy");
Print("");
Print("================================================================================\n");
Print(" wB97M-V Energy:  %20.10lf\n",EwB97MV);
Print(" wB97M(2) Energy: %20.10lf\n",EwB97M2);
End

    双杂化泛函的定制（Customization of Double-Hybrids）¶

    由于双杂化泛函使用全局杂化泛函或范围分离杂化泛函的可定制组成部分，它们也可以用类似的方式构造和定制。 双杂化的 MP2 关联处理可以通过 %method 块中的 DoMP2 true 和 ScalMP2C 关键词控制。 此外，MP2 处理还可以通过 %mp2 块进一步定制。例如，自旋分量缩放的范围分离双杂化泛函 \(\omega\)Pr²SCAN50 可以按如下方式构造： 

    ! RIJCOSX def2-TZVP/C NOTRAH
# wPr2SCAN50
%method
   Method       DFT
   DoMP2        true       # activates MP2 correlation part
   Exchange     X_WR2SCAN
   Correlation  C_R2SCAN
   LDAOpt       C_PWLDA
   ScalHFX      0.50       # fraction of static Hartree-Fock exchange
   ScalDFX      0.00       # fraction of static GGA exchange
   ScalGGAC     0.65       # fraction of GGA correlation
   ScalLDAC     0.65       # fraction of LDA correlation, must be equal to ScalGGAC 
   ScalMP2C     0.35       # fraction of MP2 correlation
   RangeSepEXX  true       # activates range-separated exchange
   RangeSepMu   0.214013   # range-separation parameter, should be >0
   RangeSepScal 0.50       # fraction of variable HFX, should sum to 1 with ScalHFX and ScalDFX
end
%mp2
   DoSCS        true       # activates spin-component-scaling
   RI           true       # activate RI-MP2
   PS           1.333      # opposite-spin-scaling parameter
   PT           0.000      # same-spin-scaling parameter
end
    许多其他与 MP2 相关的选项（如 DLPNO 处理和正则化（regularization））可在手册的 MP2 章节中找到。

    用于定制双杂化泛函的最重要 %method 块输入关键词（Most important %method block input keywords to customize double-hybrid functionals）。

    关键词（Keyword） 选项（Options） 描述（Description）

    LibXC 泛函库（LibXC Functional Library）¶

    可以在 ORCA 框架内使用 LibXC 提供的泛函 16。ORCA 所使用的 LibXC 版本会在输出开头打印出来。当 LibXC 用作您计算的一部分时，应引用 LibXC 的参考文献。参考文献见 libxc。 通过 LibXC 接口可用的泛函完整列表始终可以通过在命令行输入以下命令来查看： 

    orca -libxcfunctionals
    泛函列表的形式如下： 
    Functionals available via LibXC:
  No.:     ID / Keyword                    - Name
    0:     18 / lda_c_1d_csc               - Casula, Sorella & Senatore
    1:     26 / lda_c_1d_loos              - P-F Loos correlation LDA
    2:     15 / lda_c_2d_amgb              - AMGB (for 2D systems)
    3:     16 / lda_c_2d_prm               - PRM (for 2D systems)
    4:    552 / lda_c_br78                 - Brual & Rothstein 78
   ...
    列表按泛函的"层级"（LDA、GGA、meta-GGA 等）分组，然后按其建模的能量部分（关联、交换、交换-关联）分组。 关联泛函的名称中带有 '_c_'，交换泛函带有 '_x_'，合并的交换-关联泛函带有 '_xc_'。特定泛函的附加信息可以通过以下命令获取： 
    orca -libxcinfo [functional name]
    其中泛函名称是上述列表中的关键词。 在 ORCA 输入中指定 LibXC 泛函遵循标准格式： 
    %method 
  Method     DFT
  Functional hyb_gga_xc_b3lyp
end
    或者在分别指定交换和关联的情况下： 
    %method 
  Method      DFT
  Exchange    mgga_x_m06_l
  Correlation mgga_c_m06_l
end
    自 ORCA 5.0 起，CAM 型范围分离泛函通过 LibXC 接口得到支持。包含非局域（VV10）关联的泛函（参见 nl.theory）同样如此。VV10 部分由 ORCA 内部计算。其他非局域泛函（如 BEEF-vdW）不受支持。依赖动能密度（kinetic energy density）\(\tau\) 的 meta-GGA 泛函受支持，但依赖密度拉普拉斯（Laplacian of the density）\(\nabla^2\rho\) 的则不受支持。 双杂化泛函可以用 LibXC 组成部分按照前述定制章节构造，但只能使用分开的交换和关联组成部分。因此可以使用 exchange=gga_x_pbe 和 correlation=gga_c_pbe，但 functional=hyb_gga_xc_pbeh 不能用于双杂化表述。请注意，LibXC 计算的交换和关联贡献只是简单地分别被 ScalDFX 和 ScalGGAC 缩放，并不会单独缩放 LDA 组分或更改其他内部参数！

    筛选阈值（Screening Thresholds）¶

    当密度小于某个阈值时，LibXC 会跳过泛函的求值，转而将所有输出量设为零，以避免下溢和/或上溢（under- and/or overflows）。不同泛函的默认阈值由 LibXC 开发者设定，但有时可能过低。我们没有进行大量测试，但允许用户设置该阈值。类似地，为避免除零，对 \(\zeta\) 和 \(\tau\) 的最小值也存在阈值。默认值与泛函无关，可以使用以下关键词更改。 

    %method 
  LibXCDensityThreshold 1e-12    # seems to be reasonable
  LibXCZetaThreshold    2e-16    # default value in LibXC
  LibXCTauThreshold     1e-20    # default value in LibXC
end

    修改 LibXC 泛函参数（Modifying LibXC Functional Parameters）¶

    从 ORCA 5.1 起，可以修改 LibXC 接口所提供的泛函"外部参数"（external parameters）。 可用参数及其默认值可以在输出中查看，也可以用上述 orca -libxcinfo 命令查看。使用此接口时请谨慎，如果使用的是已发表的泛函重新参数化，请确保能够重现原始文献的结果。该语法要求使用 ExtParamX、ExtParamC 或 ExtParamXC 关键词之一（取决于修改的是哪个泛函），后跟引号中的参数名称，最后是新的值。例如，以下是 PWPB95 双杂化泛函的一个输入，其中用简单输入关键词设置大多数参数（如 MP2 缩放因子），只修改 mPW91 和 B95 LibXC 泛函的交换和关联参数：
