    辅助程序（Utility Programs）¶
    orca_2aim 生成适用于 AIM 分析的 WFN 和 WFX 文件
    orca_2json 将 gbw 文件中的信息转换为 JSON 文件
    orca_2mkl 生成供 molekel、molden 或其他可视化程序读取的 ASCII 文件
    orca_asa 计算吸收、荧光和共振拉曼光谱的谱带形状
    orca_chelpg 计算由静电势导出的电荷
    orca_euler 从 .property.txt 文件计算 Euler 角
    orca_exportbasis 以 ORCA 或 GAMESS-US 格式打印任何基组
    orca_fitpes 拟合双原子分子的势能曲线
    orca_mapspc 生成用于传入绘图程序的文件
    orca_mergefrag 合并两个独立 .gbw 文件的 MO 系数
    orca_pltvib 生成用于振动动画的文件
    orca_pnmr 计算顺磁 NMR 屏蔽张量
    orca_vib 从已完成的频率运行计算振动频率
    otool_gcp 计算几何 Counterpoise 校正（GCP）
    otool_xtb 允许将来自 Grimme 实验室 的独立 xTB 代码与 ORCA 一起使用

    ORCA 以一组预编译可执行文件的形式分发，因此不需要正式安装。 您只需将文件放在您选择的目录中。为确保各组件能够 正确交互，应将该目录添加到系统的 PATH 环境变量中。 或者，也可以在输入文件中手动指定各个组件的位置。

    orca_mapspc¶

    实用程序 orca_mapspc 为标准图形软件准备输入文件，以绘制 计算得到的线光谱以及相应的卷积连续谱带形状。 关于使用 orca_mapspc 所提供文件生成的绘图光谱示例， 见下列章节： tddft.semiemp、 vib.ir、 vib.raman 和 rocis.rixs）：

    orca_mapspc 的符号命令结构如下：

    orca_mapspc  Output-file Spectrum Options
    其中 
      Outfile-file    = name of an ORCA output file
                  name of an ORCA Hessian file (for IR and Raman)

  Spectrum        = abs    - Absorption spectra
                    cd     - CD spectra
                    ir     - IR spectra
                    raman  - Raman spectra

  Options         -x0value: Start of the x-axis for the plot
                  -x1value: End of the x-axis for the plot
                  -wvalue : Full-width at half-maximum height in
                            cm**-1 for each transition
                  -nvalue : Number of points to be used

    有关支持的光谱类型和高级选项的完整列表，在终端中不带参数运行 orca_mapspc。

    光学/X 射线吸收光谱（Optical/X-ray Absorption Spectra）¶

    这些关键词计算光学或 X 射线区域的吸收光谱，描述分子如何在特定能量处吸收光。

    偶极近似（Dipole Approximation）¶

    偶极近似假设相互作用由电偶极项主导。

    偶极近似（Dipole Approximation）¶

    偶极近似假设相互作用由电偶极项主导。

    • ABS（偶极长度表示的光学/X 射线吸收光谱）

    • 说明：使用长度表示的电偶极算符绘制吸收光谱（\(\mu = -er\)）。

    • 目的：适用于偶极跃迁主导的 UV-Vis 或 X 射线吸收光谱（XAS）。
    • 用例：常见于 UV-可见区的任何化学体系或 XAS。
    • 输出：强度（振子强度，或 UV/Vis 光谱的吸光度 \(\epsilon\)）对能量（例如波长）
    • 注意：对低能跃迁更准确；对高能 X 射线跃迁不太可靠。

    • 换算约定：振子强度 \(f_{osc}~= 4.31*10^{-9} * \epsilon\)

    • ABSV（偶极速度表示的光学吸收光谱）

    • 说明：使用速度表示的偶极算符（\(\mu \propto p\)）。

    • 目的：ABS 的替代方案，用于数值稳定性或交叉验证。
    • 用例：验证 ABS 结果。
    • 输出：与 ABS 类似。
    • 注意：对精确波函数与 ABS 等价，但对近似方法可能不同。

    超越偶极近似（Beyond Dipole Approximation）¶

    这些方法包含更高阶相互作用（例如四极、磁偶极）以提高精度。

    • ABSFFMIO（半经典完全物质相互作用算符的吸收光谱）

    • 说明：基于包含超越偶极近似项的半经典完全物质相互作用算符绘制光谱。

    • 目的：对具有显著四极或磁偶极贡献的体系准确。
    • 用例：推荐用于常规 X 射线吸收光谱（例如 K 边 XAS...）或含有电偶极禁阻跃迁的光学光谱。
    • 输出：含偶极及超越偶极贡献的常规光谱表。强度（振子强度，或 UV/Vis 光谱的吸光度 \(\epsilon\)）对能量（例如波长）

    • 注意：对大多数应用推荐且稳健。

    • ABSQ（含偶极、四极和磁偶极的吸收光谱）

    • 说明：包含电偶极（长度）、电四极和磁偶极贡献的超越偶极多极公式。

    • 目的：供专家用户使用的详细光谱，尤其是禁阻跃迁。
    • 用例：需要做复杂/高级分析的 X 射线吸收（例如过渡金属 K 边）。
    • 输出：处理所有可用表格，包括：
    • 与原点相关的表格
    • 原点调整后的表格 debeer2008tddft。
    • 与原点无关的表格，使用多极展开二阶项的修正高阶矩 jacob2012。
    • 注意：只要在输入运行中请求了 DecomposeFosc，就为高级/专家分析产生全面数据。

    光学/X 射线圆偏振光谱（Optical/X-ray Circularly Polarized Spectra）¶

    这些关键词处理圆偏振光的光谱，与圆二色（CD）和磁圆二色（(X)MCD）相关。

    • CD（圆二色）

    • 说明：绘制左旋和右旋圆偏振光的微分吸收。

    • 目的：探测手性分子或不对称跃迁。
    • 用例：对映异构体或手性配合物的 UV-Vis 光谱。
    • 输出：\((\Delta\epsilon)\) 对能量（例如波长）
    • 注意：需要手性体系。

    • 换算约定：旋转强度：\(R ~= 22.94 * \Delta\epsilon\)

    • MCD（磁圆二色）

    • 说明：绘制磁场存在下左旋和右旋圆偏振光的计算微分。

    • 目的：探测 MCD 过程中的自旋-轨道耦合或 Zeeman 效应
    • 用例：过渡金属配合物或磁性材料的光学（MCD）或 X 射线光谱（XMCD）性质。
    • 输出：左-右 (X)MCD 强度对能量（例如波长）以及左+右 ABS/XAS 强度对能量（例如波长）

    • 注意：需要通过 DoMCD 关键词在有资格的模块（TD-DFT、CASSCF、MRCI、RASCI、ROCIS、LFT...）中进行磁场模拟运行

    • CDV（速度表示的圆二色）

    • 说明：速度表示的 CD。

    • 目的：数值稳定的替代公式。
    • 用例：验证 CD 结果。

    • 输出：与 CD 类似。

    • CDFFMIO（完全物质相互作用算符的圆二色）

    • 说明：绘制采用包含超越偶极近似项的半经典完全物质相互作用算符生成的 CD 光谱。

    • 目的：超越偶极近似的更高精度，用于名义上偶极禁阻跃迁的 CD 光谱
    • 用例：适用于由电偶极禁阻跃迁主导的 CD 光谱。
    • 输出：超越偶极近似的 CD 光谱，\((\Delta\epsilon)\) 对能量（例如波长）

    自旋-轨道耦合（SOC）变体（Spin-Orbit Coupling Variants）¶

    这些关键词包含自旋-轨道耦合 1. 用于具有显著多重态结构的化学体系（L 边 XAS） 2. 用于含重元素（镧系、锕系）的化学体系 3. 用于探测自旋禁阻跃迁。

    • SOCABS（SOC 吸收光谱）

    • 说明：偶极长度表示下含 SOC 的吸收光谱。

    • 目的：考虑光学/X 射线吸收中的 SOC 效应。
    • 用例：SOC 效应主导的 ABS/XAS 光谱。

    • 输出：含 SOC 效应的吸收光谱。强度（振子强度，或 UV/Vis 光谱的吸光度 \(\epsilon\)）对能量（例如波长）

    • SOCABSV（速度表示的 SOC 吸收光谱）

    • 说明：速度表示的 SOCABS。

    • 目的：SOCABS 的替代公式，用于数值稳定性或交叉验证
    • 用例：验证 SOCABS 结果。

    • 输出：与 SOCABS 类似。

    • SOCABSFFMIO（完全物质相互作用算符的 SOC 吸收光谱）

    • 说明：SOCABS 采用超越偶极近似的强度贡献。

    一般说明（General Notes）¶

    • 偶极对速度：长度（ABS）和速度（ABSV）表示对精确波函数等价，但在近似计算中可能不同。
    • 超越偶极：FFMIO 和 Q 关键词包含四极和磁偶极项，对 X 射线光谱至关重要。
    • 自旋-轨道耦合：SOC 关键词对重元素或自旋禁阻跃迁必不可少。
    • 专家对常规：Q 变体产生供专家使用的详细输出；FFMIO 变体应用于常规分析。
    • ORCA 要求：某些关键词需要特定设置（例如 SOC 需要相对论方法，瞬态吸收方法需请求 DOTRANS true/all）。

    orca_chelpg¶

    orca_chelpg 程序按照 Breneman 和 Wibergbreneman1990 的方法计算 CHELPG 原子电荷。原子电荷通过拟合以再现分子周围规则网格上的静电势（ESP），同时将所有原子电荷之和约束为分子的总电荷。有关默认值的更多信息见 pop.chelpg。

    要从终端运行该程序，只需提供一个参数：gbw 文件名：

    orca_chelpg  MyJob.gbw

    作为可选参数，可以通过文件名提供总溶质密度矩阵。

    orca_pltvib¶

    orca_pltvib 程序与 gOpenMol（或 xmol）配合使用，在频率计算后生成振动模式的动画或图形。其用法很简单，在章节 vib.animation 中描述，同时附有在 gOpenMol 中生成这些图形的简要指南。

    该程序为每个振动模式生成 20 个动画帧。第一帧和最后一帧对应于 TS，中间帧按 \(sin(2\pi frame/20-1) * displacement\) 计算。 这产生以平衡几何结构为中心的平滑振荡图样。

    orca_vib¶

    orca_vib 是一个用于执行振动分析的小型"独立"程序。 它让用户可以控制原子质量等参数，这些参数影响 预测的振动频率，但与电子结构计算本身无关。

    该程序以 ".hess" 文件作为输入，生成的输出 本质上与标准 ORCA 频率计算产生的输出等价。关键优势是 .hess 文件是用户可编辑的 纯文本文件，允许手动修改，例如用于同位素位移 预测或自定义质量调整。

    orca_vib 的用法连同示例在章节 vib.isotopeshifts 中提供。通过将屏幕 输出通过管道传给文本文件，可以进一步用 orca_mapspc 处理振动数据， 从修改后的 Hessian 生成用于绘制 IR、Raman 或 NRVS 光谱的数据文件。

    orca_loc¶

    定域化是量子化学中广泛使用的技术。通过定义不同的 泛函，发展了各种定域化方法。其中最广泛使用的是 Foster–Boys（FB）和 Pipek–Mezey（PM）方法。在 ORCA 中，六种定域化方法可用： Pipek-Mezey 方法（PM）、 Foster-Boys 方法（FB）、 基于内禀原子轨道（IAO）的 PM 方法、 基于 IAO 的 FB 方法、 价层虚轨道的 PM 定域化（PMVVO）， 以及定域化内禀价层虚轨道（LIVVO）。

    FB 定域化有三种可用算法：常规算法（FB）、 更快的替代方案 NEWBOYS（推荐用于大体系中虚 MO 的定域化）， 以及增广 Hessian FB（AHFB）算法，适合获得紧密收敛的 轨道（例如用于具有适当容差的局域相关方法）。

    AHFB 算法系统地收敛到局部极小点，而不是 其他类型的驻点，它分三个阶段进行： (i) 获得一组初始的 NEWBOYS 定域轨道。 (ii) 接着进行增广 Hessian 极大化（有理函数优化）， 使用直接或 Davidson 对角化，取决于轨道数目， 以使其对小体系和大体系都高效。 (iii) 如果优化失败但增广 Hessian 具有正确的本征值结构， 则触发 Newton-Raphson 极大化。

    AHFB 中唯一可由用户调整的参数是容差 Tol。当本征值结构正确且轨道梯度的最大元素 \(4 \langle i|r|j\rangle \left( \langle j|r|j\rangle - \langle i|r|i\rangle \right)\) 低于 Tol 时发出收敛信号。这与其他定域化方法不同，后者使用两次连续迭代之间 定域化泛函变化量的总和作为收敛判据。

    由 Gerald Knizia knizia2013 开发的内禀原子轨道和内禀键轨道（IAOIBO）定域化方法按如下步骤进行： (i) 将占据 MO 投影到最小基组上得到 IAO。 在 ORCA 中，IAO 默认从原子的收敛 SCF MO 生成， 而不是像原始方法那样使用 MINI 或 STO-3G 基组。 不过，ORCA 默认计算的 IAO 电荷与原始 IAO 电荷非常相似。 默认行为可以用 IAOBasis 关键词更改。 (ii) 使用 PM 泛函将这些 IAO 定域化为 IBO。 (iii) 将 IBO 反变换回其原始基组。

    注意：在 IAOIBO 定域化之前打印正则 MO 的 IAO 部分电荷。 请务必包含所有占据 MO，因为缺少任何一个都会使 IAO 电荷失去意义。

    ORCA 中该方法的改进版本用 FB 替代 PM 作为定域化泛函， 得到 IAOBOYS 方法。对大体系，IAOBOYS 在计算上比标准 FB 方法更高效。 不过，值得注意的是基于 IAO 的定域化目前仅适用于占据 MO。

    价层虚轨道（VVO）可以按照参考文献 Derricotte2017LIVVO 中描述的方法定域化。该方法可简述如下：通过 IAO 与虚 MO 之间重叠的奇异值分解获得 VVO。 IAO 数目与占据 MO 数目之差即为 VVO 数目。不过，完整的虚轨道窗口 必须作为输入提供给 orca_loc！最终的 VVO 窗口打印在输出中。其余 虚 MO 不被修改，因此与 VVO 不正交。然后可以分别使用 PMVVO 和 LIVVO 关键词 按 PM 或 IBO 判据定域化 VVO。 后一选项对应于参考文献 Derricotte2017LIVVO 中的定域化内禀 VVO。

    在 ORCA 中请求 MO 定域化有两种方式：(i) 在输入文件中使用 %loc 块内联请求， (ii) 对预计算的 MO 使用 orca_loc 实用程序。

    orca_blockf¶

    orca_blockf 实用程序对 .gbw 文件中任意子空间内的轨道进行正则化。 在这里，正则化指的是 Fock 矩阵在指定轨道子空间内的 块对角化。

    orca_plot¶

    orca_plot 为用 ORCA 计算的各种轨道和密度类型生成可直接绘图的文件（如 .plt 和 .cube）， 以便用外部 2D 和 3D 图形软件进行可视化。 它可以用两种方式调用：

    1) 在 ORCA 输入文件中通过 %plots 块。这种方式允许您在运行过程中自动生成图形数据 （例如 .plt 或 .cube 文件）。细节见章节 utilities.plots。

    2) 计算后交互式地，使用已生成的 .gbw 文件，有下列可用参数：

    gbwfile     # name of gbw-file
-i          # interactive use of orca_plot
-m 256      # max. memory in MB (if needed)

    如有需要，-m 选项可用于控制绘图作业的内存使用。 orca_plot 可以在终端中调用，例如对名为 my.gbw 的 gbw 文件，调用方式为：

    orca_plot my.gbw -i

    orca_2mkl：旧版 Molekel 以及 Molden 输入（Old Molekel as well as Molden inputs）¶

    orca_2mkl 实用程序将 .gbw 文件转换为 .mkl ASCII 文件。 .mkl 文件包含的信息与 .gbw 文件基本相同， 但不包括 ORCA 特定的内部标志。ASCII 格式使其适合 外部使用——例如，可以由 Molekel 读取用于可视化 或由自定义后处理脚本访问。因此，.mkl 文件 为开发与第三方工具的接口提供了便捷的起点。 orca_2mkl 可以简单地这样调用：

    orca_2mkl BaseName 
      (will produce BaseName.mkl from BaseName.gbw)
orca_2mkl BaseName -molden
      (writes a file in molden format)
orca_2mkl BaseName -mkl
      (writes a file in MKL format)

    任何 gbw 类文件（包含 QRO、UNO、UCO 等轨道）都可以用 orca_2mkl 转换为 mkl 和 Molden 格式：

    orca_2mkl gbw_type_file.extension mkl_file.extension -mkl -anyorbs 
# or
orca_2mkl gbw_type_file.extension molden_file.extension -molden -anyorbs

    orca_2mkl 也可以反向运行，从 .mkl 文件生成 .gbw 类文件：

    orca_2mkl BaseName -gbw
      (will produce BaseName.gbw out of BaseName.mkl)

    该功能允许用户将分子轨道从外部来源导入 ORCA。虽然此功能很少使用且能力有限，但为希望尝试的用户在此列出。该用法的示例在随 ORCA 手册附带的 CASSCF 教程中演示。

    最后，一些第三方工具可用于将其他量子化学程序的波函数文件与 MKL 格式相互转换，例如 MOKIT（https://gitlab.com/jxzou/mokit）。与 orca_2mkl 结合，这提供了一种便捷方式，可在其他程序中使用 ORCA 生成的分子轨道，或反过来。一个示例应用是使用 ORCA 的 TRAH 方法收敛困难的 SCF 问题，然后将收敛的轨道传递给没有 TRAH 收敛器的另一个程序。另一个示例是从另一个程序读入困难体系的轨道，然后用 ORCA 计算其高水平单点能（使用另一个程序不支持的泛函或方法），而不必从 PModel 初始猜测收敛波函数。最后，MOKIT 可以将 MKL 格式转换为 PySCF 格式，这允许在 Python 环境中操作 ORCA 分子轨道。

    orca_vpot 程序计算用户定义的一组给定点上的静电势。它既可以与输入文件一起使用，也可以在交互模式下使用。它需要四个参数：

    orca_vpot  MyJob.gbw  MyJob.scfp  MyJob.vpot.xyz  MyJob.vpot.out

    第一：包含正确几何结构和基组的 gbw 文件

    第二：该基组下所需的密度矩阵（也许使用 KeepDens 关键词）

    第三：目标位置的 ASCII 文件（原子单位），例如

    6                 (number_of_points)
  5.0 0.0  0.0    (XYZ coordinates)
 -5.0 0.0  0.0
  0.0 5.0  0.0
  0.0-5.0  0.0
  0.0 0.0  5.0
  0.0 0.0 -5.0

    第四：目标文件，它将包含静电势，例如

    6                 (number of points)

  etc.

    orca_vpot  MyJob.densities

    orca_euler¶

    orca_euler 实用程序计算所计算的超精细耦合（HFC）或核四极耦合（NQC）张量与参考张量（通常是 g 张量或 D 张量）之间的相对取向。 如果在同一次运行中既计算了 HFC/NQC 又计算了 g-/D-张量，orca_euler 程序会在 ORCA 作业结束时自动调用。 或者，它可以作为独立程序执行，前提是 来自先前 NQC/HFC- 和 D- 或 g-张量计算的 .property.txt 文件可用。

    张量之间的取向表示为 3×3 旋转矩阵 R， 由三个 Euler 角参数化：\(\alpha\)、\(\beta\) 和 \(\gamma\)。 这些角通过三次绕不同轴的连续旋转将 A 与 B 对齐， 定义张量 A 相对于张量 B 的相对取向， 即在常用的 z-y-z 约定中：

    • 将 A\(_{xyz}\) 绕其 \(z\) 轴逆时针旋转 \(\alpha\) 得到 A\(_{x'y'z'}\)。

    • 将 A\(_{x'y'z'}\) 绕其 \(y'\) 轴逆时针旋转 \(\beta\) 得到 A\(_{x''y''z''}\)。

    • 将 A\(_{x''y''z''}\) 绕其 \(z''\) 轴逆时针旋转 \(\gamma\) 使其与 B 对齐。

    orca_euler 程序的选项如下：

    orca_euler prop-file options

  file    = basename of an ORCA .property.txt file

  options  
   -refg/-refD:         Reference tensor (g-tensor or D-tensor, default is -refg)
   -conv zyz/-conv zxz: Euler rotation convention (default is zyz)
   -order:              Ordering of the reference tensor (x, y, z) with respect to 
                        ORCA output (min, mid, max)
   -plotA:              plot the HFC-tensors
   -plotQ:              plot the NQC-tensors
   -detail:             print detailed information

    注意：

    • 默认情况下，只有当 \(S\) >\(\frac{1}{2}\) 且 D>0.3 cm\(^{-1}\) 时才将 D 张量用作参考张量。在所有其他情况下，将 g 张量用作参考张量。用户可以通过使用 --refg 或 --refD 手动选择参考张量（如果在 .property.txt 文件中可用）。

    • 默认情况下，Euler 旋转使用 z–y–z 约定执行。 可以通过使用选项 --conv zxz 手动选择 z-x-z 约定。

    • 默认情况下，g- 或 D-张量的轴根据其分量的大小分配： g\(_{\text{min} }\to g_{x}\)、 g\(_{\text{mid} }\to g_{y}\)、g\(_{\text{max} }\to g_{z}\)（D 类似）。 运行独立程序时可以用 --order 选项手动修改此排序，如下所示：
    -order 3 2 1: min \(\to\) z
    mid \(\to\) y
    max \(\to\) x
    -order 1 -2 3: min \(\to\) x
    mid \(\to\) y (flipped in the orientation)
    max \(\to\) z

    • 可以生成 .xyz 格式的文件，使用 orca_euler 程序 配合选项 --plotA 或 --plotQ 来绘制核超精细 和四极耦合张量。例如，原子 3（从零开始计数）的 HFC 张量 保存为 prop-file.3.A.xyz， 相应的 NQC 张量保存为 prop-file.3.Q.xyz。这些 xyz 文件 包含四个虚构原子（He、Ne、Ar、Kr），其中张量轴的方向 定义为向量：x 轴从 He 到 Ne； y 轴从 He 到 Ar；z 轴从 He 到 Kr。

    • 要打印旋转矩阵的实际定义以及关于相对取向的更多信息， 使用 --detail 选项。

    orca_lft¶

    从 ORCA 5.0 起，ORCA 提供了一个名为 orca_lft 的独立多重态程序。

    • orca_lft 专为实验光谱学家打造。

    • 它能够运行任意数量的光谱模拟，重点是 X 射线光谱。

    本节我们简要回顾 orca_lft 的主要功能。 更详细的描述和示例讨论请参阅 orca_lft 教程。

    1. 目标是能够计算给定 LFT 中心（离子）的各种光谱性质， 前提是能以例如 LFT 矩阵的对角元 （LFT 轨道能量）和给定 LFT 问题的 Slater-Condon 参数 的形式手动传递单电子和双电子积分的信息。

    2. 这将使实验光谱学家能够在实际运行实验期间 执行大量光谱模拟

    任何 LFT 问题都可以用单电子 \(H_{LF}\) 矩阵 元和 Slater-Condon 双电子积分 F0、F2、F4（或 d 壳层的 Racah 参数 A、B、C）来参数化。（图： fig:LFT_Integrals）

    用单电子能量和 Slater Condon 参数（SCP）定义 LFT 问题

    实践中我们需要知道：

    1. 给定 LFT 问题的 Slater Condon 参数

    2. \(H_{LF}\) 矩阵元或它们之间的关系（配体场 分裂、10Dq、AOM 模型）

    orca_lft 的设计工作流如下：

    • 在用户指定的 LFT 问题上求解一般 CI 问题：离子 类型、电子数、涉及的壳层、涉及的 多重度

    • 计算所有可能的非相对论态/多重度

    • 在 CSF 基上计算跃迁密度

    • 在给定 LFT 基（即 2p3d）中计算所需的跃迁矩

    • 计算各种性质，重点是 X 射线光谱（ABS、 XAS、XES、RIXS）的非相对论极限

    • 在准简并微扰理论基础上计算相应的 相对论校正态

    • 提供对各种相对论校正性质的访问（ABS、 XAS、XES、RIXS、MCD、XMCD、G 张量、D 张量、超精细耦合、 电场梯度）

    orca_lft 模拟的镍原子 \(Ni^{2+}\) L 边 XAS 光谱（红色）以及 存在 Oh 场时镍原子的 XAS 光谱

    orca_lft 的强大之处在于它完全可参数化。 这种灵活性通过 PARAMETERS 和 FUNCTIONS 子块的内在能力实现 - 参数可扫描性 任何给定参数——例如 D 壳层的 ZETA_D 自旋-轨道耦合（SOC）常数——可以： - 开启/关闭：ZETA_D= 0.0 - 在参数范围内扫描：ZETA_D= 0.0, 0.1, 11，即在 0.0-0.1 eV 范围内取 11 步。 - 新参数的定义 - 用户可以在 PARAMETERS 子块内定义任意数量或类型的自定义参数：例如 10Dq= 1.2 - PARAMETERS 和 FUNCTIONS 子块中的代数关系 - PARAMETERS 子块中的代数关系： 

    `DOh = 1.2`
`D1 = {-0.4*DOh}`
`D2 = {0.6*DOh}`
    - FUNCTIONS 子块中的代数关系： 
    `3   3 "1138.35 + D2" # => dz2`
`4   4 "1138.35 + D1" # => dxz`

    这提供了必要的灵活性，可以设置针对特定实验化学问题量身定制的任意参数化配体场理论（LFT）模型。

    orca_crystalprep¶

    ORCA 提供实用程序 orca_crystalprep，可以处理 晶体学 .cif 文件或 .xyz 超胞文件，并为嵌入簇计算生成 正确的输入。

    要进行常规的或 Ionic-Crystal-QMMM 中的嵌入簇计算，基本上需要定义 3 个区域：

    1. 将被量子力学处理的量子簇（QC）。

    2. 表示固体环境的点电荷区域（PC）。

    3. 位于 QC 和 PC 之间、主要作用是防止 QC 和 PC 区域之间电荷传递的边界区域（BR）或 ECP。

    这意味着第一步必须生成超胞（.xyz）， 并按计算设计分离不同区域。 第二步必须平衡体系的电荷。 最后，所有这些需要组合成正确的计算 输入。

    这显然是一个多步骤、常常跨平台的过程，

    1. 复杂，

    2. 耗时，

    3. 对用户不友好。

    orca_crystalprep 实用程序旨在自动生成 ORCA 嵌入簇计算的正确输入，目标是 让广大有经验和无经验的用户都能 以最小的工作量设置嵌入簇计算。

    从 ORCA 6.1 起，orca_crystalprep 实用程序在以下方面扩展了其能力：
    

      

    • 处理各种各样的 .cif 文件
      • 

    

    原则上任何类型的 .cif 文件都可以处理，以创建从分子到固体的任何化学体系的各种超胞，
涵盖大量结构复杂性和空间群对称性，如图 fig:SuperCells_CrystalPrep 所示。值得注意的是
晶体学信息文件（.cif）的结构自国际晶体学联合会（IUCr）引入以来经历了相当大的演变。在较早的 .cif 文件中——尤其是在 CIF 核心字典标准化之前生成的那些——头部
部分常常不一致，缺少诸如 _symmetry_space_group_name_H-M、_cell_length_a 或 _atom_site_label 等标准化数据项。
取而代之的是经常使用自定义或缩写记法，而必要的元数据（例如单位、对称操作或出版物引用）
常常不完整或完全省略。相比之下，符合 IUCr Core CIF 和 mmCIF 字典的现代 .cif 文件遵循严格
定义的语法，并包含支持互操作性、可重复性和自动化处理的广泛元数据。这些增强包括
显式的数据块命名约定、原子位置的层次化循环结构，以及通过 _space_group_symop_operation_xyz 等条目
明确定义的对称操作。鉴于这种差异，当代 .cif 解析器的设计必须具有足够的灵活性
以适应结构异质性，同时确保准确提取固有的晶体学信息。这包括对国际晶体学表所定义的全部 230 个晶体学空间群及其相应
子群的对称操作和晶格参数的正确识别和解释。这种稳健性对于实现可靠的对称分析、
结构精修以及晶体学和材料科学中的高通量计算工作流至关重要。在此背景下 Orca_crystalprep 包含
自己的对称操作库，它将尝试修复 .cif 文件中包含的任何潜在缺陷。如果未检测到对称操作则自动激活，
或者也可以通过关键词 SymmetryOperations true 请求
