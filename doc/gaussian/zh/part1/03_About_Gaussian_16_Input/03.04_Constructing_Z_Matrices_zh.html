    3.4 构造 Z 矩阵(Constructing Z-Matrices)

    3.4 构造 Z 矩阵(Constructing Z-Matrices)¶

    本节简要概述分子体系的传统 Z 矩阵描述方法。Z 矩阵的规模受到限制:变量的最大数目和计算中的最大原子数目。两者的上限保持一致,即最多 250,000 个实原子(包括幽灵原子,但不包括虚原子),以及最多 250,000 个 Z 矩阵中心(包括原子、幽灵原子和虚原子)。Z 矩阵的每一行给出分子中某一原子的内坐标。最常用的 Z 矩阵格式采用以下语法:元素标签, 原子 1, 键长, 原子 2, 键角, 原子 3, 二面角 [格式代码]。尽管这些示例使用逗号分隔行内各项,但也可使用任何有效的分隔符。元素标签是由字符构成的字符串,可以是原子的化学符号或其原子序数。若使用元素符号,可在其后加上其他字母数字字符,以构成该原子的识别标签。常见做法是在元素符号后加上一个用于区分的整数,如 C1、C2 等。原子 1、原子 2、原子 3 是先前已定义原子的标签,用于确定当前原子的位置。此外,也可使用其他原子在分子定义部分中的行号作为变量值,其中电荷与自旋多重度所在行为第 0 行。当前原子的位置由以下各项确定:它与原子 1 之间的键长、该键与原子 1 和原子 2 之间的键所成的键角,以及由原子 1、原子 2 和原子 3 所在平面与当前原子、原子 1 和原子 2 所在平面构成的二面角。注意,键角必须在 0 o < 角度 < 180 o 的范围内。二面角可取任意值。

    可选的格式代码参数用于指定 Z 矩阵输入的格式。对于此处描述的语法,该代码始终为 0。仅当 Z 矩阵的标准数据之后还有额外参数时才需要此代码,例如在 ONIOM 计算中。作为初始示例,考虑过氧化氢。其 Z 矩阵如下:

    H
O10.9

    O21.41105.0
H30.92105.01120.0

    Z 矩阵的第一行仅指定一个氢原子。下一行列出一个氧原子,并将其与氢原子之间的核间距指定为 0.9 埃。第三行定义另一个氧原子,其与原子 2(另一个氧原子)的 O-O 距离为 1.4 埃,且与原子 2 和原子 1 所成的 O-O-H 键角为 105 度。第四行也是最后一行,是唯一需要给出全部三个内坐标的行。它定义了另一个氢原子与第二个氧原子成键,H-O 距离为 0.9 埃,H-O-O 键角为 105 度,H-O-O-H 二面角为 120 度。Z 矩阵中可以使用变量来指定部分或全部数值。下面是前述 Z 矩阵的另一种写法:

    H
O1R1
O2R21A
H3R12A1D
Variables:
R10.9
R21.4
A105.0
D120.0

    分子的对称性约束会体现在内坐标中。两个 H-O 距离由同一变量指定,两个 H-O-O 键角也由同一变量指定。当此类 Z 矩阵用于以内坐标进行几何优化(Opt=Z-matrix)时,变量的值将被优化,以找到能量最低的结构。对于全优化(FOpt),变量必须线性无关,并且包括分子的全部自由度。对于部分优化(POpt),第二段中的变量(通常标为 Constants:)在优化过程中保持数值固定,而第一段中的变量则被优化:

    Variables:
R10.9
R21.4
A105.0
Constants:
D120.0

    有关内坐标优化的更多信息,请参见 Opt 关键字的讨论中的示例。

    此 Z 矩阵有以下几个值得注意的特点:

    • 原子符号后的整数 0 表示后续为符号形式的笛卡尔坐标。
    • 与二面角一样,笛卡尔坐标也可以通过符号变化相互关联。

    备选 Z 矩阵格式

    一种备选的 Z 矩阵格式允许使用两个键角(而非一个键角和一个二面角)来指定核位置。这通过在第二个角之后的附加字段中填入 1 来表示(该字段默认为 0,表示第三个分量为二面角):

    C4O10.9C2120.3O2180.00
C5O11.0C2110.4C4105.41
C6O1RC2A1C3A21

    第一行使用二面角,后两行使用第二个键角。

    3.4.2 模型构建器(Model Builder)¶

    模型构建器是 Gaussian 中用于快速指定某些特定类型分子体系的另一项功能 [119]。使用 ModelA 或 ModelB 选项请求该功能,它需要在任务文件的单独段中提供额外输入。模型构建器的基本输入称为短式分子矩阵,由若干行组成,每行通过原子符号定义一个原子及其连接关系,并且可以最多再包含六个条目。每个条目可以是以下三者之一:整数,即与当前原子成键的另一个显式指定原子的行号;原子符号(如 H、F),表示当前原子通过一个末端键与之相连;或表示与当前原子相连的末端官能团的符号。目前可用的官能团有 OH、NH2、Me、Et、NPr、IPr、NBu、IBu 和 TBu。短式分子矩阵还以如下方式隐式定义每个键周围的旋转几何:设原子 X 与 Y 已被显式指定,则 X 出现在 Y 所在的行中,Y 出现在 X 所在的行中。令 I 为 Y 所在行中位于 X 右侧的原子,J 为 X 所在行中位于 Y 右侧的原子,则原子 I 与 J 相对于 X-Y 键呈反式取向。短式分子矩阵之后可以跟随可选的行,用于修改生成的结构。以下各类行可以各出现零次或多次,且必须按此处给出的顺序成组排列:

    AtomGeom,I,Geom:

    通常,某原子周围的局部几何由其成键的数目和类型决定(例如,甲烷中的碳为四面体构型,乙烯中的碳为三角构型等)。同一中心处的所有键角必须相等。AtomGeom 行用于改变中心 I 处键的数值。Geom 可以是浮点数形式的角度,也可以是字符串 Tetr、Pyra、Trig、Bent 或 Line 之一。

    BondRot,I,J,K,L,Geom:

    该行用于改变 I-J 与 K-L 键围绕 J-K 键的取向。Geom 可以是二面角,也可以是字符串 Cis(≥0)、Trans(≥180)、Gaup(≥+60) 或 Gaum(≥-60) 之一。

    BondLen,I,J,NewLen:

    该行将 I-J 键的长度设为 NewLen(浮点数值)。

    模型构建器只能构建原子处于其正常价态的结构。若需要自由基,可以使用虚原子来有效地"束缚"其多余的价键,方法是在原子符号前加负号(例如 -H)。只有末端原子可以作为虚原子。两种可用模型(A 和 B)的区别在于:模型 A 在分配键长时会考虑键的类型(单键、双键、三键等),而模型 B 的键长仅取决于所涉及原子的类型。模型 B 适用于从 H 到 Cl 的所有原子(He 和 Ne 除外)。若请求模型 A,而所用原子没有定义模型 A 的键长,则改用相应的模型 B 键长。
