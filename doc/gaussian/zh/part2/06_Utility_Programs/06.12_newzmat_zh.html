    6.12 newzmat(分子结构格式转换工具)

    6.12 newzmat(分子结构格式转换工具)¶

    newzmat 工具主要用于在多种标准格式之间转换分子结构描述。它还可以执行许多相关功能,例如从 Gaussian 检查点文件中提取分子结构描述。其完整功能包括以下几项:

    • newzmat 可以在多种数据文件格式之间转换分子结构描述。这包括从其他程序生成的文件中生成 Z 矩阵(进而生成 Gaussian 输入),以及在这些程序的文件格式之间相互转换。因此,newzmat 关键字可用于从许多常用图形软件和分子力学软件包的数据文件生成 Gaussian 输入,使这些软件包能够充当 Gaussian 的图形化输入前端。生成的数据文件在适用时带有适当的对称性约束,以便高效计算。
    • newzmat 还可以从其他数据文件生成 Gaussian 16 检查点文件,并且(更重要的是)从检查点文件生成数据文件。该功能可用于提取数据,以便用可视化软件包显示。
    • newzmat 可以从几何优化过程中(或优化期间)的检查点文件中检索中间结构,以供复用或显示。

    newzmat 的已知问题

    • 对称性平均过程会根据仅近似对称的坐标推测预期的对称性,但它并不总能达到预期的对称性。对于以 6 位数字打印在 Gaussian 输出文件中的坐标,它能够恢复对称性,并且只要分子力学优化收敛得足够充分,对于分子力学给出的坐标通常也能正常工作。例如,在用 MacroModel 生成坐标时,有时需要在常规极小化之后再进行一次完整的牛顿-拉夫森步。

    • newzmat 会计算初始读入结构和最终结构的核排斥能,作为一致性检查。若二者不一致,则会打印警告。若差异显著,则表明程序出现故障。

    6.12.1 语法¶

    newzmat 的一般语法为:newzmat option(s) input-file output-file,其中 option(s) 为一个或多个选项,用于指定所需操作;input-file 为包含待转换(或待检索)结构的文件;output-file 为存放新分子结构描述(或 Gaussian 输入)的文件。合并两个文件的信息时使用略有不同的语法(见下文)。若省略输出文件名,则其使用与输入文件相同的基本名称,并加上表示文件类型的常规扩展名。一般而言,只要遵循扩展名约定,文件说明中即可省略扩展名。默认扩展名列于下表:

    扩展名 描述 选项形式

    .bgf Biograf 内部数据文件 bgf .cac CaChe 分子文件 cache .chk Gaussian 09 检查点文件 chk .com Gaussian 输入文件(Z 矩阵分子结构描述) zmat .com Gaussian 输入文件(笛卡尔坐标分子结构描述) cart .con QUIPU 系统数据文件 con .dat Model/XModel/MM2 数据文件 model .dat MacroModel 数据文件(可为格式化或非格式化) mmodel, ummodel .ent Brookhaven 数据文件(等同于 PDB) ent .com 晶体的分数坐标(需要恰好 3 个平移操作) fract .inp MOPAC 输入文件 mopac 蛋白质数据库格式(等同于 Brookhaven) .pdb pdb .ppp 某 PPP 程序(仅输出) ppp .xyz 未经修饰的笛卡尔坐标 xyz .zin 旧版 ZIndo zindo

    6.12.2 选项¶

    输入和输出分子结构描述格式的选项,由字符串 -i 或 -o(分别表示输入和输出)紧接上表中对应所需分子结构描述格式的选项形式字符串组成(中间不留空格)。例如,-ipdb 表示输入分子结构为 PDB 格式,并且若未指定扩展名,则对输入文件名应用扩展名 .pdb。同样,-oxyz 指定输出格式为笛卡尔坐标,并将默认扩展名 .xyz 用于输出文件名。默认的输入和输出选项为 -izmat 和 -ozmat。注意 -izmat 与 -icart 是同义词,二者中的任一个都可以读取包含任意分子结构描述格式的 Gaussian 输入文件:Z 矩阵、笛卡尔坐标,或内坐标与笛卡尔坐标混合的格式。

    选择输出格式

    为了与不受支持的可视化系统通信,首先应尝试的格式是 PDB 文件。该格式包含连接性信息,并且得到广泛支持。注意,某些软件包使用 .ent 扩展名而非 .pdb;-ient 和 -oent 选项选择前者,而 -ipdb 和 -opdb 选择后者。另一种常用的替代格式是 Mopac 文件格式。以下选项可进一步指定 newzmat 的输入:

    -ngeom N

    使用检查点文件中第 N 个结构的几何构型。其作用方式与 Geom=(NGeom=N) 相同。

    -ot list

    使用检查点文件中列出的结构的几何构型。列表可包含多个结构编号(以逗号分隔)以及结构编号的范围。例如,-ot 3,7 提取第 3 步和第 7 步的结构,-ot 2-5 提取第 2 步至第 5 步之间的所有结构。

    -step N

    使用 Gaussian 16 检查点文件中几何优化数据第 N 步的结构(仅对 -ichk 输入选项有效)。对于使用冗余内坐标(默认坐标系)的优化,此选项不可用。替代做法是在后续作业中,通过包含 Geom=(Check,Step=N) 的路由段从检查点文件中检索该结构。

    -ubohr

    输入文件中的距离以玻尔(Bohr)为单位指定(默认为埃)。

    -urad

    输入流中的角度以弧度为单位指定(默认为度)。

    以下选项从检查点文件中检索电荷变化,并将其作为普通原子和链接原子的 MM 电荷应用。这些选项指定要检索的电荷类型:

    -qmul

    Mulliken 电荷。

    -qesp

    ESP 拟合电荷。

    -qaim

    AIM 电荷。

    -qnpa

    NPA 电荷。

    -qapt

    APT 电荷。

    以下选项进一步指定输出文件格式:

    -mof1

    使用 MacroModel 格式 1(仅在指定 -ommodel 时有效)。

    -mof2

    使用 MacroModel 格式 2(指定 -ommodel 时的默认值)。

    -optprompt

    提示输入应优化的参数;用于在指定 -ozmat(或未包含输出选项)时,设置供几何优化使用的分子结构描述。默认情况下,所有不受对称性固定的参数都会被优化。

    -prompt

    在使用 -ozmat(或未指定输出选项)时,提示输入路由段和标题段行,以及电荷和多重度。由 newzmat 生成的 Gaussian 输入文件默认设置为 HF/6-31G(d) 单点能计算。

    6.12.3 示例¶

    以下命令从 PDB 文件 water.pdb 读取分子结构描述,并将包括等效 Z 矩阵在内的 Gaussian 输入文件写入 h2o.com:

    $ newzmat -ipdb water h2o-ozmat 为默认值,因此可以省略。

    Charge and multiplicity [0,1]? A return accepts the default values shown.

    newzmat 会提示输入 Z 矩阵的电荷和多重度,因为这些信息无法从 PDB 文件中确定。以下命令从 Gaussian 09 检查点文件 job-11234.chk 读取分子结构描述,并写入 PDB 文件 propell.pdb:

    $ newzmat -ichk -opdb job-11234 propell

    以下命令从检查点文件 newopt.chk 中读取优化第 5 步的分子结构描述,并生成 Mopac 文件 step5.inp:

    $ newzmat -ichk -omopac -step 5 newopt step5

    以下命令从 Mopac 文件 newsalt.inp 读取分子结构描述,并将包含等效 Z 矩阵的 Gaussian 输入文件写入 newsalt.com,同时提示输入路由段和标题段,以及分子的电荷和自旋多重度:

    $ newzmat -imopac -prompt newsalt

    Percent or Route card? # B3LYP/6-31G(d,p) Opt Route card?以空行结束路由段。 Titles? 咖啡因在 B3LYP/6-31G 下的优化Titles?以空行结束标题段。 Charge and Multiplicity? 0,1**

    利用 newzmat 合并两个文件的信息 newzmat 可以创建一个输入文件,其中合并了两个不同文件的数据。此功能有助于设置 ONIOM 计算:当希望将一个文件中的自定义设置(ONIOM 层、MM 原子类型、MM 原子电荷等)应用到另一个文件中不同的结构上时,此功能尤为有用。它允许您只指定一次自定义设置,然后将该信息应用到其他结构上。

    -t 和 -s 选项用于请求并控制合并输入文件的创建。合并命令的一般形式如下:

    $ newzmat -i type [-o type] -t format -s itemn files

    该命令要求指定现有输入文件(input)、正在创建的新输入文件(output)以及模板文件(template)的位置。命令行中输入、输出和模板文件的顺序取决于输入和/或模板文件是否为 Gaussian 检查点文件:

    是否为检查点文件: input?template?files arguments nn input output ignore template ny input output template ynignore output input template yy input output template

    上表中,"ignore" 为占位符。-t 需要与 -i 和 -o 一样的文件类型参数,并接受相同的取值。-s 选项可以多次指定,用于指定新输入文件所需的各项信息。它接受以下关键字,每个关键字后跟 1 或 2,分别表示该项应取自输入文件还是模板文件:

    XYZ n 几何结构(坐标、核电荷等)。MMT n MM 类型。MMC n MM 电荷。若被复制,且存在 ONIOM 数据,则也复制到链接原子上。PDB n PDB 信息(包括二级结构)。Con n 连接性。Oni n ONIOM 层及链接原子数据。Mic n MicOpt(冻结/优化原子及刚性块信息)。

    所有项目的默认值均为输入文件(即文件 1)。以下为一个示例。我们有一个 Gaussian 输入文件 allsetup.gjf,其中包含 MM 原子类型、MM 电荷、PDB 信息、连接性、ONIOM 层等。我们可以用以下命令将所有这些设置应用到 PDB 文件 new.pdb 中的结构上:

    $ newzmat -icart -tpdb -sXYZ2 -sCon2 allsetup.gjf newinput.gjf ignore new.pdb

    该命令仅从文件 2(模板文件 new.pdb)中取几何结构和连接性,其余所有内容(MM 原子类型、MM 电荷、PDB 信息、ONIOM 数据以及优化/冻结原子数据)均取自文件 1(输入文件 allsetup.gjf)。输出文件 newinput.gjf 即为合并结果。newzmat 的其他选项用于生成连接性信息、使用标准几何参数,以及确定和使用分子对称性。完整的连接性表可用于生成包含对称性约束的 Z 矩阵描述,也是输出分子力学程序数据文件所必需的。若使用包含完整连接性的输入格式(例如 MacroModel 数据文件),则使用其提供的连接性。然而,当提供 Z 矩阵或 MOPAC 格式输入时,只有内坐标规范所隐含的连接性信息

    才可用。因此,若要生成包含分子对称性的新 Z 矩阵,则必须补充生成其余的连接性信息。读入笛卡尔坐标时,自然不提供连接性信息,因此默认使用内部存储的原子半径生成连接性表。此外,分子力学程序在生成输入结构时,可能无法给出合适的键长,且常常产生接近但并非完全对称的坐标。各选项可控制对这些情形的处理方式。

    -allbonded

    在生成新的连接性信息时,假设所有原子均已成键。

    -bmodel

    在确定键长时,结合内部值使用标准 model B 键长。

    -density N

    为密度 N 生成自然轨道。此选项仅在生成 CaChe 文件时有用。对于 HF,N 应设为 0;对于 MP2 设为 2;对于 CI 设为 6;对于 QCISD 或 CCD 设为 7。

    -fudge

    利用内部值调整键长,以确保其合理。这是模型输入的默认值,在其他情况下不适用。

    -gencon

    使用内部半径生成连接性信息。

    -getfile

    要求为所有参数指定文件名,不接受标准输入和标准输出。

    -lsymm

    使用宽松的截断判定对称性。此选项隐含 -symav。

    -mdensity M

    从 -density 指定的广义密度中减去广义密度 M,得到差分密度,然后将其转换为自然轨道。

    -nofudge

    不调整键长。这是默认值,并且除模型输入外的所有情形下都是唯一的选择。

    -nogetfile

    取消 -getfile。

    -noround

    关闭 Z 矩阵参数的取整。

    -nosymav

    关闭输入坐标的平均化。

    -nosymm

    关闭所有对称性的使用。

    -round

    将 Z 矩阵参数取整至 0.01 Å 和 1 度。

    -symav

    利用近似对称操作对输入坐标进行平均,以获得精确对称性。

    -symm

    指定分子对称性。

    -tsymm

    使用严格的截断判定对称性。此为默认选项。

    -rebuildzmat

    重新构建 Z 矩阵,而不使用读入的 Z 矩阵(这是 Z 矩阵或 MOPAC 输入的默认行为)。此选项隐含 -gencon,该选项可缩写为 -redoz。
