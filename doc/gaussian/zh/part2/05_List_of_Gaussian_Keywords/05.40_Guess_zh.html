    5.40 Guess(初始猜测)

    5.40 Guess(初始猜测)¶

    Guess 关键字用于控制 Hartree-Fock 波函数的初始猜测。此关键字必须配合选项才有意义。默认使用 Harris 猜测。

    5.40.1 选项¶

    算法相关选项

    Harris

    对 Harris 泛函 [471] 进行对角化以获得初始猜测。这是所有 HF 和 DFT 计算的默认设置。

    Huckel

    请求生成 Hückel 猜测。这是 CNDO、INDO、MNDO 和 MINDO3 的默认设置。对于涉及较多第二周期原子的 PM6 计算,应考虑使用 Hückel 猜测。

    RdScale

    读入迭代扩展 Hückel 中所用原子硬度的缩放因子。默认值为 QEq 值的 7.0 倍。

    OldHuckel

    使用旧版 Hückel 猜测(Gaussian 03 之前的版本),而不是 CNDO 或更新的 Hückel 猜测。

    INDO

    使用 Gaussian 98 的默认猜测:第一周期体系使用 INDO,第二周期使用 CNDO,第三周期及以后使用 Hückel。

    AM1

    使用 AM1 计算生成初始猜测(目前仅适用于稀疏矩阵代码)。Guess=(AM1, Always) 会使几何优化的后续步骤在每个点都生成新的猜测,并比较旧点的密度与新猜测的能量,选取较优者。

    Core

    要求对核心哈密顿量进行对角化以形成初始猜测。这是 AM1、PM3、PM3MM、PM6 和 PDDG 的默认设置。

    TightConvergence

    将 SCF 的默认收敛标准改为 10−10,将 CIS、TD 和 CC 的收敛标准改为 10−8。CPHF 的收敛标准不变。

    轨道相关选项

    Permute

    读入初始猜测中轨道的置换。生成的猜测轨道编号按其在 SCF 中应使用的顺序给出。可使用范围(例如 7–12),未列出的轨道将按其原始顺序放在已列出轨道之后。对于开壳层体系,必须分别指定 α 和 β 轨道的置换列表(各列表之间以空行分隔)。

    Alter

    表示用于在 Hartree-Fock 波函数中占据的轨道不应是能量最低的轨道。通常,占据轨道是按照初始猜测程序所用单电子哈密顿量的本征值从低到高选取的。交换段由一组转置指令构成,用于将某个占据轨道替换为另一个(虚)轨道。每条转置单独占一行,包含两个整数 N 1 和 N 2(自由格式,以空格或逗号分隔),表示轨道 N 1 与轨道 N 2 互换。转置列表以输入段末尾的空行结束。对于 UHF 计算,需要两个这样的轨道交换段:第一个指定 α 轨道的转置,第二个指定 β 轨道的转置。两个段始终都必须提供,即使只需要 α 转置,也必须提供(可以为空的)β 段,反之亦然。表示 β 段为空的第二个空行必须包含在内。

    Mix

    要求对 HOMO 和 LUMO 进行混合,以破坏 α−β 对称性和空间对称性。这对于生成单重态的 UHF 波函数很有用。仅在生成复数初始猜测时才会默认进行轨道混合。NoMix 表示不混合轨道。

    DensityMix[=N]

    是否在形成初始猜测密度时混合占据轨道与虚轨道的贡献。N 默认为 -3(使用 Hückel 本征值决定混合哪些轨道)。

    CopyChk

    从检查点文件中原样复制用于猜测的 MO 和密度,不做未编辑、未投影和未检查处理。适用于从矩阵元文件导入时。

    Biorthogonalize

    对于非限制性猜测,对 α 和 β MO 进行双正交化,以使相反自旋的电子最大程度配对。将 UHF 波函数作为 ROHF 的猜测读入时会自动完成。此选项与 Guess=(BiOrth,Read,Only,Save) 组合使用时也很有用,可用 α 和 β 轨道尽可能匹配的结果替换正则 UHF 轨道,便于在 GaussView 或其他可视化软件中查看。

    NaturalOrbitals

    将自然轨道包含在检查点文件中。必须通过单独的作业步骤完成,该步骤需同时指定此选项以及 Only 和 Save。详见 Population 关键字的说明。

    过程选项

    Only

    Guess=Only 作为计算类型关键字使用,要求在计算并打印初始猜测后立即终止计算。注意,打印的轨道信息量由 Pop 关键字控制。Guess=Only 不能用于基于 MOPAC 的半经验方法(INDO、CNDO、MNDO、MINDO3)。此选项适用于预备运行,以检查是否需要修改组态。例如,可将 Guess=Only 与 CASSCF 一起使用,以获取 CAS 活性空间中 CI 组态数(以及初始轨道)的信息。Guess=(Only,Read) 也可用于从检查点文件中的数据生成布居分析和其他计算后分析。例如,仅使用这些选项即可基于检查点文件中的波函数进行布居分析。Guess(Only,Read) Prop 将使用检查点文件中的波函数计算静电性质。

    Always

    要求在优化的每个点都生成新的初始猜测。默认情况下,使用上一点的 SCF 结果作为下一点的猜测。

    Fragment=N

    由片段猜测或 SCF 解构建初始猜测。无论当前计算是否使用该猜测,都会将其保存到检查点文件中,以便在后续计算中使用。此选项通常与 Guess=Only 联用,用于由片段轨道生成初始猜测(否则将对每个片段执行完整的 SCF 计算)。原子到片段的分配,以及片段电荷和多重度的指定方式与"分子描述"中所述相同,但负的自旋多重度表示该片段中未配对的轨道将在合并集合中成为 β 自旋轨道。

    Local

    要求使用 Boys 方法 [184] 对轨道进行定域化。占据轨道与虚轨道分别定域化,并且在(可能经 LowSymm 或 NoSymm 合并后的)不可约表示之间不进行混合。收敛 SCF 波函数的定域化轨道分析可通过第二个作业步骤完成,该步骤的路由段中包含 Guess(Read,Local,Only) 和 Pop=Full。

    Sparse

    为初始猜测执行稀疏 SE 计算。此选项对于使用稀疏矩阵功能的超大规模 HF 或 DFT 计算可能有用。

    Extra

    从 RWF 文件读取轨道时(即在几何优化期间)生成一个额外的新初始猜测。默认情况下,若允许使用默认的 Harris 猜测、未请求组态修改,并且优化未采取由 ILSW 中变量 4 标记的小步长,则会执行此操作。使用 NoExtra 可禁用此功能。

    Fock

    从读写文件或检查点文件读取先前结果时,重用 Fock 矩阵而非轨道。若未指定 Guess=Alter,这是周期性边界条件计算的默认设置。NoFock 可禁用此行为,它是非 PBC 计算的默认设置。

    猜测的读写选项

    Read

    要求从检查点文件中读取初始猜测(通常与 Geom=Checkpoint 一起指定 Guess=Read)。此选项可与 Alter 组合使用,此时轨道从检查点文件中读取,投影到当前基组上,然后进行指定的修改。Checkpoint 是 Read 的同义词。TCheck 选项表示尝试从检查点文件中读取猜测,但在必要时生成新的猜测。

    Alpha

    在 Guess=Read 期间,对 α 和 β 猜测均使用 α 轨道。

    Translate

    Translate 要求将用于生成所读入猜测的原子坐标平移到当前原子坐标。这是默认设置。在某些特殊情况下可能失败,例如将某波函数用作化学计量不同的体系的猜测时,此时应指定 Guess=NoTranslate。

    Cards

    指定在生成初始猜测之后,部分或全部轨道将被从输入流中读入的轨道替换。通过替换全部轨道,此选项可用于从输入流读入完整的初始猜测。替换轨道放置在输入段中,位于轨道交换命令(如有)之后。对于 UHF,分别有 α 和 β 替换轨道输入段。替换轨道输入段(UHF 的 α 替换轨道段)以一行开始,该行指定读取替换轨道输入所用的 Fortran 格式,并用括号括起来。例如:(4E20.8)。该段其余部分包含一个或多个如下形式的条目:

    待替换的轨道 IVec(0 表示结束,-1 表示按顺序替换所有轨道)。 (A(I,IVec),I=1,N) 按第一行指定格式给出的新轨道。

    包含 IVec 的行采用 Fortran I5 格式。UHF 计算中的 β 替换轨道段与 α 段的区别仅在于省略了开头的格式说明行。示例部分给出了替换轨道输入的示例。

    Input

    从输入文件中读取一行,其中包含检查点文件的名称。除文件名外,也可以指定以下关键字之一:

    • generate 表示按常规生成猜测。
    • read 和 chk 表示从作业的检查点文件中读取数据。它们因此等同于 Guess=Read,并像往常一样使用 %Chk 或 %OldChk 指定的检查点文件。
    • none 表示完全跳过生成猜测。
    • dummy 生成一个无需任何计算的伪猜测。关于将此选项用于 ONIOM 的信息,请参见示例部分。

    Restart

    使用来自几何结构和/或基组不同的作业所保存在检查点文件中的重启数据,开始一次新的 SCF 计算。(选项名称有些容易引起误解。)

    Save

    在 Guess=Only 运行结束时,将生成的初始猜测保存回检查点文件。此选项适用于保存定域化轨道。

    Print

    打印初始猜测。

    对称性相关选项

    LowSymm

    要求将分子点群的不可约表示合并到 SCF 中 N 3 步骤所使用的对称性信息中,以允许波函数具有降低的对称性。这使得轨道(以及可能但不一定包括整个波函数)的对称性可以低于完整的分子点群。此选项仅适用于 GVB 计算,对于对称体系的计算通常是必需的(关于使用此选项的示例,请参见下文 GVB 关键字的说明)。

    该选项需要一行输入(格式为 16I2),给出要合并的不可约表示的编号,各新组之间以 0 分隔;列表本身必须以 9 结束。编号对应于输出文件中 Link 301 列出不可约表示的顺序(见下文示例小节)。由于该输入段始终恰好为一行,因此不以空行结束。注意,不可约表示的合并在轨道定域化之前进行,定域化轨道保留其所保持的任何对称性。Guess=NoSymm 无需读取任何输入即可取消所有轨道对称性约束。

    NoSymm

    要求取消所有轨道对称性约束。与 SCF=NoSymm 和 Symm=NoSCF 同义。

    ForceAbelianSymmetry

    强制初始猜测轨道按照阿贝尔点群的不可约表示进行变换。NoForceAbelianSymmetry 为默认设置。

    有效的选项组合

    只有合理的组合才是有效的。例如,Guess=(Always,Alter) 和 Guess=(Read,Alter) 按预期工作(前者中,交换指令只读取一次,并在每个几何结构上应用相同的交换)。相反,Guess=(Always,Read) 自相矛盾,将导致不可预测的结果。关于 Guess=(Cards,Alter) 等选项组合的输入段顺序,请参阅本章开头的输入段顺序表。

    5.40.2 限制¶

    Guess=Only 不能用于基于 MOPAC 的半经验方法:INDO、CNDO、MNDO 和 MINDO3。

    使用 Guess=Input 为 ONIOM 指定计算专用猜测

    Guess=Input 对于 ONIOM 作业很有用,尤其是在初始几何结构下某些子计算的 SCF 难以收敛时。可按如下步骤实现收敛:

    步骤 1. 使用 ONIOM=OnlyInput 打印各个计算的输入文件。

    步骤 2. 单独为问题步骤收敛 SCF(例如,使用 Stable=Opt)。

    步骤 3. 在确认找到了正确的状态后,运行带有 Guess=Input 的 ONIOM 计算,以获取各个状态的正确初始猜测。在 ONIOM 输入文件中,每个计算对应一行猜测(即对于 2 层 MO:MO,共 3 行),每行可以是检查点文件名、read(从常规检查点文件中执行 Guess=Read)或 generate(生成新的初始猜测),视情况而定。例如,若仅模型体系上的高层计算存在问题,输入将为:

    generate 真实体系上的低层计算。 空行。 guess_for_high.chk 模型体系上的高层计算。 空行。 generate 模型体系上的低层计算。
