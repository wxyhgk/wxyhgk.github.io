    5.72 SCF(自洽场)

    5.72 SCF(自洽场)¶

    该关键字用于控制 SCF 过程的运行。通过选项可以指定所需的行为、替代算法等。默认的 SCF 过程结合使用 EDIIS [679] 与 CDIIS,不使用阻尼或费米展宽。在 Gaussian 16 中,SCF=Tight 为默认设置。对于收敛困难的情形,SCF=QC 选项通常很有帮助。对于难以收敛的 ROHF 波函数(无法使用 QC 时),请在路由段中添加 Use=L506。有关 SCF 收敛与稳定性的讨论,请参阅文献 [680]。

    5.72.1 选项¶

    算法选择选项

    DIIS

    DIIS 启用、而 NoDIIS 禁止使用 Pulay 的迭代子空间直接求逆(DIIS)外推方法 [681]。

    CDIIS

    仅使用 CDIIS。CDIIS 同时隐含 Damp(阻尼)。

    Fermi

    在早期迭代中请求温度展宽 [682],并与 CDIIS 及阻尼结合使用。NoFermi 禁止费米展宽,为默认设置。默认情况下,Fermi 还隐含 Damp,并包含能级移动。

    Damp

    开启早期 SCF 迭代的动态阻尼。NoDamp 为默认设置。但若请求 SCF=Fermi 或 SCF=CDIIS,则会启用阻尼。注意,阻尼与 EDIIS 配合效果不佳。

    NDamp=N

    允许对最多 N 次 SCF 迭代进行动态阻尼(默认为 10)。

    QC

    请求使用二次收敛的 SCF 过程 [683]。默认情况下,距离收敛较远时进行线性搜索,接近收敛时采用 Newton-Raphson 步(除非能量上升)。该方法比带 DIIS 外推的常规 SCF 慢,但更可靠。SCF=QC 不适用于限制性开壳层(RO)计算。

    XQC

    若一阶 SCF 未收敛,则额外增加一步 SCF=QC。XQC 默认 MaxConventional=32。

    YQC

    提供一种新算法,适用于超大分子中难以收敛的 SCF 情形。它先进行最速下降,然后像 QC 一样进行缩放最速下降,之后切换为常规 SCF 而非二次收敛;仅当常规 SCF 未能收敛时才使用二次算法。YQC 默认 MaxConventional=32。

    MaxConventionalCycles=N

    将 SCF=XQC 与 SCF=YQC 期间常规 SCF 循环的上限设置为 N。

    PseudoDiagonalization=N

    在 Link 502 中尽可能使用伪对角化,仅在早期循环、末尾以及其间每第 N 次循环时进行完全对角化。PDiag 为该选项的同义词。这是半经验方法的默认设置(默认 N=30)。

    FullDiagonalization

    强制在 Link 502 中进行完全对角化。这是 HF 与 DFT 的默认设置。FDiag 为该选项的同义词。

    SD

    进行最速下降 SCF。

    SSD

    进行缩放最速下降 SCF。

    SaveKPoint

    在 SCF 结束时保存 k 点信息。NoSaveKPoint 表示不保存这些数据,除数值频率计算外,它是默认设置;对于数值频率计算,SaveKPoint 为默认设置。

    DM

    请求使用直接极小化 SCF 程序 [684]。该方法通常不如 SCF=QC,仅为向后兼容以及作为最后手段而保留。仅适用于 RHF 闭壳层与 UHF 开壳层计算。

    VShift[=N]

    将轨道能量移动 N×0.001(即 N 毫哈特里);N 默认为 100。该选项会禁用自动归档。N=-1 禁用能级移动;NoVShift 与此设置等效。

    MaxCycle=N

    将允许的最大 SCF 循环次数更改为 N;默认为 64(对于 SCF=DM 和 SCF=QC 为 512)。

    FullLinear

    指定 L508(SCF=QC、SD 或 SSD)在每次迭代时进行完整的线性搜索。默认情况下,仅当初始微迭代导致能量上升时才进行完整极小化。

    FinalIteration

    FinalIteration 在使用 DIIS 或直接 SCF 的 SCF 收敛后执行一次最终的非外推、非增量迭代;NoFinalIteration 则阻止该步骤。默认为 NoFinalIteration。

    IncFock

    强制使用增量 Fock 矩阵构造。这是直接 SCF 的默认设置。NoIncFock 禁止使用增量 Fock 矩阵构造,它是常规 SCF 的默认设置。

    Pass

    对于完全内存(in-core)计算,同时将积分保存到磁盘上,以避免在 Link 1002 中重新计算。仅在与 SCF=InCore 配合用于频率计算时有用。NoPass 强制在每个完全内存阶段重新计算积分。

    TightLinEq

    在整个 SCF=QC 过程中对线性方程组求解使用严格收敛。默认情况下,收敛判据随旋转梯度减小而逐步收紧。

    VeryTightLinEq

    在整个 QCSCF 过程中(微迭代)对线性方程组的求解使用更为严格的收敛。该选项有时用于接近线性相关的情形。VTL 为 VeryTightLinEq 的同义词。

    积分存储选项

    Direct

    请求直接 SCF 计算,即根据需要重新计算双电子积分。这是 Gaussian 中的默认 SCF 过程。除 MCSCF 二阶导数及使用复轨道的方法外,所有可用方法均可使用。

    InCore

    要求 SCF 在内存中存储完整的积分列表。若内存足够,直接 SCF 计算会自动这样做。SCF=InCore 用于强制完全内存存储,若内存不足则终止作业。NoInCore 禁止使用完全内存过程,对 SCF 与 CPHF 均适用。

    Conventional

    双电子积分存储在磁盘上,并在每次 SCF 迭代时读入。NoDirect 为 Conventional 的同义词。

    与收敛及截断相关的选项

    PtDensity=N

    指定每平方埃(Angstrom²)N 个点(N>0),或 -N 个小块(tesserae)(N<0)。默认为 5。

    Conver=N

    将 SCF 收敛判据设为 10−N。SCF 收敛要求密度矩阵的 RMS 变化小于 10−N,且密度矩阵的最大变化小于 10−(N−2)。注意,收敛测试并不使用能量变化;然而,通常 SCF 中密度矩阵的 RMS 变化为 10−N 对应于能量(原子单位)约 10−2N 的变化。对于 GVB 与 CASSCF 计算,SCF 收敛并非由密度矩阵的变化决定,而分别由轨道变化与能量变化决定。

    VarAcc

    在直接 SCF 早期使用适度的积分精度,之后再切换为完全精度。这是直接 SCF 的默认设置,可通过 NoVarAcc 关闭。VarInt 为 VarAcc 的同义词,NoVarInt 为 NoVarAcc 的同义词。

    Tight

    在 SCF 中使用常规的严格收敛。这是默认设置。与 TightIntegrals 同义。

    Big

    关闭可选的 O(N³) 步骤,以加快非常大体系(>5000 个基函数)的计算。

    MaxNR=N

    将 SCF=QC 与 SCF=YQC 中 Newton-Raphson 步的最大旋转梯度设为 10−N。低于此阈值时,程序切换到 QC SCF 过程(若使用 SCF=QC),或切换到常规 SCF 过程(若使用 SCF=YQC)。高于此阈值时采用缩放最速下降;高于其 100 倍时采用最速下降。N 的默认值为 2。

    对称性相关选项

    IDSymm

    在第一次迭代时对密度矩阵进行对称化,使其与分子的对称性一致(“初始密度对称化”)。NoIDSymm 为默认设置。

    DSymm

    在每次 SCF 迭代时对密度矩阵进行对称化,使其与分子的对称性一致(“密度对称化”)。NoDSymm 为默认设置。DSymm 隐含 IDSymm。

    NoSymm

    请求解除所有轨道对称性约束。它与 Guess=NoSymm 和 Symm=NoSCF 同义。

    Symm

    保留所有对称性约束:使每种对称类型(阿贝尔不可约表示)的占据轨道数与初始猜测相匹配。用于在整个计算过程中保持波函数的特定态。仅在 GVB 计算中为默认设置。

    IntRep

    要求 SCF 过程通过对称操作复制积分来考虑积分的对称性。即使波函数不具有完整的分子对称性,也允许使用短积分列表。适用于 L502(RHF、ROHF 与 UHF 的默认设置)及 L508(SCF=QC)。

    FockSymm

    要求 SCF 过程通过对 Fock 矩阵进行对称化来考虑积分的对称性(使用 petite 积分列表)。这是默认设置。FSymm 为 FockSymm 的同义词。

    重启相关选项

    Save

    每次迭代都将波函数保存到检查点文件中,以便 SCF 可以重启。这是直接 SCF 的默认设置。NoSave 禁止保存波函数。

    Restart

    从检查点文件重启 SCF。SCF=DM 无法重启。SCF=Restart 会跳过重启 SCF 计算时不必要、但在从具有不同基组或不同几何结构的计算中读取猜测时必要的步骤。相反,若要使用来自不同几何结构和/或不同基组计算的重启信息开始新的 SCF,请使用 Guess=Restart。
