    5.58 Optimization(几何优化)

    5.58 Optimization(几何优化)¶

    本关键字用于请求执行几何优化。结构将被调整,直到找到势能面上的驻点。若有解析梯度可用,则使用解析梯度。对于 Hartree-Fock、CIS、MP2、MP3、MP4(SDQ)、CID、CISD、CCD、CCSD、QCISD、BD、CASSCF 以及所有 DFT 和半经验方法,无论是极小化(优化到局部极小值)还是优化到过渡态和高阶鞍点,默认算法都是在冗余内坐标 [461, 583–587] 中使用 GEDIIS [582] 的 Berny 算法(对应 Redundant 选项)。Berny 算法的简要概述见本讨论的最后一小节。对于所有缺乏解析梯度的方法,默认算法是本征值跟随算法(Opt=EF)。Gaussian 还包含用于定位过渡结构的 STQN 方法。该方法由 H. B. Schlegel 及其同事实现 [461, 587],使用二次同步渡越方法接近过渡态的二次区域,然后使用拟牛顿或本征矢跟随算法完成优化。与极小化的默认算法一样,它默认在冗余内坐标中进行优化。当提供经验性的 Hessian 估计值和合适的起始结构时,该方法能够高效收敛。该方法通过 QST2 和 QST3 选项请求。QST2 需要两个分子规格作为输入,分别对应反应物和产物;QST3 需要三个分子规格,依次为反应物、产物以及过渡态的初始结构。原子的顺序必须 在所有分子规格中完全相同。 有关本方法输入与输出的示例,参见示例部分。关于几何优化的基础信息以及相关技术和陷阱,在 Exploring Chemistry with Electronic Structure Methods [152] 第 3 章中有详细讨论。关于优化及相关主题的综述文章,参见 [502]。Gaussian 16 支持广义内坐标(GIC),这一功能允许定义任意冗余内坐标,并将其用于优化约束及其他用途 [460]。Opt 有若干与 GIC 相关的选项,GIC 信息 小节介绍了使用 GIC 的方法及其在当前实现中的局限性。

    5.58.1 设置 Opt 目标¶

    默认情况下,优化搜索局部极小值。

    QST2

    使用 STQN 方法搜索过渡结构。该选项需要以两组连续的标题与分子规格部分输入反应物和产物结构。注意,两个结构中的原子必须以相同的顺序指定。使用 QST2 时不应指定 TS。

    QST3

    使用 STQN 方法搜索过渡结构。该选项需要以三组连续的标题与分子规格部分输入反应物、产物以及初始过渡态结构。注意,三个结构中的原子必须以相同的顺序指定。使用 QST3 时不应指定 TS。

    TS

    请求使用 Berny 算法优化到过渡态,而非局部极小值。

    Saddle=N

    请求使用 Berny 算法优化到 N 阶鞍点。

    Conical

    使用态平均 CASSCF 方法搜索锥形交叉或避免交叉。Avoided 是 Conical 的同义词。注意,若要定位单重态与三重态之间的锥形交叉,需要 CASSCF=SlaterDet。

    5.58.2 选项¶

    修改初始几何结构的选项

    ModRedundant

    除与 GIC 选项组合使用的情况外(见下文),ModRedundant 选项会在执行计算之前添加、删除或修改冗余内坐标定义(包括扫描和约束信息)。该选项需要在几何规格之后附加一个单独的输入部分;与 QST2 或 QST3 联用时,每个几何规格之后都必须跟随一个 ModRedundant 输入部分

    必须跟随每个几何规格。AddRedundant 与 ModRedundant 同义。ModRedundant 输入部分中的行采用以下语法: [Type] N 1 [N 2 [N 3 [N 4]]] [A | F] [Type] N 1 [N 2 [N 3 [N 4]]] B [Type] N 1 [N 2 [N 3 [N 4]]] K | R [Type] N 1 [N 2 [N 3 [N 4]]] D [Type] N 1 [N 2 [N 3 [N 4]]] H diag-elem [Type] N 1 [N 2 [N 3 [N 4]]] S nsteps stepsize N 1、N 2、N 3 和 N 4 为原子编号或通配符(见下文讨论)。原子编号从 1 开始,虚原子不计入编号。原子编号之后是一个单字符代码字母,表示要执行的坐标修改操作;如上所示,操作代码之后有时还需跟随额外的必需参数。可用的操作代码如下:A 若坐标已被冻结,则将其激活用于优化。F 在优化中冻结该坐标。B 添加该坐标并构建所有相关坐标。K 移除该坐标,并删除所有包含该坐标的相关坐标。R 将该坐标从定义列表中移除(但保留相关坐标)。D 为初始 Hessian 中该坐标所在的行和列计算数值二阶导数。H 将初始 Hessian 中该坐标的对角元素改为 diag-elem。S 执行松弛势能面扫描:将该坐标按 stepsize 递增共 nsteps 次,每次都从所得的起始几何结构出发执行一次优化。

    在原子编号的位置使用星号(*)表示通配符。以下是通配符用法的一些示例:

    所有以笛卡尔坐标指定的原子。 所有已定义的键。3 与原子 3 相关的所有已定义键。 * 所有已定义的键角。 4 围绕原子 4 的所有已定义键角。 * * 所有已定义的二面角。 3 4 围绕连接原子 3 与原子 4 的键的所有已定义二面角。*

    默认情况下,坐标类型由所指定的原子数决定:1 个原子为笛卡尔坐标,2 个原子为键长,3 个原子为键角,4 个原子为二面角。也可以选择使用 type 指定这些类型以及其他坐标类型:

    X 笛卡尔坐标。B 键长。A 键角。D 二面角。L 由三个原子指定的线性弯曲(若 N 4 为 -1),或由四个原子指定的线性弯曲,其中第四个原子用于确定线性弯曲的两个正交方向。

    有关 ModRedundant 用法的示例,参见示例部分。

    ReadOptimize

    读取一个输入部分,用于修改哪些原子参与优化。原子列表在单独的输入部分中指定(以空行结束)。默认情况下,原子列表包含分子中的所有原子,除非在分子规格中将某些原子指定为冻结,此时初始原子列表会排除这些原子。若结构从检查点文件读入,则待优化原子列表与检查点文件中的一致。ReadOpt 和 RdOpt 是该选项的同义词。ReadFreeze 和 RdFreeze 为已弃用的同义词。该输入部分采用以下格式:atoms=list [notatoms=list],其中每个 list 都是以逗号或空格分隔的原子编号、原子编号范围和/或原子类型的列表。关键字依次生效。以下是一些示例:

    atoms=3-6,17 notatoms=5 Adds atoms 3,4,6,17 to atom list. Removes 5 if present.
atoms=3 C 18-30 notatoms=H Adds all C & non-H among atoms 3, 18-30.
atoms=C N notatoms=5 Adds all C and N atoms except atom 5.
atoms=1-5 notatoms=H atoms=8-10 Adds atoms 8-10 and non-hydrogens among atoms 1-5.

    不带关键字的裸整数被解释为原子编号:

    1,3,5 7 Adds atoms 1, 3, 5 and 7.

    仅对 ONIOM 优化而言,可以类似地使用 block 和 notblock 来包含或不包含 ONIOM 分子规格中定义的刚性块。若 atoms 指定的原子与块中的原子存在矛盾(例如某原子包含在块中,却又被原子类型排除),Gaussian 16 将报错。可以将 noatoms 作为输入部分的第一项,从空原子列表开始。例如,以下输入优化原子 1–100 中的所有非氢原子,并冻结分子中的所有其他原子:

    noatomsatoms=1-100notatoms=H

    原子也可以通过 [not]layer 关键字按 ONIOM 层指定,其接受的取值为:real 表示真实体系,model 表示两层 ONIOM 中的模型体系,middle 表示三层 ONIOM 中的中间层,small 表示三层 ONIOM 中的模型层。原子同样可以通过 residue 和 notresidue 按残基包含或排除,二者接受残基名称列表。这两对关键字都是原子列表的简写形式。对使用 QST2 或 QST3 的过渡态优化,每个几何结构都会读取一个单独的输入部分。请注意,提供相互矛盾的输入(例如反应物与产物的冻结原子不同)将产生不可预测的结果。

    NoFreeze

    激活(解冻)所有变量,即不冻结任何原子,优化所有原子。当从包含冻结原子的检查点文件读入结构(即使用 Geom=Check)时,该选项很有用。使用 GIC 时不应使用该选项;应改用 GIC 输入部分中的 UnFreezeAll。

    通用过程选项

    MaxCycles=N

    将最大优化步数设为 N。默认值为 20 与所用冗余内坐标数的两倍中的较大者(对默认过程而言),或为待优化变量数的两倍(对其他过程而言)。

    MaxStep=N

    将优化步的最大尺寸(初始信任半径)设为 0.01 N Bohr 或弧度。N 的默认值为 30。

    Restart

    从检查点文件重启几何优化。此时,整个路由段将仅包含 Opt 关键字及其与原始作业相同的选项(另加 Restart)。无需其他输入(见示例)。

    InitialHarmonic=N

    以力常数 N/1000000 Hartree/Bohr² 向初始结构添加谐振约束。IHarmonic 是该选项的同义词。

    ChkHarmonic=N

    以力常数 N/1000000 Hartree/Bohr² 向保存在 chk 文件中的初始结构添加谐振约束。CHarmonic 是该选项的同义词。

    ReadHarmonic=N

    以力常数 N/1000000 Hartree/Bohr² 向输入流中读取的结构(输入取向下)添加谐振约束。RHarmonic 是该选项的同义词。

    MaxMicroiterations=N

    允许最多 N 次微迭代。默认值基于 NAtoms 确定,但至少为 5000。MaxMicro 是该选项的同义词。

    NGoDown=N

    在尝试下坡时,混合至多 N 个具有负本征值的 Hessian 本征矢。默认值为 3。若 N=-1,则仅执行常规 RFO 步。NoDownHill 等价于 NGoDown = -1。

    与初始力常数相关的选项

    除非另行指定,Berny 几何优化从对二阶导数矩阵(又称 Hessian)的初始猜测开始,该猜测由原子半径导出的成键关系和简单价力场确定 [461, 588]。在每个点上,利用计算得到的一阶导数不断改进该近似矩阵。这一方案通常效果良好,但在某些情况下,初始猜测可能很差,以致优化无法正常开始,或在前几步中花费大量步数改进 Hessian,而未接近优化后的结构。此外,对于过渡态优化,必须了解鞍点附近的曲率,因此默认的近似 Hessian 必须得到改进。有多种选项可以获取或计算几何优化的改进力常数,它们列于本初步讨论之后。另有两种提供初始 Hessian 的方法有时也很有用:

    • 输入新的猜测值:可以使用默认的近似矩阵,但对 Hessian 的部分或全部对角元素读入新的猜测值。这在 ModRedundant 输入中或 Z 矩阵的变量定义行上指定。例如:
    12H0.55

    字母 H 表示为该坐标指定对角力常数,其值为 0.55 Hartree/au²。

    • 数值计算 Hessian 的部分或全部:可以要求优化程序以数值方式计算二阶导数矩阵的一部分。在这种情况下,每个指定变量仅沿一个方向步进,而非精确求力常数所需的向上和向下两个方向。所得二阶导数不如频率计算所得的精确,但足以用于开始优化。当然,这需要程序对每个指定变量额外进行一次梯度计算。该过程通过变量定义行上的标志 (D) 请求:
    12D
123D

    此输入告诉程序在执行第一步优化之前计算三个点:通常的第一个点、原子 1 与 2 之间键长略微增加的几何结构,以及原子 1、2、3 之间键角略微增加的几何结构。程序将根据这三个点估计键(1,2)和键角(1,2,3)的所有力常数(包括对角和非对角元素)。该选项仅适用于 Berny 和 EF 算法。

    以下选项用于选择提供改进力常数的方法:

    ReadFC

    从检查点文件中提取力常数。这些通常是较低理论水平优化的最终近似力常数,或(更好的是)较低理论水平频率计算正确得到的力常数(后者远优于前者)。

    CalcFC

    指定在第一点使用当前方法计算力常数(仅适用于 HF、CIS、MP2、CASSCF、DFT 及半经验方法)。

    RCFC

    指定从频率计算中读取检查点文件中以笛卡尔坐标(而非内坐标)表示的力常数。通常更适合采用上文所述已转换为内坐标的力常数(CalcFC)。然而,频率计算有时会表明分子需要畸变至较低对称性。在这种情况下,基于旧内坐标的力常数无法使用,此时应使用 Opt=RCFC 读取笛卡尔力常数并进行变换。注意,笛卡尔力常数只有在频率计算之后才会出现在检查点文件中。若优化因近似二阶导数矩阵中负本征值数目错误而中止,则不能使用此选项。在后一种情况下,你可能希望从最近的几何结构出发,并数值计算部分导数(见下文)。ReadCartesianFC 是 RCFC 的同义词。

    CalcHFFC

    指定在第一点计算解析 HF 力常数。CalcHFFC 用于 MP2 优化;对于 DFT 方法以及 AM1、PM3、PM3MM、PM6 和 PDDG,它等价于 CalcFC。

    CalcAll

    指定在每个点使用当前方法计算力常数(仅适用于 HF、CIS、MP2、CASSCF、DFT 及半经验方法)。注意,振动频率分析会在收敛结构处自动进行,计算结果将作为频率作业存档。

    RecalcFC=N

    在优化过程中,于第 1 步以及此后每第 N 步进行解析二阶导数计算。

    VCD

    在 Hartree-Fock 或 DFT Opt=CalcAll 优化的每个点上计算 VCD 强度。

    NoRaman

    指定在 Hartree-Fock Opt=CalcAll 作业的每个点上不计算拉曼强度(因为该作业在优化的最终点进行频率分析)。拉曼强度会使每个中间二阶导数点的计算成本增加 10–20%。对于 Hartree-Fock 以外的方法,NoRaman 为默认值。

    StarOnly

    指定所指定的力常数以数值方式估计,但不进行优化。注意,这与振动频率的计算无关。

    NewEstmFC

    使用价力场估计力常数。这是默认值。

    EstmFC

    使用旧的对角猜测值估计力常数。仅适用于 Berny 算法。

    FCCards

    请求从输入流中读取能量(尽管该数值不被使用)、笛卡尔力以及力常数,格式与 Punch=Derivatives 写出的格式相同。该输入格式为:

    能量格式 (D24.16) 笛卡尔力 每行格式为 (6F12.8) 力常数 每行格式为 (6F12.8)

    力常数以下三角形式给出:((F(J,I),J=1,I),I=1,3Natoms),其中 3N atoms 为笛卡尔坐标的数目。

    收敛相关选项 这些选项仅适用于 Berny 算法。

    Tight

    该选项收紧用于判断收敛的力和步长截断值。使用 Opt=Tight 的优化将比使用默认截断值多执行若干步。对于具有非常小力常数的分子体系(低频振动模式),这可能是确保后续作业步中计算的频率具有足够收敛性和可靠性所必需的。该选项只能用于 Berny 优化。对于 DFT 计算,还应指定 Int=UltraFine。

    VeryTight

    极其严格的优化收敛判据。VTight 是其同义词。对于 DFT 计算,还应指定 Int=UltraFine。

    EigenTest

    EigenTest 请求对 Berny 优化中的曲率进行测试,NoEigenTest 则抑制该测试。该测试仅默认对过渡态开启,且仅针对内坐标(Z 矩阵)或笛卡尔坐标中的过渡态,并且推荐使用。偶尔即使未通过该测试,过渡态优化也能收敛,但仅建议计算资源充足者使用 NoEigenTest。

    Expert

    放宽 Berny 程序所施加的最大和最小力常数及步长限制。该选项可能加快收敛,但非常危险。它供专家在力和力常数与典型分子及 Z 矩阵差异很大的情形下使用,有时也与 Opt=CalcFC 或 Opt=CalcAll 联用。NoExpert 强制执行默认限制,且为默认值。

    Loose

    将优化收敛判据设为最大步长 0.01 au、RMS 力 0.0017 au。这些数值与 Int(Grid=SG1) 关键字一致,对于使用 DFT 方法的大分子初始优化可能合适,之后应使用默认(Fine)格点进行完全收敛的优化。不建议单独使用该选项。

    算法相关选项

    GEDIIS

    使用 GEDIIS 优化算法。在有梯度可用时,这是极小化的默认算法。

    RFO

    在 Berny 优化中请求有理函数优化(RFO)[589] 步。它是过渡态优化(Opt=TS)的默认算法。在 Gaussian 03 中,它也是使用梯度进行极小化的默认算法。

    EF

    请求本征值跟随算法 [589–591],该算法仅对没有导数的方法有用(对此类方法它是默认值)。适用于极小值与过渡态。EigenvalueFollow 等均为 EF 的同义词。与 Opt=Z-Matrix 联用时,最多可优化 50 个变量。

    ONIOM 相关选项

    Micro

    在 ONIOM(MO:MM) 优化中使用微迭代。这是默认值,微迭代所用的 L120 或 L103 取决于是否开启电子嵌入。NoMicro 禁止在 ONIOM(MO:MM) 优化中进行微迭代。Mic120 表示即使在机械嵌入下,也在 L120 中进行 ONIOM(MO:MM) 的微迭代,这是电子嵌入的默认值。Mic103 表示在 L103 中进行 ONIOM(MO:MM) 的微迭代。它是机械嵌入的默认值,且不能用于电子嵌入。

    QuadMacro

    控制在 ONIOM(MO:MM) 几何优化中是否使用耦合的二次宏步 [579]。NoQuadMacro 为默认值。

    坐标系选择选项

    Redundant

    使用 Gaussian 16 中可用的旧算法,根据当前笛卡尔坐标或 Z 矩阵值自动构建一组冗余内坐标,如键、键角和二面角。在这些冗余内坐标中使用 Berny 算法进行优化。对于可获得解析梯度的方法,这是默认值。

    Z-matrix

    使用内坐标 [592–594] 通过 Berny 算法进行优化。在这种情况下,使用关键字 FOpt 而非 Opt 可请求程序验证正在执行的是完全优化(即包括非活动变量在内的所有变量彼此线性无关,并张成分子对称性所允许的自由度空间)。POpt 形式请求在内坐标中进行部分优化。它还会抑制在每个点都包含二阶导数(通过 CalcAll 选项)的优化结束时的频率分析。有关 Z 矩阵分子规格的细节和示例,参见 构建 Z 矩阵。

    Cartesian

    请求使用 Berny 算法在笛卡尔坐标中进行优化。注意,初始结构可以使用任何坐标系输入。纯笛卡尔优化不能进行部分优化或冻结变量;若需要这些功能,可以在 Z 矩阵中以笛卡尔行指定所有原子的混合格式,并与 Opt=Z-matrix 联用。当分子规格使用不含任何变量的 Z 矩阵且指定了 Opt=Z-matrix 时,优化实际上将在笛卡尔坐标中进行。注意,可以使用 ModRedundant 选项构建其他多种坐标系,例如距离矩阵坐标。

    广义内坐标(GIC)选项

    GIC

    使用新的 GIC 算法自动构建一组冗余内坐标,并在 GIC 类型的内坐标中使用 Berny 算法进行优化。注意,该选项生成的坐标可以与默认算法生成的键、键角和二面角相同。然而,这些坐标在内部是作为广义坐标存储和处理的(例如,相对于笛卡尔坐标位移的相关解析导数可通过自动微分引擎自动计算)。GIC 更加灵活,原则上可以是任意标准数学函数的组合。注意,Geom=Checkpoint Opt=GIC 选项等价于 Geom=(Checkpoint,GIC)。

    AddGIC

    在使用新的 GIC 算法执行计算之前,添加、删除或修改 GIC 类型的内坐标定义(包括扫描和约束信息)。该选项需要在几何规格之后附加一个单独的输入部分。与 QST2 或 QST3 联用时,每个几何规格之后都必须跟随一个 GIC 输入部分。GIC 输入部分的语法见 GIC 信息。注意,Opt=(ModRedundant,GIC) 等价于 Opt=AddGIC。注意,Geom=Checkpoint Opt=ReadAllGIC 等价于 Geom=(Checkpoint, ReadAllGIC)。

    GICOld

    使用当前默认算法(与 Redundant 选项相同)自动构建一组冗余内坐标,然后将这些坐标转换为 GIC 并以 GIC 的形式处理。在 GIC 类型的内坐标中使用 Berny 算法进行优化。

    ReadAllGIC

    默认不构建任何冗余内坐标。取而代之的是,从输入流中读取用户提供的 GIC 定义并生成坐标。在 GIC 类型的内坐标中使用 Berny 算法进行优化。该选项需要在几何规格之后附加一个单独的 GIC 输入部分。与 QST2 或 QST3 联用时,每个几何规格之后都必须跟随一个 GIC 输入部分。GIC 输入部分的语法见 GIC Considerations 标签页。

    很少使用的选项

    Path=M

    与 QST2 或 QST3 选项联用时,请求在冗余内坐标中同时优化过渡态和一条 M 点反应路径 [595]。此类计算中不能冻结任何坐标。若指定 QST2,则与往常一样需要输入反应物和产物结构的标题及分子规格部分。路径上其余 M-2 个点随后通过在反应物和产物输入结构之间线性插值生成。能量最高的结构成为过渡结构的初始猜测。每个点都被优化至位于反应路径上,且最高点被优化趋向过渡结构。若指定 QST3,则如常在输入中还需包含第三组标题和分子规格部分,作为过渡态的猜测。路径上其余 M-3 个点通过两次连续线性插值生成:先在反应物与过渡结构之间插值,再在过渡结构与产物之间插值。默认情况下,中心点被优化为过渡结构,与能量的排序无关。在这种情况下,M 必须为奇数,以便路径上的点能在过渡结构两侧均匀分布。在同时优化计算的输出中,预测的过渡结构最终几何结构之后会列出所有 M 个收敛的反应路径结构。输入的反应物和产物结构的处理由其他选项控制:OptReactant、OptProduct、BiMolecular。注意,反应物区域内结构的 SCF 波函数可能与产物区域内结构的波函数差异很大。Guess=Always 可用于防止类反应物结构的波函数被用作类产物结构波函数的猜测。

    OptReactant

    指定在路径优化计算(Opt=Path)中,反应物的输入结构应被优化至局部极小值。这是默认值。NoOptReactant 则保留输入结构作为反应路径上已有的点(这通常意味着它此前已被优化至极小值)。OptReactant 不能与 BiMolecular 联用。

    BiMolecular

    指定反应物或产物为双分子体系,且输入结构将用作 Opt=Path 优化中的锚点。该锚点不会作为路径上的 M 个点之一出现。相反,它用于控制反应物一侧距过渡态的延伸范围。默认情况下,该选项关闭。

    OptProduct

    指定路径优化计算(Opt=Path)中产物的输入结构应被优化到局部极小值。这是默认行为。NoOptProduct 则保留输入结构,将其视为已位于反应路径上的点(通常意味着它此前已被优化到极小值)。OptProduct 不能与 BiMolecular 同时使用。

    Linear

    Linear 请求进行线性搜索,NoLinear 则抑制 Berny 优化中的线性搜索。在可能的情况下,默认使用线性搜索。

    TrustUpdate

    TrustUpdate 请求在 Berny 优化中动态更新信赖半径,NoTrustUpdate 则抑制该动态更新。对于极小值搜索,默认进行更新。

    Newton

    在 Berny 优化中使用 Newton-Raphson 步而非 RFO 步。

    NRScale

    NRScale 要求:若 Berny 优化中 Newton-Raphson 步的步长超过最大值,则将其按比例缩小。NoNRScale 会使步长在最大步长球面 [596] 上进行极小化。过渡态优化默认采用缩放,极小化默认采用球面极小化。

    Steep

    在 Berny 优化中请求最速下降步而非 Newton-Raphson 步。这仅与 Berny 局部极小值优化兼容。当起始点远离极小值时可能有用,但不太可能达到完全收敛。

    UpdateMethod=keyword

    指定 Hessian 更新方法。关键字可选值为:Powell、BFGS、PDBFGS、ND2Corr、OD2Corr、D2CorrBFGS、Bofill、D2CMix 和 None。

    HFError

    假定能量和力的数值误差分别为 HF 及后 SCF 计算所对应的值(分别为 1.0D-07 和 1.0D-07)。这是使用这些方法进行优化时的默认值,半经验方法同样如此。

    FineGridError

    假定能量和力的数值误差为使用默认格点的 DFT 计算所对应的值(分别为 1.0D-07 和 1.0D-06)。使用 DFT 方法并采用默认格点(或指定 Int=FineGrid)进行优化时,这是默认值。

    SG1Error

    假定能量和力的数值误差为使用 SG-1 格点的 DFT 计算所对应的值(分别为 1.0D-07 和 1.0D-05)。使用 DFT 方法并指定 Int(Grid=SG1Grid)进行优化时,这是默认值。

    5.58.3 可用性¶

    解析梯度可用于 HF、所有 DFT 方法、CIS、MP2、MP3、MP4(SDQ)、CID、CISD、CCD、CCSD、QCISD、CASSCF 以及所有半经验方法。Tight、VeryTight、Expert、Eigentest 和 EstmFC 选项仅适用于 Berny 算法。对于具有许多极低频振动模式的大分子,使用 DFT 进行优化时,若请求更大的 DFT 积分格点(Int=UltraFine),通常能更可靠地收敛。

    5.58.4 相关关键字¶

    IRC, IRCmax, Scan, Force, Frequency, Geom

    Gaussian 中的 Berny 几何优化算法基于 H. B. Schlegel 早期编写的程序,该程序实现了他发表的算法 [592]。此后该程序已大幅改进,采用了从其他算法借鉴或从未发表的技术,因此在此适当总结 Berny 算法的当前状态。

    在 Berny 优化的每一步,都会执行以下操作:

    • 除非已计算解析 Hessian 或处于第一步(此时对 Hessian 进行估算),否则将更新 Hessian。通常对于极小值使用迭代 BFGS 更新,对于过渡态使用迭代 Bofill 更新,并在冗余内坐标中进行;对于内坐标中的优化,则使用对原始 Schlegel 更新过程的修改。默认情况下,该估算由价力场导出 [588],但若有需要,也可以生成单位矩阵或对角 Hessian 作为估算值。
    • 若寻求极小值,则使用 Fletcher 方法 [597–599] 更新信赖半径(允许的最大 Newton-Raphson 步长)。
    • 梯度向量中对应冻结变量的分量被设为零或投影去除,从而消除它们对下一优化步的直接贡献。若寻求极小值,则在最新点与最佳先前点(先前点中能量最低者)之间进行线性搜索。若两点处均有二阶导数且寻求极小值,则首先尝试五次多项式拟合;若其在可接受范围内没有极小值(见下文),或者没有二阶导数,则尝试受约束的四次拟合。该拟合在两点处用多项式拟合能量及沿连线的一阶导数,并约束多项式的二阶导数恰好在其极小值处为零,从而保证多项式恰好有一个极小值。若此拟合失败,或得到的步长不可接受,则进行简单的三次拟合。只要最新点是迄今最佳点,任何五次或四次步都被视为可接受;但若最新点不是最佳点,则线性搜索必须返回位于最近点与最佳点之间的一点,该步才可接受。三次步除非位于两点之间或不大于上一步,否则绝不接受。最后,若所有拟合均失败且最新一步是迄今最佳点,则不进行线性步。若所有拟合均失败且最新一步不是最佳点,则沿连接最新点与最佳先前点的直线,朝其中点方向进行线性步。
    • 若最新点是迄今最佳点,或寻求过渡态,则利用当前(可能是近似的)二阶导数确定二次步。若进行了线性搜索,则二次步从线性搜索外推得到的点出发,并使用在线性搜索所用的两点之间插值估算的该点处的力。默认情况下,该步采用有理函数优化(RFO)方法 [589, 591, 600, 601]。当当前点的曲率不理想时,RFO 步比早期 Gaussian 版本中使用的 Newton-Raphson 方法表现更好。旧的 Newton-Raphson 步仍可作为选项使用。
    • 由二次步产生的步矢量中对应冻结变量的分量被设为零或投影去除。
    • 若二次步超过信赖半径且寻求极小值,则通过在信赖半径所定义的球面上寻找二次函数的极小值来将步长缩减至信赖半径,如 Jørgensen [596] 所述。若寻求过渡态或请求了 NRScale,则

    二次步仅按比例缩小至信赖半径。

    • 最后,根据最大力分量、力的均方根、最大步长分量及步长均方根的收敛判据进行收敛性检验。步长是最新点与下一个待计算点之间的变化(即线性步与二次步之和)。

    5.58.6 GIC 信息¶

    不提及 GIC 的、可与 Opt 关键字一同使用的选项应按说明工作——但 NoFreeze 除外,它不应与任何 GIC 相关选项组合使用。在后一种情形下,应在 GIC 输入部分使用 UnFreezeAll 标志。本节讨论在 Gaussian 输入文件中指定广义内坐标(GIC)的方法。GIC 有许多潜在用途:定义在几何优化过程中报告其值的附加坐标,在优化过程中冻结各种结构参数,指定用于扫描的参数,基于结构参数或它们之间复杂关系定义几何优化的约束,请求计算 Hessian 的部分,以及其他用途。GIC 输入部分与前面的输入以空行分隔。它包含一行或多行坐标定义、表达式或独立选项。以下是一个针对水分子的简单 GIC 输入部分,展示了部分可用功能:

    R(1,2) Define a bond length coordinate for atoms 1 and 2

    HOH=A(2,1,3)Freeze

    标签是用户为坐标指定的标识符,不区分大小写。标签可以包含字母和数字,但必须以字母开头。若未指定标签,程序将自动分配一个通用标签(例如 R1、R2、A1 等)。如需要,可在标签后附加一个用括号括起、以逗号分隔的选项列表。注意,在坐标定义的任何位置,方括号或花括号都可以替代圆括号。

    结构参数坐标 由表达式定义。最简单的表达式只需使用下述结构,标识分子中的某一特定结构参数。注意,星号可用作任意原子编号的通配符(见示例)。

    R(i,j)

    定义原子 i 与 j 之间的键长坐标。B、Bond 和 Stretch 是 R 的同义词。

    A(i,j,k)

    定义涉及原子 i、j 和 k 的非线性键角坐标,其中键角顶点位于原子 j。Angle 和 Bend 是 A 的同义词。

    D(i,j,k,l)

    定义由原子 i、j、k 所在平面与原子 j、k、l 所在平面之间的二面角。Dihedral 和 Torsion 是 D 的同义词。

    L(i,j,k,l,M)

    定义涉及原子 i、j 和 k 的线性弯曲坐标,其中角顶点位于原子 j。Linear 和 LinearBend 是 L 的同义词。线性弯曲定义包含两个分量,分别由 M 值 -1 和 -2 表示第一和第二分量(不允许其他值)。线性弯曲通过定义其两个正交方向来指定。可通过两种方式指定:

    Active

    如果指定的坐标尚不存在,则按给定表达式建立新坐标,并将其标记为 active 且未冻结。如果该坐标先前已定义,则将其标记为 active 且未冻结(无论其先前状态如何)。这是默认选项。Activate、Add 和 Build 是 Active 的同义词。当写在表达式之后时可缩写为 A。

    Frozen

    如果坐标不存在,则按表达式建立该坐标,将其标记为几何优化中的 active,并将其冻结在当前数值。Freeze 是 Frozen 的同义词。当写在表达式之后时可缩写为 F。

    Inactive

    如果坐标不存在,则按表达式建立新坐标并将其标记为 inactive。如果具有给定标签或给定表达式的坐标已建立并被标记为 active(冻结或未冻结),则将其标记为 inactive,从几何优化中移除。Remove 是 Inactive 的同义词。当写在表达式之后时可缩写为 R。

    Kill

    将该坐标从几何优化所用的内坐标列表中移除,同时将所有依赖坐标标记为 inactive。依赖坐标包括依赖于同一原子的任何坐标。例如,R(1,5) Kill 将移除坐标 R(1,5)(原子 1 与原子 5 之间的核间距),以及键角、二面角和其他依赖于原子 1 和原子 5 笛卡尔坐标(与分子中其他原子组合)的任何坐标。RemoveAll 是 Kill 的同义词。当写在表达式之后时可缩写为 K。

    PrintOnly

    将该坐标在初始几何结构中的初始数值写入 Gaussian 输出文件,然后将其标记为 inactive。

    Modify

    使用此选项时,坐标定义中必须包含标签。它用新表达式替换具有指定标签的旧坐标,并将新修改的坐标标记为 active 且未冻结。

    Diff

    为初始 Hessian 中与该坐标对应的行和列计算数值二阶导数。当写在表达式之后时可缩写为 D。

    FC=x

    将初始 Hessian 中该坐标对应的对角元素改为 x,x 为以原子单位表示的浮点数。ForceConstant 是 FC 的同义词。

    Value=x

    将给定内坐标的初始数值设为 x,x 为浮点数。数值的单位与 Gaussian 程序一致,由 Units 关键字定义(默认为埃或度)。当前笛卡尔坐标将被调整,以尽可能精确地匹配该数值。此选项应谨慎且少量使用。在 GaussView 等图形环境中设置所需的初始分子结构要容易且可靠得多。

    StepSize=x,NSteps=n

    这些选项用于指定松弛势能面扫描:坐标每次增加 x,共增加 n 次,并从每个得到的起始几何结构出发进行约束优化。x 应为以原子单位表示的正浮点数,n 应为大于 1 的整数。当这些选项写在表达式之后时,它们之间的逗号应替换为空格。

    Min=min,Max=max

    此选项与 Active、Freeze 或 Inactive 联合使用。当坐标数值满足 min ≤ value ≤ max 条件时,将其加入、冻结或设为 inactive。min 和 max 为浮点数,单位由 Units 定义(默认为埃或度)。若省略 Min 或 Max,条件分别变为 value ≤ max 或 value ≥ min。当这些选项写在表达式之后时,逗号应替换为空格。

    action OnlyIf condition

    action IfNot condition

    这些选项提供条件性的坐标操作。它们只能放在定义当前坐标的表达式之后。action 为 Active、Freeze 或 Inactive 之一。condition 是另一坐标的标签或表达式。若 condition 所指坐标对于 OnlyIf 为 active,或对于 IfNot 为 inactive,则对当前坐标执行指定操作。注意,条件检验只作用于其前面的 action,不作用于坐标定义中可能存在的其他选项。

    独立选项(Standalone Options):以下选项与坐标定义无关,全局适用。它们应单独写在一行输入中。

    FreezeAll

    冻结之前已添加为 active 的所有内坐标。

    UnFreezeAll

    解冻之前已添加为 active 冻结状态的所有内坐标。

    RemoveAll

    将之前已添加为 active(冻结或未冻结)的所有内坐标移除/设为 inactive。

    Atom i action

    对原子 i 的笛卡尔坐标施加指定的 action。若 i 为星号,则该操作适用于所有原子。action 为 Active、Freeze、UnFreeze、Remove(设为 inactive)、RemoveAll 和 XYZOnly 之一。这些选项的定义同上;XYZOnly 表示移除依赖于原子 i 的任何内坐标,但添加或保留该原子的坐标。默认 action 为 Active。

    当前实现中 GIC 的局限性(Limitations of GICs in the Current Implementation)

    在当前实现中,GIC 可以成功用于许多用途,包括优化约束和势能面扫描。然而,对于包含多个二面角的 active 复合坐标,存在潜在问题。一般而言,由键长和键角组合而成的坐标应表现良好。简单二面角也得到了较好的支持。涉及多个二面角的复杂表达式可用于冻结坐标和势能面扫描。但是,不应将其用作 active 优化坐标。

    在非 GIC 优化中,或仅使用常规二面角的 GIC 优化中,程序会谨慎处理这些坐标的周期性。例如,在判断几何步长是否过大、需要缩放回退时,程序能识别出从 1 度变到 359 度实际上是 -2 度的变化,而非 358 度。类似地,在通过数值微分力来更新 Hessian 时,需要内坐标下几何结构之间的位移,此时也会考虑周期性。当 GIC 由需要考虑周期性的部分组合而成时可能出现问题,典型情况是多个二面角的组合。例如,考虑以下 GIC:

    D1=D(1,2,3,4)
D2=D(5,6,7,8)
V1=D1+2*D2

    D1 和 D2 是二面角,但它们只是中间变量,并未在优化中用作变量。它们的周期性在复合坐标 V1 中目前未被识别。假设在一个几何结构中它们的数值分别为 1 度和 2 度,在下一个几何结构中为 1 度和 359 度。优化变量 V1 的变化应为 0 + 2×(−3) = −6 度,但实际上为 0 + 2×(357) = 714 度,看起来像是一个巨大的变化。这将导致优化算法表现非常差。V1 并不是简单的周期函数;必须在计算时对其各组成部分分别施加周期性,而当前的 GIC 实现并未这样做。

    Gaussian 输出中的 GIC 单位(GIC Units in Gaussian Output)

    被定义为纯距离和角度的 GIC(包括价键角、线性弯曲和二面角/扭转角)的数值,由笛卡尔坐标以原子单位(玻尔)计算,并以玻尔和弧度的形式在内部存储。但为方便用户,它们在 Gaussian 输出中按通常方式以埃和度表示。对于一般的 GIC(即该 GIC 不是纯笛卡尔坐标、键长或键角时),其数值是由笛卡尔坐标和以玻尔为单位的键长、以弧度为单位的角度,结合可选的用户自定义单位常数计算得到的函数。这类一般 GIC 数值(标记为 GIC)以相同单位计算、存储和输出:即,若 GIC 是键长的组合或价键角的组合,则任意单位分别变为键长的玻尔和角度的弧度。

    ModRedundant 格式输入的使用(Use of ModRedundant Format Input)

    GIC 的修改可以使用当前内坐标算法的 ModRedundant 格式读入。但是,旧格式仅适用于仅包含纯键长、键角或扭转角的 GIC。此外,旧格式与上述新 GIC 格式不能在同一输入段中混用。
