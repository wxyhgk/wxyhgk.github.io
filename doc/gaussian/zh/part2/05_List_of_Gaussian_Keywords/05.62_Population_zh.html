    5.62 Population(布居分析)

    5.62 Population(布居分析)¶

    此性质关键字控制分子轨道的打印以及多种布居分析和原子电荷分配。默认仅打印总原子电荷和轨道能量,但 Guess=Only 作业除外,其默认为 Pop=Full(参见选项)。布居分析在单点计算中进行一次,并在几何优化的第一个和最后一个点进行。注意,Population 关键字必须带有一个选项。布居分析所用的密度由 Density 关键字控制。注意,在一个作业步中只能使用一种密度和一种电荷拟合方法。若关注多种组合,可通过添加 Guess=Only Density=Check 的额外作业步来实现,以避免重复耗时的计算。布居分析结果以标准取向给出。由 Population 关键字控制的输出包括:

    • 分子轨道及轨道能量。默认包含所有轨道,但可以通过 Orbitals 选项将输出限制在特定的轨道范围内。
    • 原子电荷分布。如适用,还会给出每个片段的总电荷。
    • 多极矩:从偶极矩到十六极矩。振动频率计算期间默认也会计算 APT 电荷 [637]。

    5.62.1 选项¶

    输出文件内容控制选项

    None

    不打印轨道,也不进行布居分析。这是所有使用 ZIndo 方法计算的默认设置。

    Minimal

    打印总原子电荷和轨道能量。这是除 Guess=Only 和/或 ZIndo 之外所有作业类型和方法的默认设置。

    Regular

    打印 5 个最高占据轨道和 5 个最低空轨道,以及密度矩阵和完整的(逐轨道、逐原子)Mulliken 布居分析。由于输出大小与分子大小的平方成正比,对于较大的分子,输出可能非常庞大。

    Full

    与 Regular 布居分析相同,但打印所有轨道。这是 Guess=Only 作业的默认设置。

    Always

    在每个优化步都进行布居分析,而不仅仅是在初始和最终点。

    Orbitals[=N]

    AllOrbitals

    对最高的 N 个占据轨道和最低的 N 个空轨道进行布居分析,包括每个 MO 的原子贡献(见示例)。N 默认为 10。也可以用 AllOrbitals 代替 Orbitals=N 来请求分析所有轨道。对于开壳层计算,α 和 β 轨道均包括在内。

    ThreshOrbitals=N

    设置纳入单个轨道布居分析的最小贡献百分比。默认为 10。

    布居分析选项

    Bonding

    除标准分析外,还进行成键布居分析。这是一种 Mulliken 布居分析,其中仅保留位于不同中心上的基函数对的密度项。

    MBS

    进行最小基组 Mulliken 布居分析 [110, 181]。NoMBS 告诉程序不进行 MBS Mulliken 布居分析。

    Hirshfeld

    进行 Hirshfeld 布居分析 [638–640]。在计算 Hirshfeld 电荷的同时计算 CM5 原子电荷 [641]。CM5 是 Hirshfeld 的同义词。HirshfeldEE 选项还会请求计算原子间静电相互作用。

    Biorthogonalize

    对非限制性分子轨道进行双正交化,以最大程度地对齐电子对。

    SaveBiorth

    将双正交化后的轨道保存到检查点文件中,覆盖正则 MO。

    DCT

    对可用的未弛豫激发态密度(以及若请求了弛豫密度,则对弛豫密度)计算 Ciofini 的 DCT 电荷转移诊断 [642, 643]。

    NaturalTransitionOrbitals

    请求对 CI-Singles 或 TD-DFT 激发态进行自然跃迁轨道(NTO)分析 [644]。必须同时指定 Density=(Check,Transition=N),以指明用于生成轨道的跃迁密度。若要打印多个感兴趣态的轨道,可在初始激发态计算之后依次运行 Pop=NTO Density=(Check,Transition=N) Guess=Only 作业。NTO 是此选项的同义词。

    SaveNaturalTransitionOrbitals

    将生成的轨道保存到检查点文件中,若密度是从检查点文件中读入的,则替换正则轨道。SaveNTO 是此选项的同义词。若要可视化这些轨道,需要将其写回检查点文件。最好对每个态使用检查点文件的副本来执行此操作。在初始激发态计算(使用 %Chk=ex.chk)之后,可使用类似下面的方法为每个态生成可视化数据:

    $ g16 <<END Run a Guess=Only job just to

    用于生成轨道。

    %OldChk=excited.chk Work on copy of original check-

    检查点文件的副本。

    %Chk=staten.chk Checkpoint file for this state.
#Geom=AllCheckChkBasGuess=Only
Density=(Check,Transition=n) Pop=SaveNTO Repeat for each state.
END End of Gaussian input file.

    电荷保存选项

    NoOrthogonalize

    抑制对所保存的 Pop=(SaveMixed,NoOrthogonalize) 轨道进行正交化(主要用于可视化原始 NBO 结果)。

    Save Type

    计算得到的原子电荷可以存储在检查点文件中,供之后使用 Geom=Check 的 MM 计算调用。选项 Pop=SaveMulliken、Pop=SaveESP、Pop=SaveNPA、Pop=SaveCM5 等可用于保存相应的电荷。在多层 ONIOM 计算中,默认仅保存显式计算得到的电荷,即 QM 层中原子的电荷。输入文件中存在的任何原子电荷都不会被使用,而会被这些选项保存的新拟合电荷替换。附加选项 Uncharged 会保留输入文件中的原子电荷,仅对 QM 层中无电荷的原子拟合电荷。选项组合 Pop=(Uncharged, SaveMulliken)、Pop=(Uncharged, SaveCM5) 等将同时保存原始原子电荷以及为原本无电荷的原子新拟合的电荷。

    自然轨道相关选项

    NaturalOrbitals

    对总密度进行自然轨道分析。NO 是 NaturalOrbitals 的同义词。

    NOAB

    分别对 α 和 β 密度进行自然轨道分析。NaturalSpinOrbitals 是 NOAB 的同义词。

    AlphaNatural

    分别对 α 和 β 密度进行自然轨道分析,但仅存储 α 密度,用于 .wfn 文件(参见 Output=WFN)。NOA 是 AlphaNatural 的同义词。

    BetaNatural

    分别对 α 和 β 密度进行自然轨道分析,但仅存储 β 密度,用于 .wfn 文件(参见 Output=WFN)。NOB 是 BetaNatural 的同义词。

    SpinNatural

    生成自旋密度的自然轨道(α 取正值)。默认情况下,自然轨道不包含在检查点文件中。若要将自然轨道放入检查点文件,可使用如下形式的第二个作业步:

    --Link1--
%Chk= name
#Guess=(Save,Only,NaturalOrbitals)Geom=AllCheckChkBasis

    对生成的检查点文件运行 formchk 实用程序,以便为可视化准备轨道。

    用于生成静电势衍生电荷的选项

    MK

    生成拟合于静电势的电荷,其拟合点按 Merz-Singh-Kollman 方案 [645, 646] 选取。ESP 和 MerzKollman 是 MK 的同义词。可以使用 Pop=MK IOp(6/50=1) 并在 Gaussian 输入文件末尾单独一行指定文件名,来生成 Antechamber(用于生成 RESP 电荷的 AMBER 程序)所需的数据文件。

    MKUFF

    使用 MK 拟合方法,但采用 UFF 半径,该半径覆盖整个元素周期表。

    CHelp

    生成拟合于静电势的电荷,其拟合点按 CHelp 方案 [647] 选取。

    CHelpG

    生成拟合于静电势的电荷,其拟合点按 CHelpG 方案 [648] 选取。

    HLY

    指定 Hu、Lu 和 Yang 电荷拟合方法 [649]。

    HLYGAt

    指定 Hu、Lu 和 Yang 电荷拟合方法,但使用 Gaussian 标准原子密度,而非 HLY 所用的原子密度。HLY 的作者仅对前 18 个元素参数化了原子密度。这是使用 HLY 拟合方案、但采用 Gaussian 标准原子密度的另一版本,后者适用于整个元素周期表。对于两种方法都适用的体系,原子电荷的差异通常在 1% 到 5% 之间。

    Dipole

    在将电荷拟合到势能时,约束其复现偶极矩。ESPDipole 是 Dipole 的同义词。

    AtomDipole

    在将电荷拟合到势能时,同时在每个原子中心拟合一个点偶极子。

    ReadRadii

    读入每种元素用于拟合势能的替代半径(单位为埃)。这些半径以原子符号和半径成对读入,以空行结束。

    ReadAtRadii

    读入每个原子用于拟合势能的替代半径(单位为埃)。这些半径以原子序号和半径成对读入,以空行结束。

    NBO 相关选项(版本 3)

    NBO

    请求完整的自然键轨道分析,使用 NBO 版本 3 [14–21]。

    NCS

    请求利用基于 NBO 分析方法的 Bohmann 等人的自然化学屏蔽分析 [650],将(使用 GIAO 计算的)NMR 屏蔽张量划分为来自键和孤对的磁贡献。默认对各向同性屏蔽进行分析。NoNCS 跳过此分析。

    NCSDiag

    请求对张量对角元素进行 NCS 分析。

    NCSAll

    请求对所有张量分量进行 NCS 分析。

    NPA

    仅请求 NBO 中的自然布居分析阶段。

    NBORead

    请求完整的 NBO 分析,分析的控制输入从输入流中读取。使用此选项可指定 NBO 的关键字。有关此输入的细节,请参阅 NBO 文档。

    NBODel

    请求分析删除某些相互作用的效果。仅适用于 SCF 方法。意味着将读取 NBO 输入;细节请参阅 NBO 文档。注意,NBO 输入从第 2 列开始,以免 UNIX shell 将开头的 $ 解释为特殊字符。

    SaveNBOs

    将自然键轨道保存到检查点文件中(供之后可视化使用)。

    SaveNLMOs

    将自然定域分子轨道保存到检查点文件中(供之后可视化使用)。

    SaveMixed

    将占据轨道的 NBO 和空轨道的 NLMO 保存到检查点文件中(供之后可视化使用)。

    NBO 相关选项(版本 6)

    系统提供了与 NBO 版本 6 的接口。Pop=NPA6、Pop=NBO6、Pop=NBO6Read 和 Pop=NBO6Delete 通过外部接口请求使用独立的 NBO6 程序。运行 NBO6 所需的脚本及程序本身必须从 Frank Weinhold 处获取(nbo6.chem.wisc.edu)。

    5.62.2 相关关键字¶

    Density, Output=WFN

    5.62.3 示例¶

    逐轨道布居分析。 以下路由段请求对最低 3 个空轨道和最高 3 个占据轨道进行布居分析:

    #UHF/6-311+G(d)Pop=Orbitals=3

    以下是 FeO+ 四重态计算的输出结果:

    AtomiccontributionstoAlphamolecularorbitals:
Alphaocc16OE=-0.923isFe1-d=1.00
Alphaocc17OE=-0.699isO2-p=0.88
Alphaocc18OE=-0.690isO2-p=0.68Fe1-s=0.21
Alphavir19OE=-0.253isFe1-s=0.70Fe1-p=0.27
Alphavir20OE=-0.188isFe1-p=0.71O2-p=0.29
Alphavir21OE=-0.133isFe1-p=1.04
AtomiccontributionstoBetamolecularorbitals:
Betaocc13OE=-0.801isO2-p=0.79
Betaocc14OE=-0.783isFe1-d=1.00
Betaocc15OE=-0.758isO2-p=0.89
Betavir16OE=-0.241isFe1-s=0.81Fe1-p=0.17
Betavir17OE=-0.139isFe1-p=0.91Fe1-d=0.14

    注意,α 和 β 轨道信息均已包含。对每个轨道,输出给出轨道能量(标记为 OE,单位为原子单位),随后是每个相关原子上给定角动量的所有基函数的分数贡献。这是一个难以判断体系自旋态的例子,因为正则 α 和 β 轨道差别很大。若随后运行 Guess=(Read,Only,BiOrthogonalize) Pop=Orbital 计算来分析结果,程序会对 α 和 β 轨道进行变换,使其尽可能匹配(占据轨道与空轨道分别处理)。在这种情况下,变换后轨道的能量不再给出。取而代之,Pop=Orbital 分析会报告对应轨道对之间的重叠(即 α 19 与 β 19),值为 1 表示 100% 对应。轨道不再标记为占据或空,而是标记为:

    Docc Doubly occupied: alpha and beta are occupied, with a match of 90% or better.
Asing, Bsing Singly occupied: alpha without matching beta occupied, or lower occupieds which

    未与任何相反自旋轨道匹配的轨道。

    Dvir Virtual orbital with nearly the same alpha and beta orbitals.
AVir, BVir Virtual orbital which does not match up with any of the other opposite-spin virtuals.
